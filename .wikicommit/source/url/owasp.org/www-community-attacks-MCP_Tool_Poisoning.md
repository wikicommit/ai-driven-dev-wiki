## Summary

OWASP's community attack page "MCP Tool Poisoning", credited to the author kOaDT, which locates the injected instructions in tool responses at runtime rather than in tool metadata — a framing that differs from Microsoft's and CoSAI's and is recorded as such on both pages. It sets out the attack as a six-step sequence with a worked malicious-server example, and lists attack surface, risk factors and five structural preventions including schema-constrained responses, privileged-tool isolation and server-side enforcement. As a continuously-maintained community reference with no publication date, it was not treated as a citable single-instance work, so no page was created for it.
