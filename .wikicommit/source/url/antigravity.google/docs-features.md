## Summary

This page of the Google Antigravity documentation describes the features of Antigravity 2.0. Agents work in Projects that support Git worktrees, scoped settings and permissions, and multiple folders, while one-off conversations run in an isolated scratch folder; other features include scheduled tasks, secure-by-default approvals and bounded file access, live voice transcription, JSON hooks, a reworked browser subagent, Remote Control from any web browser, an integrated terminal and a Git-native version-control panel.
