## Summary

This page of the Google Antigravity documentation gives an overview of the Antigravity IDE's browser integration. Antigravity can open, read and actuate a local Chrome browser to test development websites, read documentation and automate browser tasks, operating on tabs through a specialised browser subagent that captures screenshots and action videos as artifacts. Browser tools can be switched off in settings, and URL access is governed by a two-layer denylist and allowlist, with the agent running in a separate Chrome profile.
