## Summary

In this August 2025 personal blog post, Graham Helton tries out Charm's terminal-based AI coding agent Crush, running it in a neovim side pane to build an Open Graph image generator for his static site, and describes its interface: edit approvals, a list of changed files, a model and cost display, and quick model switching and session summaries. He values its model-agnostic design but reports that the feature cost $23.04 in API fees, argues that tools such as Cursor hold pricing advantages through optimization and economies of scale, and says he will keep using Crush only for smaller tasks until he has self-hosted GPUs.
