## Summary

A GitHub Docs how-to on creating GitHub Agentic Workflows: Markdown files in `.github/workflows/` that combine YAML frontmatter (trigger, permissions, safe outputs, engine) with natural-language instructions and are compiled into a `.lock.yml` file with the `gh aw` extension. It covers authentication through the built-in `GITHUB_TOKEN` with organization billing or through a personal access token or API key, creating a workflow with a coding agent, a weekly issue-activity report example, updating a workflow with `gh aw compile`, and importing workflows from other repositories.
