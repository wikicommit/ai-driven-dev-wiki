## Summary

A GitHub Docs tutorial for GitHub Agentic Workflows, which let repository automations be defined in Markdown and run in GitHub Actions by a chosen coding agent once the `gh aw` CLI extension has compiled them into Actions workflows. It walks through installing the extension, choosing an engine (Copilot CLI by default, or Claude Code, OpenAI Codex or Google Gemini CLI) and storing its credential, then using a coding agent with the `agentic-workflows` skill to create a pull request reviewer that checks whether changes are adequately tested.
