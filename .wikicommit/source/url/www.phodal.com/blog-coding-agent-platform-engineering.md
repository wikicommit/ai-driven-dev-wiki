## Summary

Phodal Huang's March 2026 post argues that every stage of the DevOps toolchain is growing its own AI agent, leaving platform engineering with isolated agents that do not collaborate, and that three protocol layers — MCP for tools and context, ACP for coding-agent process lifecycle, and A2A for cross-platform agent discovery and collaboration, with Skills describing agent capabilities — are the foundation for connecting them. It then contrasts two multi-agent orchestration modes, an external orchestrator driving ACP agent processes and a Workspace Agent that coordinates sub-agents itself, and presents the Routa platform's hybrid architecture as a practical reference.
