## Summary

A Chinese-language blog post by Phodal Huang (March 2026) proposing "AI Coding Fluency", a model adapted from the Agile Fluency Model for how teams' capability to develop software with AI evolves. It describes five levels — Awareness, Assisted Coding, Structured AI Coding, Agent-Centric and Agent-First — across five dimensions (human-AI collaboration, SDLC coverage, AI engineering harness, governance and quality, context engineering), stressing that it is not a strict maturity path. It argues that the core challenges of AI programming (trust, context, task design) are about collaboration rather than model capability.
