## Summary

A page from Wei Zhang and Jessie Jie Xia's Structured-Prompt-Driven Development (SPDD) material on martinfowler.com describing "Iterative Review", the practice of turning AI-assisted output into a controlled review-and-iterate loop rather than a one-shot draft. It lists what to check during review (prompt and code consistency, architecture boundaries, cross-cutting engineering standards, hallucination and correctness), the capabilities a team needs (prompt debugging, functional validation, deep code review, asset integrity), and two operating principles: treat the structured prompt as code, and validate behaviour before reviewing code in depth.
