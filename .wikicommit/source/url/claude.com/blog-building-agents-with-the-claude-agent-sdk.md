## Summary

An Anthropic blog post (September 29, 2025) announcing the renaming of the Claude Code SDK to the Claude Agent SDK, on the grounds that the agent harness powering Claude Code can power many non-coding agents too. It frames agent design around a feedback loop of gathering context, taking action and verifying work, and walks through SDK features for each stage — agentic search over the file system, subagents, compaction, tools, bash, code generation, MCP, and rule-based, visual and LLM-as-judge verification — using an email agent as a running example.
