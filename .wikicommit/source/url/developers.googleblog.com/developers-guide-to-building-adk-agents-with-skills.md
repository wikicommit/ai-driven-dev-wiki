## Summary

A Google for Developers guide to giving Agent Development Kit (ADK) agents domain expertise through its SkillToolset, which implements the Agent Skills specification's progressive disclosure in three levels — metadata, instructions and resources — instead of one monolithic system prompt. It walks through four patterns of increasing reach: an inline skill defined in code, a file-based skill directory with a SKILL.md and reference files, an external skill imported from a community repository, and a skill factory in which a meta skill lets the agent write new, spec-compliant skills at runtime, with the advice to review generated skills before deploying them.
