## Summary

Google announces an Automated Review feature for Conductor, a Gemini CLI extension that keeps project context in version-controlled markdown files rather than in chat logs. Once a coding agent finishes its tasks, Conductor can generate a post-implementation report covering code review, compliance with the plan and spec files, project guideline enforcement, test-suite results and a basic security scan. Findings are graded High, Medium or Low with the exact file path, and a track can be started within Conductor to fix them.
