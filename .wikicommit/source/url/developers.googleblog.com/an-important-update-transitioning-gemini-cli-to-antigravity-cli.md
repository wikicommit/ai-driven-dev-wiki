## Summary

Google announces that it is unifying its terminal agent efforts into Google Antigravity, making Antigravity CLI available to everyone and transitioning Gemini CLI users to it. Antigravity CLI is built in Go, keeps Gemini CLI's Agent Skills, hooks, subagents and extensions (now as Antigravity plugins), runs multiple agents asynchronously in the background, and shares its agent harness with the Antigravity 2.0 desktop app. From June 18, 2026 Gemini CLI and the Gemini Code Assist IDE extensions stop serving consumer users, while enterprise customers on Gemini Code Assist Standard or Enterprise licenses keep their access.
