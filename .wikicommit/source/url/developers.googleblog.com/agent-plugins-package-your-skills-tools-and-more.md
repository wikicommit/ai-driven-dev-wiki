## Summary

Google announces that it is joining the Agent Plugins specification as a Core Maintainer. Agent Plugins 1.0.0 is an open, vendor-neutral format that packages Agent Skills and MCP servers into a single portable directory with a minimal plugin.json manifest, fixed component locations and a reverse-domain extension namespace per client, and deliberately leaves installation, distribution, permissions and trust out of scope. The post places the format in a layered ecosystem alongside Agentic Resource Discovery, AI Catalog, MCP and Agent Skills, and names Agents CLI and Data Agent Kit as the first Google products to support it.
