## Summary

Google's announcement that Jules, its asynchronous coding agent, can be driven from the terminal through Jules Tools, a lightweight command line interface and TUI installed via npm. The post's argument is that a command line surface makes the agent programmable, scriptable and customizable rather than merely reachable from another place, and it shows the CLI composed with other terminal tools — looping a TODO file into sessions, piping GitHub issues in, using the Gemini CLI to pick work. It closes with a "hybrid by design" position: local plus remote, and do-it-yourself plus delegation.
