## Summary

A Google for Developers post distilling five architectural patterns for production AI agents from the Google Cloud AI Agent Bake-Off, a competition series in which teams built autonomous agents under tight time limits for e-commerce, legacy banking and go-to-market challenges. The patterns are: decompose into specialized sub-agents behind a supervisor; expect the agent harness to be short-lived as models advance; treat multimodality as native rather than an add-on; adopt open agent protocols instead of bespoke integration code; and confine the model to reasoning while validated output is executed by deterministic code.
