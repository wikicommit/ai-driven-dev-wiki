## Summary

Anthropic announced automated security reviews in Claude Code in August 2025: a /security-review command that runs an ad-hoc, security-focused analysis of a codebase from the terminal, and a GitHub Action that reviews every new pull request and posts inline comments on security concerns. The post lists the vulnerability classes the command checks for and gives two examples from Anthropic's own use in which the action caught a remote code execution vulnerability and an SSRF vulnerability before they shipped.
