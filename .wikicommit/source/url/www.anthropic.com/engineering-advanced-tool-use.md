## Summary

Anthropic announces three beta features on the Claude Developer Platform: the Tool Search Tool, which lets Claude discover deferred tool definitions on demand; Programmatic Tool Calling, which lets Claude orchestrate tools from code running in a code-execution environment so that intermediate results stay out of its context; and Tool Use Examples, which attach sample calls to a tool definition to convey usage patterns a JSON schema cannot express. For each it states the problem addressed, how the feature works, Anthropic's internal measurements, and when it is and is not worth using, and it closes with guidance on layering the three.
