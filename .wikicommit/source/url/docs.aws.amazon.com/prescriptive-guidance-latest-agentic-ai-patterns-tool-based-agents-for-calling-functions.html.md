## Summary

An AWS Prescriptive Guidance page describing the "tool-based agents for calling functions" architecture pattern, in which a language model selects a tool from registry metadata, generates the call arguments and folds the result back into its reasoning. It sets out a five-step control flow from query to response and lists the pattern's capabilities, common use cases and AWS implementation building blocks. It frames the pattern as the shift from understanding language to performing actions, and as an important component of agentic AI in enterprise settings.
