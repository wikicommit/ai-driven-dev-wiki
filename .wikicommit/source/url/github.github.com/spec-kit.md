## Summary

The landing page of GitHub Spec Kit's documentation site presents the toolkit as giving a coding agent structured processes that keep intent and evidence ahead of implementation, offering Spec-Driven Development (Specify → Plan → Tasks → Implement → Converge) in core and bug fixing and idea assessment as opt-in bundled extensions, each an independent entry point. It describes integrations with many coding agents, customization through presets, extensions, workflows and bundles (including community processes beyond software development), and organizational use offline or behind firewalls with self-hosted catalogs.
