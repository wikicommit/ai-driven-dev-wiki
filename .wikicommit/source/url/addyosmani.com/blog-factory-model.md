## Summary

This post argues that AI coding agents have produced a step change in software engineering, reframing the developer's job from writing code to building and orchestrating a "factory" — a fleet of parallel autonomous agents each with its own task, toolbelt, context, and feedback loop. It argues that as code generation is increasingly automated, specification clarity and disciplined testing (especially red/green test-driven development) become the main source of engineering leverage, and that verification, not generation, is now the unsolved bottleneck limiting how far this model can scale. It closes by arguing that core software engineering skills — systems thinking, problem decomposition, architectural judgment — have not been devalued but have shifted in relative importance, consistent with every prior rise in the level of abstraction.
