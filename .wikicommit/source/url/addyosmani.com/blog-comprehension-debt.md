## Summary

A March 2026 post by Addy Osmani naming comprehension debt — which it equates with cognitive debt — as the growing gap between how much code exists in a system and how much of it any human genuinely understands, and contrasting it with technical debt on the grounds that technical debt announces itself through friction while comprehension debt breeds false confidence. Its mechanism is a speed asymmetry: AI generates code far faster than humans can evaluate it, inverting the old arrangement in which reviewing was faster than writing and turning a quality gate into a throughput problem. The post argues that tests and detailed specs each have a hard ceiling as substitutes for understanding, that conventional delivery metrics cannot see the deficit at all, and that regulation will eventually make "the AI wrote it and we didn't fully review it" untenable in safety- or money-critical systems.
