## Summary

This post argues that coding-agent configuration — CLAUDE.md and AGENTS.md context files, skills, plugins, MCP servers, hooks and memory — decays as models, harnesses and codebases change, and should be audited periodically rather than accumulated. It summarizes recent research suggesting that context files change how agents work more than how often they succeed, and that generic community skills tend to outperform personalized ones, and recommends running Claude Code's /doctor command, reviewing memory separately, archiving before deleting, and testing tasks with local skills removed.
