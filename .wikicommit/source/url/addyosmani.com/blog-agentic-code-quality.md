## Summary
A blog post by Addy Osmani arguing that, because agents produce more code than people can read, software quality increasingly depends on the constraints placed around agents: quality gates such as tests, mutation testing, code-quality metrics and security scanning, applied as back-pressure throughout the delivery loop rather than as a single review at the end. It frames quality as a collection of signals rather than one metric, and argues that human attention should be directed to the problems that need judgment, with teams deciding deliberately where to tighten or relax constraints.
