## Summary

A glossary entry from Addy Osmani's agentic engineering glossary explaining "LSP for AI": the idea that AI coding tools need a shared integration standard, just as the Language Server Protocol reduced the editor-by-language M×N integration problem to M+N. It names protocols such as MCP as early steps toward that vision, and argues that standardization reduces lock-in and lets one tool server serve every compatible client. It notes the vision is still early and likely to change.
