## Summary
A June 2026 blog post by Addy Osmani arguing that as coding agents make writing code nearly free, code review has become software engineering's most leveraged bottleneck, citing 2026 industry data (Faros AI, CodeRabbit, GitClear, GitHub) showing AI adoption sharply raising output while raising churn, defect rates, review duration, and zero-review merges. It argues review effort should scale with a change's "blast radius" rather than being applied uniformly, and offers concrete practices (risk-tiering, heterogeneous AI reviewers, evidence requirements, small PRs, scrutinizing test edits, strict CI gates, and keeping a human accountable for the merge decision).
