## Summary

Addy Osmani's write-up of his O'Reilly AI CodeCon talk of 26 March 2026 on coordinating multiple coding agents. It presents three escalating multi-agent patterns — subagents, Claude Code's experimental Agent Teams, and purpose-built orchestration tooling sorted into three tiers — together with the quality gates (plan approval, lifecycle hooks, AGENTS.md) the author argues make agent output trustworthy. Its closing argument is that verification, not generation, is now the bottleneck, and that an orchestrated fleet compounds small mistakes faster than a developer can catch them.
