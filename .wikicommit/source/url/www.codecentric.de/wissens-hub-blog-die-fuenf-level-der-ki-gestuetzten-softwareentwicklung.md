## Summary

A German-language codecentric blog post by Goetz Markgraf (February 2026) that proposes a five-level model of AI-assisted software development modelled on the levels of autonomous driving: AI code assistance, AI code generation, agentic AI development, spec-driven development, and autonomous product evolution. It describes typical tools and the division of work between human and AI at each level, and lists the preconditions for using AI safely and effectively, which it calls AI readiness: code quality, automated tests, documentation, team skills, security isolation and a secured AI model.
