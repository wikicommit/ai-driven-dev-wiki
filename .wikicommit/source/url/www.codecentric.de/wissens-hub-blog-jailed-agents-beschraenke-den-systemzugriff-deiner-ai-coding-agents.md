## Summary

A German-language codecentric blog post (September 2026) introducing jailed-agents, a Nix-based tool that runs AI coding agents in a sandbox with restricted system access. It explains why coding agents should be sandboxed, compares the option with VMs and Docker containers, and describes the tool's zero-trust whitelisting, declarative Nix configuration, predefined agent configurations and its use of jail.nix combinators, including integration with devenv.
