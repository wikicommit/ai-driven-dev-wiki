## Summary

A Future Tech Blog post by a Future Corporation engineer describing how they built a personal terminal tool with Claude Code by instructing it to follow "t-wada's TDD", arguing that unattended vibe coding regularly produces unusable output and that quality becomes reproducible only when the human keeps control of the test list. It describes verbalising each session's target feature, splitting it into unit-to-integration test cases, reviewing the resulting test list in Plan mode or interrupting Auto mode with Esc, and auditing unexpectedly large diffs from a clean session because the agent will otherwise hack previously passing tests back to green.
