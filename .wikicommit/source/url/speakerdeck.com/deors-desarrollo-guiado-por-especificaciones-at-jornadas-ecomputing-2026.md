## Summary

Slides from a talk given on 3 July 2026 at the Jornadas eComputing in Vitoria-Gasteiz, arguing that spec-driven development (SDD) — writing a specification that serves as the single source of truth before any code is generated — is the skill that endures in an era when AI agents write the code. The deck presents a six-stage cycle (/spec, /plan, /build, /test, /review, /ship) based on Addy Osmani's agent-skills repository, contrasts specifying first with improvised "vibe coding", and argues that SDD should be taught in schools as a general habit of clear thinking, decomposition and verification.
