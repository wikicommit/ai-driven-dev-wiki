## Summary

An April 2025 post on the OpenHands blog introducing the OpenHands context condenser, which keeps an agent's conversation bounded by summarizing older interactions once the context passes a size threshold while keeping recent exchanges intact. The post reports that condensation cuts per-turn API cost by up to half, changes cost scaling from quadratic to linear, and matches or slightly exceeds the baseline agent's solve rate on a subset of SWE-bench Verified instances.
