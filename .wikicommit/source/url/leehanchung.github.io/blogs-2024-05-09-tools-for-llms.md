## Summary

A 2024 blog post by Han Lee tracing tool use for LLM agents from pre-ChatGPT research through the tool-calling APIs the major model providers shipped in 2023-2024. It compares the OpenAI, Gemini, Anthropic, Cohere and LangChain schemas and concludes with a three-part definition of a tool -- name, description, and a clearly defined input JSON schema -- stressing that the model only generates the arguments while the developer executes the call.
