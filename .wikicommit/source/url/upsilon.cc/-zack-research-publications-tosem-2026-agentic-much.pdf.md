## Summary

This paper presents the first large-scale study of coding agent adoption on GitHub: using heuristics over agent configuration files, commit authorship, branch names and pull request labels across 128,018 projects, it estimates that 22.20% to 28.66% of them had adopted coding agents as of February 21, 2026. It finds adoption broad across project maturity, organizations, topics and languages, biased toward younger projects, and rising fast since spring 2025, and reports that agent-assisted commits are larger than human-authored ones and are mostly feature additions and bug fixes.
