## Summary

Front matter and Chapter 1 ("The Dark Factory") of Kevin Ryan's book *Spec Driven Development: AI Native Software Engineering* (first edition, 2026, published as an in-progress beta), which argues that specifications rather than code should become the maintained artifact in AI-native software engineering. The chapter contrasts StrongDM's fully autonomous three-engineer "Dark Factory" operation with a METR randomised controlled trial in which experienced developers were 19% slower with AI while believing they were 24% faster, and presents Dan Shapiro's Five Levels of Vibe Coding as a maturity framework for locating a team's actual practice. It argues the industry bottleneck has moved from implementation to two new places — specification quality and AI-native execution infrastructure — and that the gap between Level 2 and Levels 3–4 is a change in how teams think about the work rather than a technology upgrade.
