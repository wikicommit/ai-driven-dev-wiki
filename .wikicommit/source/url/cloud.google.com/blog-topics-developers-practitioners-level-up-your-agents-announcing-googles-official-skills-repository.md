## Summary

Google Cloud's Day 1 announcement at Google Cloud Next 2026 of its official Agent Skills repository at github.com/google/skills, launching with thirteen skills across Google Cloud products, three Well-Architected pillars, and onboarding recipes. Its stated rationale is that heavy MCP-server use causes context bloat — large amounts of context loaded into the window, confusing the model and raising token costs — and that skills supply condensed, agent-first documentation loaded only as needed. Installation is a single npx skills install command targeting Antigravity, Gemini CLI and third-party agents.
