## Summary

A May 2024 GitHub blog post reporting research GitHub conducted with Accenture, combining a randomized controlled trial, a company-wide adoption analysis and a developer survey, to measure GitHub Copilot's impact in an enterprise setting. It reports rapid adoption (81.4% installed the IDE extension on the day they received a license), an 8.69% increase in pull requests per developer, a 15% increase in pull request merge rate, an 84% increase in successful builds, and high developer satisfaction, and outlines how organizations can run their own impact studies.
