## Summary

A GitHub Blog post by Tomas Vesely, published 30 September 2025, describing an experiment in which a Markdown file is treated as an application's actual source code and GitHub Copilot compiles it into Go. It sets out a four-file structure — user-facing README, specification, compile prompt and generated code — and reports that specifications can be linted like code with a second prompt file. The author offers it as an experimental workflow after a few months on one personal project, noting that compilation slows as the generated code grows and that he had not yet added tests.
