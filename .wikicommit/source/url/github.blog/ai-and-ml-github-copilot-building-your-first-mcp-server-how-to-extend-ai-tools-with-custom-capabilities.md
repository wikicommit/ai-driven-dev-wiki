## Summary

A GitHub developer advocate explains the Model Context Protocol by building a TypeScript MCP server for turn-based games that lets GitHub Copilot in VS Code play Tic-Tac-Toe and Rock Paper Scissors against the user. The post covers MCP's host/client/server pattern, its three core building blocks (tools, resources and prompts), registering servers through `.vscode/mcp.json`, and practical considerations such as authentication and vetting third-party MCP servers before installing them.
