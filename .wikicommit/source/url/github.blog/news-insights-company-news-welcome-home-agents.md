## Summary

GitHub's Universe 2025 announcement of Agent HQ, its plan to make coding agents native to the GitHub flow rather than bolted onto it: coding agents from Anthropic, OpenAI, Google, Cognition and xAI are to become available directly within GitHub under a paid Copilot subscription, while Git, pull requests, issues and Actions stay the working primitives. Around that it announces mission control -- a command center spanning GitHub, VS Code, mobile and the CLI for assigning and tracking parallel agent work -- plus VS Code's Plan Mode, custom agents configured through AGENTS.md files, and the GitHub MCP Registry. It also announces enterprise-facing pieces: GitHub Code Quality, a Copilot metrics dashboard, and an agent control plane governing which agents and models an organization may reach.
