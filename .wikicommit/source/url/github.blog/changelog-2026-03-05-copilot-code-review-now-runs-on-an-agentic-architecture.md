## Summary

A GitHub changelog entry (March 5, 2026) announcing that Copilot code review now runs on an agentic tool-calling architecture that gathers broader repository context as needed, and that it is generally available on paid Copilot plans. The agentic review runs on GitHub Actions, so organizations that have opted out of GitHub-hosted runners need a one-time self-hosted runner setup.
