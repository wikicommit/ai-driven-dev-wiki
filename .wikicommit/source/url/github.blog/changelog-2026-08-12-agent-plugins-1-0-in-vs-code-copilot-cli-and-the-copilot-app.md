## Summary

A GitHub changelog entry of 12 August 2026 announcing general availability of Agent Plugins 1.0 support in VS Code, Copilot CLI, the GitHub Copilot SDK and the GitHub Copilot app on all Copilot plans. It describes the specification, published on 6 August with AWS, Anysphere, Microsoft, OpenAI and Vercel and joined by Google as a core maintainer, as an open standard packaging agent skills and MCP servers into one installable plugin; explains that migrating a plugin is mostly manifest work, with Copilot-specific files moved into a namespaced directory; and says existing enterprise managed settings such as enabledPlugins and strictKnownMarketplaces govern these plugins without a separate policy.
