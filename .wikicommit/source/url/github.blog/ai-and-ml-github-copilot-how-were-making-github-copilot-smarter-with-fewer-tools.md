## Summary

A November 2025 GitHub blog post describing how GitHub Copilot Chat in VS Code was changed to cope with agents having access to too many tools: tools are grouped into expandable "virtual tools" using embedding-based adaptive clustering, embedding-guided tool routing pre-selects the tools most relevant to a query, and the default built-in toolset is cut from about 40 tools to 13 core ones. GitHub reports a 2-5 percentage point improvement in success rates on SWE-Lancer and SWE-bench Verified, 94.5% Tool Use Coverage for embedding-based selection, and an average 400 ms reduction in response latency in online A/B testing.
