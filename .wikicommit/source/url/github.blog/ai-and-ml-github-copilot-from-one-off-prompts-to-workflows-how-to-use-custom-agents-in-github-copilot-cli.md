## Summary

A GitHub blog post explaining custom agents in GitHub Copilot CLI: Copilot agents defined by Markdown agent profiles (`.agent.md` files with YAML frontmatter in a repository's `.github/agents` directory) that specify the agent's role, tools and guardrails, and are invoked with the `/agent` slash command. It gives example profiles for security audits, infrastructure-as-code compliance, release notes and incident response, and advises using partner-built off-the-shelf agents for speed and custom agents when a team needs precision, continuity and control over its own conventions.
