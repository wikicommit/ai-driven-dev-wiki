## Summary

GitHub's announcement of Spec Kit, an open-source toolkit for spec-driven development, arguing that coding agents should be treated as literal-minded pair programmers rather than search engines and that specifications should be living, executable artifacts serving as the shared source of truth. The toolkit runs in four gated phases — Specify, Plan, Tasks, Implement — with the developer verifying each before the next begins, driven by a `specify` CLI and `/specify`, `/plan` and `/tasks` commands across coding agents including GitHub Copilot, Claude Code and Gemini CLI. The post names greenfield projects, feature work in existing systems and legacy modernization as the scenarios it suits, and frames the wider shift as moving from code to intent as the source of truth.
