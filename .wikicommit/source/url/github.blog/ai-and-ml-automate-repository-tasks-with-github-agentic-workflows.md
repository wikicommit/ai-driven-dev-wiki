## Summary

GitHub's technical-preview announcement of GitHub Agentic Workflows: repository automation authored in plain Markdown and executed by coding agents inside GitHub Actions. Each workflow file pairs YAML frontmatter for trigger, permissions, tools and allowed outputs with Markdown instructions describing the job, and compiles to a lock file that Actions runs. The security architecture is described as defense-in-depth — read-only permissions by default, writes only through pre-approved safe outputs, plus sandboxed execution, tool allowlisting and network isolation — and GitHub groups the resulting automation categories under its term Continuous AI, which it says augments rather than replaces CI/CD.
