## Summary

A Zed blog post of 24 January 2024 announcing that the Zed code editor had become open source, with the editor under the GPL, server-side components under the AGPL and the GPUI UI framework under Apache 2. It explains the motivation (a better product and more connection with developers), introduces Zed Channels for real-time collaborative coding and the public Fireside Hacks sessions, and describes a business model built on services integrated with the editor rather than on selling a proprietary editor.
