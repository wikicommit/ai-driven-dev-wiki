## Summary

The GitHub repository for Taskmaster (Task Master), a task-management system for AI-driven development that turns a product requirements document into structured tasks an AI coding assistant can plan, expand and work through, used either as an MCP server inside editors such as Cursor, Windsurf, VS Code and Claude Code or as a command-line tool. The README covers its model configuration (main, research and fallback models across several providers, including Claude Code and Codex CLI without an API key), its recommended PRD-first workflow and commands, selective loading of its MCP tools to reduce context-window use, and its MIT-with-Commons-Clause license.
