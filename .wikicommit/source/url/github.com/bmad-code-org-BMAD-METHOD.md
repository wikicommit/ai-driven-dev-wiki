## Summary

The GitHub repository for the BMad Method (Breakthrough Method for Agile Ai Driven Development), a free, MIT-licensed agile method for AI-driven development whose agents and workflows keep decisions explicit and carry context forward, with a process that scales from direct implementation of small changes to deeper planning for complex work. The README covers installation as skills or as Claude Code and Codex plugins, the method's delivery loop and stated benefits, its official modules, and web bundles for planning in Gemini and ChatGPT.
