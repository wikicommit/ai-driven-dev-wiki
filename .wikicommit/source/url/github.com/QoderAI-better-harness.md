## Summary

The GitHub repository for Better Harness, an MIT-licensed open-source tool from QoderAI that runs inside a coding agent and analyses a project's AI coding workflow, turning project and session evidence into prioritized, evidence-bounded findings. It evaluates delivery across the five dimensions of its "Agent Work Loop" model, framed as a feedforward-and-feedback loop, and the README gives per-host installation and invocation for Claude Code, Codex, Qoder, Cursor, GitHub Copilot and several further hosts.
