## Summary

The GitHub repository for goose, an Apache-2.0-licensed, general-purpose open-source AI agent that runs on the user's machine as a desktop app, a CLI and an embeddable API, for coding as well as research, writing, automation and data analysis. The README describes its Rust implementation, support for more than 15 model providers (including existing subscriptions via ACP), connection to more than 70 extensions through the Model Context Protocol, and its place in the Agentic AI Foundation at the Linux Foundation.
