## Summary

The GitHub repository README for Microsoft's Agent Governance Toolkit (AGT), an MIT-licensed public-preview toolkit that enforces policy on autonomous AI agents in deterministic application code rather than in the prompt. It covers a policy engine accepting YAML, OPA or Cedar, zero-trust identity, execution sandboxing, tamper-evident audit logging and an MCP security gateway, shipped as SDKs for Python, TypeScript, .NET, Rust and Go. The README argues that prompt-level safety is not a control surface, and documents ten RFC 2119 specifications backed by 992 conformance tests alongside compliance mappings to the OWASP Agentic AI Top 10, NIST AI RMF, the EU AI Act and SOC 2.
