## Summary

The GitHub repository "Loop Engineering", an MIT-licensed pattern library, set of starters and CLI for loop engineering with AI coding agents — designing a system that discovers work, hands it to agents, verifies results and persists state instead of prompting the agent turn by turn. It catalogues named loop patterns such as daily triage, a PR babysitter and CI and dependency sweepers with their cadence, starting autonomy level and relative cost, prescribes a staged rollout from report-only to unattended operation, and provides a CLI that sets patterns up for Claude Code, Codex, Grok or OpenCode.
