## Summary

The GitHub repository README for DeepCode, an open-source coding agent from the Data Intelligence Lab at The University of Hong Kong that began as a Paper2Code system for reproducing research papers as code and was rebuilt in version 2.0 as a general-purpose coding agent. It describes TUI, desktop and web clients sharing one local background service, durable sessions, goal-driven "Loop Engineering", evidence-driven completion, three-level permissions with project trust, skills, local plugins, MCP support, parallel agents in isolated Git worktrees, and scheduled automations. It also restates the original multi-agent Paper2Code architecture and its reported PaperBench results.
