## Summary

The GitHub repository for Cline, an Apache-2.0-licensed open-source coding agent from Cline Bot Inc. that runs as a VS Code extension, a JetBrains plugin, a CLI and a desktop app, all built on a shared agent engine that is also exposed as an SDK. The README describes its project-wide code editing with reviewable diffs and checkpoints, terminal command execution, Plan and Act modes with per-action approval, .clinerules rules and skills, multi-provider model support, plugins and MCP servers, multi-agent teams, scheduled agents, messaging-platform connectors and a headless CLI for CI/CD.
