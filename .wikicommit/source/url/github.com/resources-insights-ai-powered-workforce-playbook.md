## Summary

A GitHub playbook published on July 22, 2025 describing how GitHub built AI fluency across its own workforce through its "AI for Everyone" initiative, treating AI adoption as a change-management problem rather than a technology one. It sets out eight pillars — AI advocates, clear policies and guardrails, learning and development, data-driven metrics, a dedicated responsible individual, executive support, right-fit tooling and communities of practice — explains how to put each into practice, and gives a three-phase measurement framework and a phased implementation checklist.
