## Summary

The GitHub repository page for Context Engineering Kit, a GPL-3.0 marketplace of context-engineering plugins for AI coding agents published by NeoLabHQ, packaging prompt patterns as installable skills, commands and sub-agents for Claude Code, Gemini CLI, Antigravity, Cursor and other tools. It documents thirteen plugins — among them Spec-Driven Development, Subagent-Driven Development, Reflexion and an implementation of Anatoly Levenchuk's First Principles Framework — alongside the project's own comparison of how different agent-usage approaches affect the probability of fully accurate results.
