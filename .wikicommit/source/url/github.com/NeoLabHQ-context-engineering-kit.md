## Summary

The Context Engineering Kit repository, an open-source plugin marketplace of context engineering techniques and patterns for Claude Code, OpenCode, Cursor, Antigravity and other agents, licensed GPL-3.0. Its README documents twelve plugins covering reflection, spec-driven development, subagent orchestration, code review, testing, domain-driven design and structured reasoning, alongside the maintainers' own reliability-versus-token-cost comparison table drawn from their production usage rather than from a published benchmark.
