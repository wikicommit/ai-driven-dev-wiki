## Summary

The repository behind the AGENTS.md format, which describes itself as a simple, open format for guiding coding agents -- a README for agents, giving a dedicated and predictable place to supply project context and instructions. It ships a minimal example file with three sections (dev environment tips, testing instructions, pull-request instructions) whose contents are concrete commands and conventions rather than prose about the codebase. The project is MIT licensed, publishes a website at agents.md explaining its goals, and carries a technical charter.
