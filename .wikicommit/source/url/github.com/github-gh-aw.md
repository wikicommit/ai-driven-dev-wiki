## Summary

The README of the github/gh-aw repository, the MIT-licensed home of GitHub Agentic Workflows: repository automation defined in Markdown with YAML frontmatter, compiled by the gh-aw GitHub CLI extension into standard GitHub Actions workflows and run by AI agents such as GitHub Copilot, Claude Code, OpenAI Codex, Google Gemini and Pi. It positions agentic workflows as a complement to deterministic CI/CD for tasks that need reasoning, and describes read-only, sandboxed agent jobs whose configured writes are applied through validated safe-outputs jobs with scoped permissions.
