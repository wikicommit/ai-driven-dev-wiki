## Summary

The GitHub repository README for OpenHarness, an open-source Python agent harness from HKUDS that provides an agent loop, tools, on-demand skills, plugins, permissions, hooks, memory and multi-agent coordination, and that is designed to be compatible with Claude-style skills and plugins. It defines an agent harness as the infrastructure that wraps an LLM to make it a functional agent, and describes the `oh` CLI, its provider workflows and its dry-run preview. It also introduces ohmo, a personal agent built on OpenHarness that works through chat apps such as Feishu, Slack, Telegram and Discord.
