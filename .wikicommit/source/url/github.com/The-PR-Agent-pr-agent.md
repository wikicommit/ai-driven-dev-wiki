## Summary

The GitHub repository for PR-Agent, an MIT-licensed, AI-powered pull-request review agent originally built by Qodo and since donated to the open-source community, where it now lives in its own GitHub organization as a community-maintained project. The README covers quick starts as a GitHub Action or CLI, the slash-command tools it runs on pull requests and issues, its support for multiple git providers, deployment modes and LLM providers, and the project's change of governance.
