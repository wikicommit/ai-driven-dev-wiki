## Summary
The repository page for Hello-Agents (《从零开始构建智能体》), a free open-source Chinese-language tutorial from the Datawhale community on building AI agents from scratch, licensed CC BY-NC-SA 4.0. Its premise is that the focus has shifted from training larger base models to building agent applications while systematic, practice-heavy tutorials remain scarce, and it scopes itself to AI-native agents rather than the process-driven kind built on low-code platforms. Sixteen chapters across five parts run from agent history and LLM foundations through hand-implemented ReAct, Plan-and-Solve and Reflection, mainstream frameworks, a framework built from zero, memory, context engineering, communication protocols, Agentic RL and evaluation, to three integrated projects and a capstone multi-agent application.
