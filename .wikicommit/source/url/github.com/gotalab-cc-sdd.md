## Summary

The README of the gotalab/cc-sdd repository, an MIT-licensed npm package that installs a Kiro-inspired, spec-driven agentic SDLC workflow into AI coding agents. Version 3.0 reworks it around 17 Agent Skills covering discovery, requirements, design, tasks and long-running autonomous implementation, with per-task TDD, independent review and auto-debug on hosts with native subagents, and it supports eight coding agents and 14 languages. It frames the spec as a contract between parts of the system that humans approve at phase gates, with code remaining the source of truth.
