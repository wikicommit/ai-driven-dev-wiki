## Summary

The GitHub repository holding the specification and documentation for Agent Skills, which supplies the format's own account of itself to complement the third-party survey and vendor-documentation material the wiki already had. It defines a skill as a folder containing a SKILL.md file with `name` and `description` metadata plus instructions, names the three properties the format is meant to deliver (domain expertise, repeatable workflows, cross-product reuse), and sets out the three-stage progressive disclosure loading model — discovery, activation, execution — which now has its own page. On governance it states the format was originally developed by Anthropic, released as an open standard, since adopted by a growing number of agent products, and open to contributions from the broader ecosystem, with repository code under Apache 2.0 and documentation under CC-BY-4.0.
