## Summary

OpenSpec Practise is a Chinese-language learning and practice repository, originating from discussions in the "AI 原力注入" community, that demonstrates spec-driven development with OpenSpec through a complete worked example. It contains a user manual and practical guides, the `/opsx` slash commands and skills generated for Claude Code, the archived OpenSpec specifications and change proposals for a minimal e-commerce system, and Node.js and Python implementations driven by the same specifications, along with walkthroughs of successive OpenSpec releases up to v1.13.0. It also proposes a mapping from domain-driven design artifacts — bounded contexts, domain services, aggregate behaviour — onto OpenSpec's domains, requirements, scenarios, design and tasks.
