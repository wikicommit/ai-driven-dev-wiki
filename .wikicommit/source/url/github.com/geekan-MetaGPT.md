## Summary

The GitHub repository for MetaGPT, an MIT-licensed multi-agent framework that assigns different roles to LLMs so that they collaborate like a software company, turning a one-line requirement into user stories, competitive analysis, requirements, data structures, APIs and documents under the philosophy "Code = SOP(Team)". The README covers installation, configuration and use as a CLI or Python library, the Data Interpreter agent, tutorials and use cases, recent news including the launch of the MGX product, and how to cite the MetaGPT paper.
