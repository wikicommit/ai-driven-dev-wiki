## Summary

The official site for AGENTS.md, the open Markdown format that gives coding agents a dedicated, predictable place for project instructions, described there as "a README for agents" and reported as used by over 60,000 open-source projects. It supplies the format's own account of itself, which the wiki did not previously have: the rationale for keeping agent instructions out of README.md, the absence of any required fields, nearest-file-wins precedence for nested AGENTS.md in monorepos with explicit chat prompts overriding everything, the migration-by-symlink recipe, and per-tool configuration for Aider and Gemini CLI. It also states an origin account — the format "emerged from collaborative efforts" across OpenAI Codex, Amp, Jules, Cursor and Factory — that differs from the "introduced by OpenAI" account already on the wiki, so both are now recorded side by side, along with the format's stewardship by the Agentic AI Foundation under the Linux Foundation.
