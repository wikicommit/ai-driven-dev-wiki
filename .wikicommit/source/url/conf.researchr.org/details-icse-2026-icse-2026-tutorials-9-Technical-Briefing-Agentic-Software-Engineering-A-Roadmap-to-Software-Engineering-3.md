## Summary

The ICSE 2026 programme page for a 90-minute technical briefing, held on 15 April 2026 in the conference's Tutorials and Technical Briefings track, on agentic software engineering as a roadmap to Software Engineering 3.0. Its abstract describes a shift from AI-assisted development (SE 2.0) to SE 3.0, in which autonomous AI agents act as collaborators, and says the briefing synthesizes a large-scale characterization of agent activity based on the AIDev dataset, an empirical study of 567 Claude Code pull requests across 157 open-source projects, and the Structured Agentic Software Engineering (SASE) framework, offering attendees evidence-backed mental models, evaluation patterns for agent-authored pull requests and a vocabulary for designing trustworthy human-agent workflows.
