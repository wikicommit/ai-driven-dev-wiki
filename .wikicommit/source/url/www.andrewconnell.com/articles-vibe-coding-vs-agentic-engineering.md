## Summary

Andrew Connell's comparison of vibe coding and agentic engineering as two different approaches to AI-assisted development. He describes vibe coding as delegating code ownership to the AI -- useful for prototypes, low-risk tools and non-engineers -- and agentic engineering as using coding agents as force multipliers while the developer retains architecture, code quality and engineering judgment, illustrating the former's failure modes with cost and platform-support examples.
