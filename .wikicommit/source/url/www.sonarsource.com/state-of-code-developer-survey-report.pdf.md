## Summary

Sonar's survey of 1,149 professional developers, fielded throughout October 2025, whose central claim is that the explosion in AI-generated code has not yet produced the expected productivity gains and has instead created a verification bottleneck downstream of generation — now a page in its own right. Its most useful figures for this wiki are the gap between distrust and practice (96% do not fully trust AI code is functionally correct, but only 48% always check before committing), the reason for the review cost (61% agree AI "often produces code that looks correct but isn't reliable"), and the finding that toil did not shrink but changed composition, holding at 23–25% of the work week regardless of AI use frequency while shifting toward managing technical debt and correcting AI-written code. Every figure is the vendor's own and framed as such on the generated pages.
