## Summary

Google's Gemini API documentation page on tools explains how tools extend Gemini models so they can take actions, reach real-time information and perform computation, and lists the fully managed built-in tools (Google Search, Google Maps, Code Execution, URL Context, Computer Use in preview, and File Search). It contrasts the built-in tool flow, which completes inside one API call on Google's servers, with the custom-tool flow of function calling, in which the application executes each call and returns the result with a matching id, and describes the preview option for combining both kinds in one turn. It also distinguishes function calling from structured outputs and notes that the two can be combined for Gemini 3 series models.
