## Summary

A conference slide deck by Arun Gupta, VP Developer Experience at JetBrains, arguing that vibe coding is a one-shot approach whose output cannot be safely extended or changed, and presenting spec-driven development as the intention-first alternative. It runs an extended analogy between building a backyard and building software, maps construction elements onto a software development lifecycle, gives a four-stage spec-driven SDLC of Research, Standardize, Define and Loop, and sets out what makes a specification reusable and unambiguous.
