## Summary

The announcement post of 14 July 2025 for Kiro, an agentic IDE built on Code OSS and organised around two features, specs and hooks, positioned as a way to carry prompt-driven prototypes through to production. It describes a three-step spec workflow — requirements with EARS-notation acceptance criteria, a design document, then sequenced tasks linked back to requirements — and event-driven agent hooks that fire on file save, create or delete.
