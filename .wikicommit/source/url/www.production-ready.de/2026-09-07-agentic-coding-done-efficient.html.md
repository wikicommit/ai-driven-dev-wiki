## Summary

A practitioner summarizes about eighteen months of agentic coding in day-to-day project work and client training, arguing that AI-assisted development and agentic coding are not the same thing and that the gains come from letting an agent work unattended toward an explicitly described end state rather than exchanging messages with it. The conditions he identifies are making implicitly held decisions explicit in advance, giving the agent a feedback signal it can act on without a human -- static analysis, linters and above all test coverage -- and keeping changes small enough that review stays timely. A closing section argues that the non-determinism of language models is worth putting to use rather than merely tolerating.
