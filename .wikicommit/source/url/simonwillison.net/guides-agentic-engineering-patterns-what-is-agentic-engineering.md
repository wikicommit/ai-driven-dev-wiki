## Summary

The opening chapter of Simon Willison's Agentic Engineering Patterns guide, defining agentic engineering as the practice of developing software with the assistance of coding agents, coding agents as agents that can both write and execute code, and agents as software that runs tools in a loop to achieve a goal. It identifies code execution as the defining capability, argues that what remains for humans is figuring out what code to write, notes that LLMs do not learn from mistakes but harnesses can be updated to encode what was learned, and defends the original narrow definition of vibe coding as unreviewed prototype-quality output.
