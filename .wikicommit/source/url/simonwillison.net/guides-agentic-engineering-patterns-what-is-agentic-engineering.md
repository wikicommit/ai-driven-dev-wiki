## Summary

The opening chapter of a guide, defining agentic engineering as developing software with the assistance of coding agents — agents that can both write and execute code — and resting that on a definition of an agent as software that runs tools in a loop to achieve a goal. It argues that code execution is the capability that makes the practice possible, that the engineer's job was never writing code but deciding what code to write, and that the practice is distinct from vibe coding, which it keeps in its original sense of prompting for code while forgetting the code exists.
