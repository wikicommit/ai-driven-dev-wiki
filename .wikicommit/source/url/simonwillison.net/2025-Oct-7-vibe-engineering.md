## Summary

Simon Willison proposes the term "vibe engineering" for the opposite end of the spectrum from vibe coding: experienced engineers using LLMs and coding agents to accelerate their work while remaining fully accountable for the software they produce. He argues that coding agents reward existing top-tier engineering practices such as automated testing, planning, documentation, version control, automation, code review, manual QA and preview environments, so that AI tools amplify existing expertise; a February 2026 update notes that "agentic engineering" appears to be winning out as the term.
