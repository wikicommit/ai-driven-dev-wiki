## Summary

A short note posted on Simon Willison's weblog on 22 August 2026, arguing that the key skill for
making productive use of coding agents is being able to confidently instruct them on how to make a
change and then confidently verify that the change was applied in the correct way. It adds that
this sometimes involves reviewing every line of code the agent wrote, but that there are other ways
to reach the same assurance, since eyeballing every line has never been the most effective way to
validate a change to a piece of software.
