## Summary

Simon Willison's post of 19 March 2025, "Not all AI-assisted programming is vibe coding (but vibe coding rocks)", six weeks after Andrej Karpathy coined the term. It states Willison's narrow definition — building software with an LLM without reviewing the code it writes — draws the line at engagement with the code rather than at tooling, states his golden rule of not committing code he could not explain to someone else, and then defends vibe coding on access and intuition-building grounds while setting out conditions for when it is appropriate. Its closing section treats safe vibe coding as a sandboxing design problem, contrasting Claude Artifacts with Cursor.
