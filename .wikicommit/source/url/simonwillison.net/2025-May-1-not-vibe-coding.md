## Summary

Simon Willison argues that two forthcoming books — Gene Kim and Steve Yegge's "Vibe Coding" (IT Revolution) and Addy Osmani's "Vibe Coding: The Future of Programming" (O'Reilly, later retitled "Beyond Vibe Coding") — misuse the term, which Andrej Karpathy coined for generating code with AI while forgetting the code exists, as a label for professional AI-assisted engineering. He argues a book on actual vibe coding for non-programmers is still needed, and concedes that semantic diffusion of the term is probably unstoppable.
