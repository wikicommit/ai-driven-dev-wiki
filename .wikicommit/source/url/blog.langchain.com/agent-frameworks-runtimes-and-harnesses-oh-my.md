## Summary

In this October 2025 LangChain blog post, Harrison Chase proposes distinguishing three kinds of agent-building package: agent frameworks such as LangChain, whose value lies in abstractions; agent runtimes such as LangGraph, which supply production infrastructure like durable execution, streaming, human-in-the-loop support and persistence; and agent harnesses such as DeepAgents, which add batteries-included defaults like prompts, planning tools and filesystem access on top of a framework. He stresses that the lines are blurry, that LangGraph is arguably both a runtime and a framework, and that he did not coin the term "agent harness".
