## Summary

An OpenAI developer blog post arguing that the open-source Codex harness behind the Codex app, CLI and IDE extension can be built into other products, so that teams bring an agent into the software already designed around their work instead of moving that work into a general-purpose coding assistant. It distinguishes three integration layers — codex exec for bounded non-interactive jobs, the Codex SDK for programmatic workflows, and Codex app-server for applications that need persistent conversations, streamed events and approval handling — and illustrates the last with Relay, a sample shipment-operations dashboard that uses application-owned MCP tools and requires human approval before consequential actions.
