## Summary

A Systematization of Knowledge preprint (v2, December 2025) by six authors across five universities, arguing that the Model Context Protocol collapses the usual distinction between adversarial security threats and epistemic safety hazards: an injected document can leave a model honestly but mistakenly believing it is authorized to delete a database, and a hallucination about a tool's parameters can produce a breach. It taxonomises security risks by impact and execution phase, maps four safety categories onto MCP primitives, identifies cross-primitive escalation as a new vulnerability class, and surveys defenses including the Enhanced Tool Definition Interface and kernel-level session isolation.
