## Summary

A large-scale study of 2,303 agent context files from 1,925 repositories by Worawalan Chatlatanagulchai and ten co-authors across Kasetsart University, NAIST and Queen's University, describing itself as the first of its kind. Its characterisation is that these files are "not static documentation but complex, difficult-to-read artifacts that evolve like configuration code through frequent, small additions" — evidenced by 67.0% of Claude Code files being revised across multiple commits, in short bursts of small additions with negligible deletions. Its content taxonomy of 16 instruction categories shows developers prioritising functional guidance (testing 75.9%, implementation details 70.8%, architecture 68.1%) while security appears in 14.8% of files, performance in 14.5% and UI/UX in 8.7% — a gap the authors read as agents being guided extensively on how to build code but not on how to build it well.

The eleven co-authors did not become pages: each is named only as a co-author with no independent facts stated about them, which is an incidental mention rather than an independent subject.
