## Summary
The paper proposing AgileCoder, a multi-agent software development framework from the FPT Software AI Center that assigns Agile Methodology roles — Product Manager, Scrum Master, Developer, Senior Developer and Tester — to LLM agents and organizes their work into sprints of planning, development, testing and review, together with a Dynamic Code Graph Generator that maintains a code dependency graph as the codebase changes so agents can retrieve relevant context. It reports higher pass@1 than ChatDev and MetaGPT on HumanEval and MBPP, and higher executability on ProjectDev, a set of 14 software development tasks the authors compiled, with ablations attributing gains to incremental sprints, generated test suites, code review and the dependency graph.
