## Summary

The ICLR 2025 paper introducing OpenHands, formerly OpenDevin, an open-source platform for building agents that interact with the world as a human developer does — writing code, using a command line, and browsing the web. Its design contributions are an event-stream state shared across agents, a deliberately small programming-language-based action space of three primitives rather than a large tool catalogue, an AgentSkills library with restrictive inclusion criteria so that skills are added only where an LLM cannot readily write the code itself, delegation between agents through a dedicated action, and a community AgentHub with CodeActAgent as its default generalist. Its reported benchmark results are its authors' own: 26% resolve rate on the 300-instance SWE-Bench Lite subset with CodeActAgent v1.8 and claude-3.5-sonnet, and 79.3% on the Python split of HumanEvalFix in a 0-shot setting.
