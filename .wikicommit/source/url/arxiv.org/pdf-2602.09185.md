## Summary

The MSR '26 paper introducing AIDev, a dataset of 932,791 agent-authored pull requests ("Agentic-PRs") from five coding agents (OpenAI Codex, Devin, GitHub Copilot, Cursor, Claude Code) across 116,211 GitHub repositories and 72,189 developers, plus a curated 33,596-PR subset from repositories with over 100 stars enriched with review, commit, and issue data, distributed via Hugging Face and Zenodo, and proposed as a foundation for large-scale empirical research on AI coding agent adoption, code quality, review dynamics, and risk.
