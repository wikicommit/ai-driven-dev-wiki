## Summary

A preprint (arXiv:2511.12884, v1 November 2025, revised August 2026) reporting what it calls the first large-scale empirical study of agent context files such as AGENTS.md and CLAUDE.md, covering 2,303 files from 1,925 repositories. It finds that these files evolve like configuration code through frequent small additions and are hard to read, and that developers mostly write functional context (test procedures 75.9%, implementation details 70.8%, architecture 68.1%) while rarely specifying non-functional requirements such as security (14.8%) or performance (14.5%).
