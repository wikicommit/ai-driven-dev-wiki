## Summary

A preprint accepted at MSR 2026 (arXiv:2602.00409) that studies mocking in agent-generated tests across more than 1.2 million 2025 commits in 2,168 TypeScript, JavaScript and Python repositories, 48,563 of them by coding agents. It finds coding agents more likely than non-agents to change tests (23% vs 13% of commits) and to add mocks (36% vs 26%), and argues that mock-heavy tests may be easier to generate but weaker at validating real interactions, calling for mocking guidance in agent configuration files.
