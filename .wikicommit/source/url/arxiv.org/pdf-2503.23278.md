## Summary

A systematic study of the Model Context Protocol by Hou, Zhao, Wang and Wang of Huazhong University of Science and Technology, with an ACM publication date of October 2025. It defines a four-phase MCP server lifecycle — creation, deployment, operation, maintenance — decomposed into 16 key activities, and builds a taxonomy of 16 threat scenarios across four attacker types (malicious developers, external attackers, malicious users, security flaws), classified by threat origin rather than by lifecycle phase because attacks such as tool poisoning and rug pulls are introduced at creation but triggered at operation. It validates the risks with proof-of-concept servers, and diagnoses the ecosystem as lacking centralized security oversight and a standardized authentication and authorization framework.
