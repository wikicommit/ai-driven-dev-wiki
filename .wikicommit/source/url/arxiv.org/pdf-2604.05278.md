## Summary

Presents Spec Kit Agents, a multi-agent spec-driven development pipeline that augments GitHub's Spec Kit workflow with a context-grounding layer: read-only discovery hooks probe the repository for evidence before each phase, and validation hooks check the intermediate artifacts and run project checks after it. The authors motivate this with a failure mode they call context blindness, in which an agent's intermediate artifacts are internally coherent but incompatible with the repository as it exists. Across 128 runs covering 32 features in five repositories they report a +0.15 gain on a 1-5 composite LLM-as-judge score while maintaining 99.7-100% repository-level test compatibility, and 58.2% Pass@1 on SWE-bench Lite against a 56.5% baseline.
