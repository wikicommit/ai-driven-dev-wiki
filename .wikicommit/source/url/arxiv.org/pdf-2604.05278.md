## Summary

An arXiv paper by Pardis Taghavi and Santosh Bhavani proposing that spec-driven workflows be augmented with phase-scoped context-grounding hooks — read-only repository probing before each stage, artifact validation after it — kept outside the generating agent's own prompt. Its main contribution to this wiki is the named failure mode it is built against, context blindness: intermediate artifacts that are internally coherent while being incompatible with the repository as it exists, which now has its own page. Its measured effect is modest and honestly reported: a 1–5 composite judged-quality score rising from 3.51 to 3.66 across 128 runs on 32 tasks in five repositories, with the authors themselves stating that the benefit is earlier detection of compounding errors rather than a large jump in average score, and with a 13-minute per-run runtime cost in the longer workflow family.

The Spec Kit Agents system itself did not get a separate SoftwareApplication page: it is a research prototype described in this one paper rather than a released product, so its design is recorded on the paper's page, and the Spec Kit page notes how the research builds on it.
