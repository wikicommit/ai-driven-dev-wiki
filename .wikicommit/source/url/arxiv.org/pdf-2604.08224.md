## Summary

A systems-level review arguing that recent progress in LLM agents comes less from changing model weights than from externalisation — relocating cognitive burdens from the model's internal computation into persistent, inspectable, reusable external structures. Drawing on Donald Norman's theory of cognitive artifacts, it treats memory as externalised state, skills as externalised procedural expertise and protocols as externalised interaction structure, with the harness as the runtime layer that coordinates all three. It traces a historical progression from weights to context to harness, sets out six analytical dimensions of harness design, and discusses the parametric-versus-externalised trade-off along with open questions in evaluation and governance.
