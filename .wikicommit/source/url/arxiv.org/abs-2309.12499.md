## Summary
The arXiv abstract page for CodePlan, which formulates software engineering activities that pervasively edit an entire repository - package migration, fixing static-analysis or test error reports, adding type annotations or other specifications - as repository-level coding tasks. The paper argues these cannot be solved directly by LLMs because repository code is inter-dependent and the repository may not fit in a prompt, and frames the problem as planning: CodePlan synthesizes a multi-step chain of edits combining incremental dependency analysis, change may-impact analysis and an adaptive planning algorithm. On package migration in C# and temporal code edits in Python, CodePlan is reported to get 5 of 6 repositories through validity checks where planning-free baselines get none.
