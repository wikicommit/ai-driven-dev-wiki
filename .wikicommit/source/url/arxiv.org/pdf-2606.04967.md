## Summary

A comparative study of six frameworks that add process to AI coding agents — GitHub Spec Kit, OpenSpec, BMAD Method, Get Shit Done (GSD), Spec Kitty and Reversa — selected by a declared functional inclusion criterion and a GitHub traction filter. Its central contribution is a six-dimension process taxonomy (specification, context, roles, execution, validation, portability) with a three-point scoring rubric, applied to the six frameworks and to an out-of-sample case, Spec-Flow. The comparison finds that no framework scores strongly on all six dimensions, exposing a structural trade-off between process depth and portability across agents.
