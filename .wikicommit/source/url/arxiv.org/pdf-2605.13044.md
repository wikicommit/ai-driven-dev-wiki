## Summary

A security paper by Ying Li, Hongbo Wen, Yanju Chen, Hanzhi Liu, Yuan Tian and Yu Feng introducing SEFZ, a goal-directed semantic fuzzer that finds what it calls specification violations — benign inputs causing an agent skill to breach the natural-language guardrails in its own specification, with no attacker involved. On 402 skills from the OpenClaw marketplace it found violations in 120 (29.9%), including 26 previously unknown exploitable cases in deployed skills. The finding with the widest implications for this wiki is that clear writing does not prevent the problem: 46 of the 120 violated skills had all their guardrails rated well-written by an independent LLM judge, and were violated anyway because terms like "critical domains" and "explicit approval" have no runtime meaning. Six recurring pitfalls are recorded, including the modality mismatch in which specifications assume either an interactive human or CI/CD automation while agent execution is a third case with no stdin but a reachable human.

SEFZ itself did not become a page: it is a research prototype described in this one paper rather than a released tool, so its mechanism is recorded on the paper's page.
