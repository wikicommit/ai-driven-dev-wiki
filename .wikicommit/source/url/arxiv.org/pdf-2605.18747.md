## Summary

This survey frames code as the harness of agentic AI systems, arguing that code is the operational substrate connecting a language model to reasoning, action, environment state and verification because it is executable, inspectable and stateful. It organises the field into three layers: the harness interface, harness mechanisms such as planning, memory, tool use, the Plan-Execute-Verify control loop and agentic harness engineering, and the scaling of harnesses to multi-agent orchestration over shared code. It surveys applications across coding assistants, GUI/OS agents, embodied agents, scientific discovery and personalisation, and sets out open problems in harness-level evaluation, semantic verification, regression-free self-evolution, transactional shared program state, human-in-the-loop safety and multimodal grounding.
