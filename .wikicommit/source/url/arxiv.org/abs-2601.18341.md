## Summary

This is the arXiv abstract page of "Agentic Much? Adoption of Coding Agents on GitHub", a software engineering paper that uses the explicit traces coding agents leave in repositories, such as co-authored commits and pull requests, to present the first large-scale study of their adoption across 128,018 GitHub projects. It estimates an adoption rate of 22.20% to 28.66% and finds adoption broad across project maturity, organizations, languages and topics, with agent-assisted commits larger than human-only ones and largely made up of features and bug fixes.
