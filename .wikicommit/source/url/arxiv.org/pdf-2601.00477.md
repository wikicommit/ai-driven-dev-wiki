## Summary

A University of Notre Dame empirical study of 33,596 agent-authored pull requests from the AIDev dataset, identifying 1,293 security-relevant ones (3.85%). Its most consequential figure for this wiki is the review-latency contrast — a median 3.92 hours for security-relevant agentic PRs against 0.11 hours for the rest — which was added to the verification bottleneck page because it changes the picture there: reviewers are triaging rather than applying uniform scrutiny, and the paper finds the triage tracks complexity and verbosity rather than security content.

No entities were excluded. The AIDev dataset is used as input rather than discussed as an independent subject, so it did not become a Dataset page; the five authors are named only as authors, so no Person pages were created.
