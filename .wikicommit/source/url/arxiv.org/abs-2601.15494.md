## Summary

An economics paper by Koren, Békés, Hinz and Lohmann that develops an equilibrium model of how vibe coding, in which AI agents assemble open-source software without users engaging with maintainers, affects the open-source ecosystem. It finds that vibe coding raises productivity but weakens the user engagement through which maintainers earn returns, so that when open source is monetized only through that engagement, wider adoption reduces the availability and quality of open-source software and lowers welfare. The authors conclude that sustaining open source at its current scale requires major changes in how maintainers are paid.
