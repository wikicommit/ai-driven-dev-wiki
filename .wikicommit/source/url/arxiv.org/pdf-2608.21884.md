## Summary
An exploratory study, under review for JAWs@ASE 2026, that situates loop engineering — designing systems that start coding-agent runs on a schedule or on repository events and stop them when a machine-checkable condition holds — one abstraction level above prompt, context and harness engineering, and consolidates the practitioner gray literature into a working definition, a set of building blocks and observations on its contested novelty and unverified value claims. It then mines 36,710 open-source repositories and confirms autonomous agent loops in 217 of 256 candidates, mostly pull-request review and scheduled issue triage started from GitHub Actions, finding that loop configuration is committed while the state files the discourse prescribes are almost never version-controlled. It closes by outlining a planned controlled experiment on agent autonomy levels.
