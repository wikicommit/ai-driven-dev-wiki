## Summary
A preprint introducing LoopsBench, a long-horizon benchmark for evaluating the loop engineering layer of coding agents. Each of its 112 tasks (from PR sequences, university course labs and research-paper evolutions) is a dependency DAG over separately testable development units, and a flow-aware runtime releases tests along the ready frontier while keeping completed units as regression obligations. Across frontier models and loop implementations the best configuration resolves 25.00% of tasks, recorded plans recover only part of the prerequisite DAG, and regression events appear in every evaluated loop profile.
