## Summary

An HKUST paper introducing LOCA-bench, which scales an agent's context by scaling the environment it must explore rather than the prompt it is given, so context length can be extended arbitrarily with task semantics held fixed. The benchmark got its own Dataset page; the context rot page gained the agentic reframing — that the core difficulty is "remaining organized and reliable at every action as the context grows" rather than finding evidence once — along with the reported degradation curve and the finding that context engineering strategies recover part of the loss but unevenly across models.
