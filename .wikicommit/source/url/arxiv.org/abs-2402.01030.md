## Summary
The arXiv abstract page for CodeAct, which proposes consolidating an LLM agent's actions into a unified action space of executable Python code instead of JSON or text in a pre-defined format, addressing what the authors describe as a constrained action space and an inability to compose multiple tools. Integrated with a Python interpreter, CodeAct executes code actions and dynamically revises prior actions or emits new ones upon new observations across multi-turn interactions. An analysis of 17 LLMs on API-Bank and a newly curated benchmark reports up to 20% higher success rate than widely used alternatives; the authors then collect CodeActInstruct, 7k multi-turn interactions, and finetune CodeActAgent from Llama2 and Mistral.
