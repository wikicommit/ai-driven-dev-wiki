## Summary
The arXiv abstract page for SWE-Pruner, a self-adaptive context pruning framework for coding agents in which the agent states an explicit goal for the current task and a lightweight 0.6B-parameter neural skimmer selects the relevant lines of context. The authors report 23-54% token reduction on agent tasks such as SWE-Bench Verified while even improving success rates, and up to 14.84x compression on single-turn tasks such as LongCodeQA with minimal performance impact.
