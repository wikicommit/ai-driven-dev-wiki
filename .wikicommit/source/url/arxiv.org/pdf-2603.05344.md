## Summary

This technical report documents OPENDEV, an open-source terminal-native AI coding agent, and the architectural decisions behind it. It describes a compound AI system with per-workflow model routing, an extended ReAct loop with separate thinking and self-critique phases, a five-layer defense-in-depth safety architecture, Adaptive Context Compaction, event-driven system reminders, and lazy MCP tool discovery. Five cross-cutting design tensions — context pressure, behavioral steering over long horizons, safety through architectural constraints, designing for approximate outputs, and bounded growth — are distilled into transferable lessons for builders of long-running agentic systems.
