## Summary

Describes BitsAI-CR, ByteDance's LLM-based automated code review system, which pairs a RuleChecker for issue detection with a ReviewFilter for verification over a taxonomy of 219 review rules and improves continuously through a data flywheel. It introduces the Outdated Rate metric for whether developers act on review comments, reporting 75.0% peak precision, a 26.7% Outdated Rate for Go and over 12,000 weekly active users.
