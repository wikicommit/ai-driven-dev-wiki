## Summary

The 2020 paper by Lewis and colleagues that introduced retrieval-augmented generation: a general-purpose fine-tuning recipe combining a pre-trained seq2seq model's parametric memory with a dense vector index of Wikipedia as non-parametric memory, retrieved by DPR and generated over by BART. It defines the RAG-Sequence and RAG-Token formulations, reports state-of-the-art results on three open-domain question answering tasks, argues that hybrid parametric/non-parametric models need far fewer trainable parameters, demonstrates that the non-parametric memory can be swapped to update knowledge, and records a retrieval-collapse failure mode it did not solve. It is included as the upstream origin of the retrieval machinery this wiki covers, not as software-engineering research.
