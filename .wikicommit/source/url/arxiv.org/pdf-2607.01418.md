## Summary

This Microsoft field study uses developer-level telemetry from tens of thousands of engineers during the company's early-2026 rollout of Claude Code and GitHub Copilot CLI to examine who adopts command-line AI coding agents, who keeps using them, and whether they increase merged pull requests. It finds that first use spread mainly through social networks, that retention was associated more with coding activity than demographics, and that adopters merged roughly 24% more pull requests than a synthetic counterfactual, with the lift persisting across the four-month window.
