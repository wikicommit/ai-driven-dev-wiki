## Summary

A survey of LLM-based code generation agents that screens 447 candidate papers down to 100 core papers spanning 2022 to June 2025, and characterises such agents by three features distinguishing them from earlier code generation techniques: autonomy, an expanded task scope covering the full software development lifecycle, and a shift of research emphasis from algorithmic innovation toward engineering practicality. It organises key techniques into single-agent methods (planning and reasoning, tool integration and retrieval enhancement, reflection and self-improvement) and multi-agent systems (workflows, context management and memory, collaborative optimisation), then reviews applications across the SDLC, evaluation benchmarks and metrics, and deployed tools grouped as co-pilot, collaborator and autonomous team. It closes with five dimensions of open challenges, including context engineering, error cascading in multi-agent systems, operational cost, trustworthiness and evaluation completeness.
