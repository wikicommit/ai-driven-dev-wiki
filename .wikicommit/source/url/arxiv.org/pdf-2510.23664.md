## Summary

This paper presents "Agentsway", a software development methodology designed for ecosystems in which autonomous AI agents operate as first-class collaborators. It positions a single human orchestrator alongside specialized Planning, Prompting, Coding, Testing, and Fine-Tuning agents, and adds a privacy-preserving retrospective learning loop in which fine-tuned LLMs are refined from each development cycle's prompts, code, and test feedback. The applicability of the method is demonstrated through a legal case handling automation use case, with the Planning Agent, Prompting Agent, and fine-tuning process each evaluated.
