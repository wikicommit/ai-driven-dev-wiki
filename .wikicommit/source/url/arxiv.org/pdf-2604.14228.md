## Summary

A source-level architectural study of Claude Code (v2.1.88, from a publicly available TypeScript extraction) that reads the tool as one set of answers to recurring design questions every production coding agent must settle: where reasoning lives relative to the harness, how the iteration loop is structured, what safety posture to adopt, how the extension surface is partitioned, how context is managed, how work is delegated, and how sessions persist. It traces five human values and thirteen design principles to concrete implementation choices - a simple while-loop agent core surrounded by a deny-first permission system with seven modes and an ML classifier, a five-layer compaction pipeline, four extension mechanisms ordered by context cost, isolated subagents returning summaries only, and mostly append-only JSONL session transcripts. It then contrasts those answers with two independent open-source systems, OpenClaw and Hermes Agent, and closes with six open directions, including the concern that the architecture offers limited mechanisms for preserving long-term developer understanding.
