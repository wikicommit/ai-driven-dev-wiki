## Summary

"AI IDEs or Autonomous Agents? Measuring the Impact of Coding Agents on Software Development" (Agarwal, He and Vasilescu; MSR '26) is a longitudinal causal study of coding-agent adoption in open-source GitHub repositories, using staggered difference-in-differences with propensity-matched controls on the AIDev dataset and defining adoption as a repository's first agent-generated pull request. Repositories where the agent was the first observable AI tool saw large, front-loaded velocity gains, while repositories with prior AI IDE usage saw minimal or short-lived ones. Quality risks were persistent in both groups, with static-analysis warnings rising by about 18% and cognitive complexity by about 39%, which the authors read as sustained agent-induced complexity debt.
