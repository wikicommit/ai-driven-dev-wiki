## Summary

An empirical comparison of traditional context-coupled Model Context Protocol (MCP) and Code Execution MCP (CE-MCP) agent architectures across efficiency, task quality, and security, using the MCP-Bench framework across 10 servers and three GPT-4 models. The paper reports CE-MCP significantly reduces token usage, execution time, and turns while maintaining comparable task quality, applies the MAESTRO framework to identify sixteen CE-MCP-specific attack classes across five execution phases, empirically validates four representative exploits, and proposes a three-stage defense-in-depth mitigation architecture.
