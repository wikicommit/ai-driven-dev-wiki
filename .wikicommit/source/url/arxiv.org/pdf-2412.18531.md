## Summary

An industrial case study at Beko of an LLM-based automated code review tool built on the open-source Qodo PR-Agent, analysing 4,335 pull requests across three projects alongside developer surveys. 73.8% of automated review comments were labelled resolved and most surveyed practitioners perceived a minor code-quality improvement, but average pull request closure time rose from 5 hours 52 minutes to 8 hours 20 minutes.
