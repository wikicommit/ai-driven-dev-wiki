## Summary

A framework proposal targeting two structural failure modes of AI-assisted development: context explosion, where an agent must reason over a whole repository and output quality degrades as the window fills, and silent spec-code drift, where code evolves while the specification does not. The Spec Growth Engine answers both with a machine-readable spec graph separating outward contract from inward design, a Spine assembler that scopes agent context to the ownership path plus one-hop dependency contracts, a two-layer hardest-first growth rule with a fixed invariant floor, and a drift gate comparing an intent graph against an evidence graph to block divergent merges. It presents itself as a lean synthesis of established software engineering ideas rather than a new paradigm, and reports no empirical evaluation.
