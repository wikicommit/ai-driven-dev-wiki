## Summary
A short early-results paper proposing an LLM-based multi-agent system for code review, made up of a Code Review Agent, Bug Report Agent, Code Smell Agent and Code Optimization Agent built with prompt-based instructions on GPT-4 and coordinated through a shared component. It reports qualitatively that the agents produced logical, actionable feedback on bugs, code smells and optimizations, and plans an empirical evaluation and an extension toward detecting many kinds of technical debt.
