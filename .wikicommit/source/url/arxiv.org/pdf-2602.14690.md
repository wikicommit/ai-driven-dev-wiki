## Summary

"Harness Engineering for Agentic AI Coding Tools: An Exploratory Study" (Galster et al.; an extended version of an AIware 2026 paper) documents eight repository-level configuration mechanisms — Context Files, Skills, Subagents, Commands, Rules, Settings, Hooks and MCP servers — across Claude Code, GitHub Copilot, Cursor, Gemini CLI and Codex CLI, and measures their adoption in 2,853 engineered open-source GitHub repositories. Context Files dominate and are often the only mechanism present, with AGENTS.md emerging bottom-up as a tool-agnostic standard, while Skills and Subagents are rarely adopted and Skills mostly carry static instructions rather than executable scripts. The authors conclude that harness engineering in open source today is mostly context engineering, and position their results as an early empirical baseline.
