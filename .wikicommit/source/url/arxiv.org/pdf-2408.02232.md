## Summary
The paper proposing SpecRover, an LLM agent from the National University of Singapore built on AutoCodeRover, that resolves GitHub issues through iterative specification inference: while searching the codebase it writes natural-language function summaries of each function's intended behavior, and a reviewer agent reconciles the issue statement, a generated reproducer test and candidate patches, giving feedback and explanations, with a selection agent choosing among patches rejected by regression tests. It reports resolving 19.31% of the full SWE-bench and 31% of SWE-bench Lite at an average cost of $0.65 per Lite issue, a reviewer-accepted patch precision of 50%, and demonstrates the approach on a Linux kernel vulnerability from DARPA's AI Cyber Challenge.
