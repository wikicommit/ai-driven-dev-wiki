## Summary

This paper studies how the information fields in tool documentation affect LLM agents, finding across 14 tool-use datasets that field composition is heterogeneous and that the effect of adding or removing a field varies with task domain, LLM backbone, and agent paradigm. On that basis it proposes DocsChisel, which diagnoses a target agent's failed execution traces and iteratively adds, removes, or refines documentation fields per tool with domain-level memories. On 74 tools from WorkBench and API-Bank it reports an average 95.89% task-success improvement over the original documentation and 75.15% over the EASYTOOL and DRAFT baselines.
