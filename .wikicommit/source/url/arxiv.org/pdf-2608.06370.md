## Summary

This paper compares programmatic tool calling, in which the model writes a Python script against typed tool stubs that is executed in a single agent turn, with native JSON tool calling across 14 models on a 309-entry subset of BFCL v4 and three ablations on chaining, parallel fan-out, and context flooding. Programmatic tool calling matched or exceeded JSON tool calling in 11 of 14 models, with the split following model generation rather than model family, and it held stable under flooding with decoy schemas. It also removed the extra inference turn per chaining step and avoided the fan-out limit at which JSON tool calling began dropping calls for Claude Sonnet 5.
