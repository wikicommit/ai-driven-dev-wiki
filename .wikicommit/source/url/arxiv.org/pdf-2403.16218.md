## Summary
The paper introducing CoverUp, an approach and tool that generates high-coverage Python regression tests by prompting an LLM with code segments annotated with their missing line and branch coverage, offering a get_info tool function for more code context, and continuing the chat when generated tests fail or do not raise coverage. Against CodaMosa it reports per-module median line+branch coverage of 80% vs. 47%, against MuTAP overall line+branch coverage of 89% vs. 77%, and ablations showing that coverage information, code context and error fixing each contribute.
