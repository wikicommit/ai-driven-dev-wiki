## Summary

This Stanford preprint introduces SWE-chat, a continually growing dataset of real coding-agent sessions collected from public GitHub repositories whose developers opted into Entire.io's session logging, with full tool-call traces and line-level human-versus-agent code attribution (about 6,000 sessions, 63,000 user prompts and 355,000 tool calls at the time of writing). Using it, the authors characterize real-world usage: code authorship is bimodal, with agents writing virtually all committed code in 41% of sessions ("vibe coding") and humans writing all of it in 23%, understanding existing code is the most common specific intent, and only 44% of agent-produced code survives into commits. They also report that vibe-coded commits introduce more security vulnerabilities per line than human-written or collaborative code, and that agents rarely stop to ask for clarification while users frequently interrupt and push back.
