## Summary

This paper studies 1.02 million reviewed pull requests from 207 GitHub projects that transition across three code review eras — human-centric review, LLM-assisted review, and agentic code review — and identifies three AI reviewer adoption practices. Modelling review discussions as reviewer interaction sequences, it finds that agent-involved collaboration patterns are associated with faster review decisions under two of those adoption practices. It reports that these efficiency gains do not translate into better review quality.
