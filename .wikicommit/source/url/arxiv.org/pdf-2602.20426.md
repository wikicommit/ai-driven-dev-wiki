## Summary

"Learning to Rewrite Tool Descriptions for Reliable LLM-Agent Tool Use" (Intuit AI Research; preprint under review) argues that the quality of tool descriptions, not only the agent, limits LLM tool-use performance, and proposes Trace-Free+, a curriculum-learning framework that fine-tunes a small model to rewrite tool descriptions from the tool schema alone, moving training from trace-based examples to trace-free ones. On StableToolBench, RestBench and BFCLv2, with all test tools unseen in training, the rewritten descriptions improved multi-step query success, degraded less as candidate tool sets grew past 150, transferred across domains and agent models, and added gains on top of agent fine-tuning. The authors note it does not beat simpler guideline-based rewriting on single-step queries and may hallucinate constraints for unfamiliar APIs.
