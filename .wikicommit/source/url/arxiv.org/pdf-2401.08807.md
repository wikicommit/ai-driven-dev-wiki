## Summary
The full text of a paper introducing SpecGen, an LLM-based technique for generating formal Java (JML) program specifications in two phases: a conversation-driven phase that feeds verifier failure messages back to the LLM, and a mutation-based phase that applies four kinds of mutation operators to failed specifications and picks verifiable variants with a weighted heuristic selection strategy. Evaluated on the SV-COMP Java benchmark and the authors' SpecGenBench dataset, it generated verifiable specifications for 279 of 385 programs, more than AutoSpec, Houdini and Daikon.
