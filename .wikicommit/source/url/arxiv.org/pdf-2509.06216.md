## Summary

This paper proposes Structured Agentic Software Engineering (SASE), a framework for the Agentic Software Engineering (SE3.0) era that reimagines software engineering's actors, processes, tools, and artifacts around a duality between SE for Humans and SE for Agents. It introduces two dedicated workbenches (the Agent Command Environment and the Agent Execution Environment), a set of version-controlled artifacts (BriefingScript, LoopScript, MentorScript, Consultation Request Pack, Merge-Readiness Pack, Version Controlled Resolution), five named engineering activities, and a six-level agency/autonomy hierarchy (SE1.0-SE5.0), grounding its argument in a worked example of a developer orchestrating an agent team and closing with a research roadmap for the field.
