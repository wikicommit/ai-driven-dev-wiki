## Summary

This paper by Hassan and colleagues presents Structured Agentic Software Engineering (SASE), a conceptual framework for what it calls the Agentic SE (SE 3.0) era, built around a duality between SE for Humans and SE for Agents. It proposes two purpose-built workbenches — the Agent Command Environment and the Agent Execution Environment — together with a set of version-controlled artifacts (BriefingScript, LoopScript, MentorScript, Consultation Request Packs, Merge-Readiness Packs) intended to turn ad-hoc agentic coding into a disciplined engineering practice. It closes with a research roadmap and a hierarchical framework of AI autonomy in SE running from manual coding (SE 1.0) to general domain autonomy (SE 5.0).
