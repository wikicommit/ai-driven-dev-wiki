## Summary

A survey that examines LLM-based agents through a model–harness lens, arguing that agent quality — success, efficiency, safety and generalization — emerges from the interaction between model capability, runtime infrastructure, task structure and evaluation design rather than from model capability alone. It traces four paradigms of agent engineering (prompt engineering; workflows and context engineering; harness engineering; agent-native training with co-evolution) and decomposes the execution harness into six coupled runtime responsibilities: observation interface, context manager, control loop, action interface, state and artifact store, and verification and governance. It maps task properties and domain pressures to harness configurations and synthesizes benchmark evidence from SWE-bench Verified, Terminal-Bench 2.0 and WebArena on how runtime design affects measured performance.
