## Summary

A January 2026 preprint (arXiv:2601.20106) presenting what it calls the first empirical study of how core and peripheral developers use coding agents, based on 9,427 agentic pull requests. It reports that some peripheral developers delegate more often and more evenly across task types, that core developers concentrate on documentation and testing and see their agentic PRs merged frequently, and that peripheral developers are more likely to merge without running CI checks while core developers more consistently require passing verification.
