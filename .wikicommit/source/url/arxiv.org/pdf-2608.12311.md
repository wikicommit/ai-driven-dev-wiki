## Summary

This exploratory case study proposes the Role Specialization Model (RSM), a framework that assigns distinct roles to several LLM-based tools in one development workflow — Antigravity as Architect, Gemini CLI as Analyst and a locally run Qwen Code as Specialist — under a human orchestrator, and applies it to building a Python climate-data visualization application. It documents the workflow, a deviation in which Gemini CLI took over a refactoring task planned for Qwen Code, prompt hardening with explicit negative constraints, and a qualitative ISO/IEC 25010 assessment, concluding that explicit role coordination can help but needs scope boundaries, context management and human verification of agent output.
