## Summary

This paper from Cairo University proposes ACEM (Agentic Cost Estimation Model), which decomposes the cost of agentic software development into three additive dimensions — LLM token cost, human-in-the-loop (HITL) oversight cost and infrastructure cost — on the grounds that traditional models such as COCOMO II, Function Points and Story Points assume effort is a function of human labor. It introduces a Revision Factor for retry overhead, a Context Factor for context growth and a four-level HITL Intensity Score, and maps Use Case Points, Story Points and Function Points to token consumption; the author presents it as an early-stage proposal whose constants are symbolic and which has not yet been validated against real project data.
