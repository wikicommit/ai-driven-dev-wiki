## Summary

"OpenHands: An Open Platform for AI Software Developers as Generalist Agents" (Wang, Li, Song, Xu, et al.; arXiv:2407.16741, accepted at ICLR 2025) introduces OpenHands, formerly OpenDevin, a platform for building AI agents that interact with the world as a human developer does — writing code, using a command line and browsing the web. It supports implementing new agents, safe interaction with sandboxed environments for code execution, coordination between multiple agents, and incorporation of evaluation benchmarks, and reports an evaluation of agents over 15 challenging tasks. OpenHands is released under the MIT license as a community project with more than 2.1K contributions from over 188 contributors.
