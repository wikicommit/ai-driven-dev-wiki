## Summary

"Magentic-UI: Towards Human-in-the-loop Agentic Systems" (Mozannar, Bansal, Tan, Fourney, et al.; Microsoft Research AI Frontiers) introduces Magentic-UI, an open-source, human-in-the-loop web interface built on an extensible multi-agent system, offering six interaction mechanisms (co-planning, co-tasking, action approval, answer verification, memory, multi-tasking), and reports results from autonomous benchmark evaluation, simulated-user testing, qualitative user studies, and targeted adversarial safety testing.
