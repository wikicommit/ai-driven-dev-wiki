## Summary
The arXiv abstract page for Reflexion, a framework that reinforces language agents through linguistic feedback rather than weight updates: agents verbally reflect on task feedback signals and keep that reflective text in an episodic memory buffer to make better decisions in later trials. The authors report significant improvements over a baseline agent across sequential decision-making, coding and language reasoning tasks, including 91% pass@1 on the HumanEval coding benchmark against 80% for GPT-4.
