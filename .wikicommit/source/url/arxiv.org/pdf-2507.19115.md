## Summary
An experience report from Ericsson describing a lightweight automated code review tool that combines open-source LLMs (Llama 2 and Code Llama) with static program analysis: it pulls changes from Gerrit, uses Tree-Sitter to extract the Java method enclosing each changed line, and prompts the LLM with the diff plus that enclosing method, without pre-training or fine-tuning. A survey-based evaluation with experienced Ericsson developers found mixed but encouraging results — Code Llama 13B was preferred in pairwise comparisons, and in a fifteen-day trial four of nine developers said the tool saved them time, while common complaints were reviews that merely explained the code, were factually wrong, or focused on irrelevant areas.
