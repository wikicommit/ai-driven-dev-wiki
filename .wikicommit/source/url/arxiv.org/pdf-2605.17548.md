## Summary

A vision paper arguing that AI-assisted development has made code review the primary control surface for the quality and accountability of generated code, not merely a productivity bottleneck. It diagnoses existing AI review tooling as fragmented across isolated stages that do not compose, and proposes an end-to-end agentic workflow spanning PR Creation, PR Augmentation, Reviewer Selection, AI-Assisted Code Review and PR Retrospective, with human-controlled quality gates and a diff-map that anchors every reviewer-visible claim to its source location and originating report. It catalogues its own risks candidly, including accumulated error across agent stages, automation bias undermining the human gates, and the erosion of implicit mentoring. The framework is proposed, not implemented or evaluated.
