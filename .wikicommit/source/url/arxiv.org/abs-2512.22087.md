## Summary
The arXiv abstract page for CAT (Context as a Tool), a context-management paradigm for long-horizon software engineering agents that makes context maintenance a callable tool within the agent's decision-making, over a structured workspace of stable task semantics, condensed long-term memory and high-fidelity short-term interactions. The authors also propose a trajectory-level supervision framework, CAT-GENERATOR, use it to train a model called SWE-Compressor, and report a 57.6% solved rate on SWE-Bench-Verified.
