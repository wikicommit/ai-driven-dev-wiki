## Summary

Introduces AIDev, a dataset of 456,535 pull requests authored by five autonomous coding agents (OpenAI Codex, Devin, GitHub Copilot, Cursor and Claude Code) across 61,453 GitHub repositories, framing these agents as the AI teammates of SE 3.0. Case studies on a popular-repository subset find that agent-authored pull requests are accepted less often than human ones, are reviewed at speeds that differ by agent, and tend to be structurally simpler, and the paper proposes nine research directions.
