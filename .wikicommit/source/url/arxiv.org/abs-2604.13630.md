## Summary
The arXiv abstract page for SafeHarness, a security architecture for LLM agent deployment that treats the execution harness (the layer orchestrating tool use, context management and state persistence) as a high-value attack surface. It weaves four defense layers into the agent lifecycle (adversarial context filtering, tiered causal verification, privilege-separated tool control, and safe rollback with adaptive degradation) and reports average reductions of roughly 38% in unsafe behavior rate and 42% in attack success rate against an unprotected baseline while preserving task utility.
