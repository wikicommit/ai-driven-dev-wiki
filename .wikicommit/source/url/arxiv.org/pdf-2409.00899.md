## Summary
A ByteDance report introducing MarsCode Agent, an LLM-based framework for automated bug fixing that combines a multi-agent collaborative framework (Searcher, Planner, Reproducer, Programmer, Tester and Editor) with code indexing through a code knowledge graph and the language server protocol, a conflict-marker-style code edit tool called AutoDiff, and LSP-based static code diagnostics. The Planner routes each issue to either a dynamic debugging workflow run in a Docker sandbox or a static repair workflow that votes among multiple candidate patches. On SWE-bench Lite the report states that MarsCode Agent resolved 102 of 300 instances (34%) and located the files to modify in 88.3% of instances.
