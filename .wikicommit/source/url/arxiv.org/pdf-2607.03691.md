## Summary

A Queen's University controlled longitudinal study that inverts the usual experimental setup — fixing the language model and varying only the agent harness across 35 sequential Qwen Code CLI releases evaluated on 50 stratified SWE-bench Verified tasks. Its central negative result is that there is no statistically significant improvement in resolve rate across those releases while token consumption and tool calls roughly double. The agent harness page gained the harness-as-evolving-software framing and the hyper-churn measurements; the harness engineering page gained this as controlled evidence for its premise together with the warning attached to it, and the paper's proposed missing practice of agentic quality assurance.

No entities were excluded. Qwen Code CLI and the other four harnesses studied are named as measurement subjects with no independent description of what they are, so no SoftwareApplication pages were created for them; the four authors are named only as authors, so no Person pages were created.
