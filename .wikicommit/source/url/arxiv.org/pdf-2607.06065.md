## Summary

An arXiv preprint introducing SWE-Review, a framework that closes the issue-resolution loop by having a reviewer agent explore the repository, decide whether an AI-generated pull request should be accepted, and produce structured feedback for revision. It contributes SWE-Review-Bench, a benchmark of 1,384 candidate pull requests drawn from 500 SWE-bench Verified issues across three PR generators, and SWE-Review-Traj, a dataset of 8,914 agentic review trajectories for training open reviewers. Experiments report that an iterative generate-review-revise loop raises resolve rates substantially, that agentic review beats single-turn fixed-context review on both decision accuracy and resolve rate after revision, and that review trajectories also improve issue-resolution models and enable test-time scaling.
