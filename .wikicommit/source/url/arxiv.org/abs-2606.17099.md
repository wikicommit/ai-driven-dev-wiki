## Summary

This arXiv paper reports a controlled pilot study of explicit software delegation contracts for AI coding agents, running 64 agent executions on ten seeded TypeScript API tasks under an issue-style prompt, an explicit contract, and a contract with a required evidence bundle, with 192 condition-blinded model-based reviews. Contracts did not change objective outcomes, since every run passed the hidden acceptance checks, but they improved reviewability, notably evidence sufficiency and reviewer ambiguity, at a cost of 13% more agent tokens and 38% more wall-clock time.
