## Summary
A large multi-institution survey and practical guide to code intelligence that traces code LLMs across their whole lifecycle — general and code-specialized foundation models and their pre-training data, coding tasks, benchmarks and evaluation metrics, alignment through supervised fine-tuning and reinforcement learning with verifiable rewards, software engineering agents across the development lifecycle, code as the medium for generalist agents, the safety of code LLMs, and deployed applications such as IDE assistants, cloud platforms, terminal agents, repair tools and pull-request reviewers. It also reports the authors' own experiments, including per-language scaling laws for code pre-training, comparisons of fine-tuning frameworks, hyperparameters, dense versus mixture-of-experts backbones and datasets, and ablations of advantage estimators, response length and rollouts per prompt for reinforcement learning on code.
