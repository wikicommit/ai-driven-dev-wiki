## Summary

An ESEM 2026 empirical study that links AI-authored GitHub pull requests with AI-attributed review events to characterize "closed-loop" AI review, in which one coding agent reviews another coding agent's contribution. Built by applying a two-tier signature attribution method to CodAGE, a public dataset of coding-agent GitHub events, it identifies 248,641 agent-authored PRs that received at least one AI review — 45,269 of them reviewed by a different product — and reports that this activity grew by more than two orders of magnitude from 2025-Q1 to 2025-Q3 while remaining about 1.6% of identified agent-authored PRs. Holding CodeRabbit constant as the reviewer, it finds the comment-category mix varies by authoring agent (35.0% refactor comments on Claude Code PRs against 10.5% on Copilot PRs), and reports higher per-PR comment volume and longer first-review latency for same-product pairs, while cautioning throughout that the differences are observational and may reflect reviewer composition rather than product pairing.
