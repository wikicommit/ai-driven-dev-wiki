## Summary

A proposal paper by Xinyu Zhang and Weiwei Sun of Fudan University for Knowledge-Based Pull Requests, a workflow for collaboration across a trust boundary in which an external contributor's code, tests and cleaned agent trace become knowledge sources rather than the merge candidate, with mergeable code regenerated inside the receiving project by a project-owned agent under its own policy. Its premise is that coding agents have moved the bottleneck — code is cheap while understanding intent, negotiating scope and governing project responsibility remain costly — and its governance claim is that this separates two decisions traditional pull requests collapse: whether the knowledge should enter the project, and whether a particular implementation should be merged. The paper is careful to disclaim novelty for the individual capabilities, to call its cost model a hypothesis rather than a property, and to label its seven-PR pilot an instrumentation check that does not involve project maintainers.
