## Summary

A personal blog post dated 28 August 2025 on guangzhengli.com arguing that "vibe coding" has become a catch-all label and should be reserved for the sense in Andrej Karpathy's original post — programming purely through conversation with an LLM without reading the code — while ordinary AI-assisted programming is better called Context Coding, because its progress beyond model capability comes from better context engineering. The author traces that progress through GitHub Copilot's open-window context, Cursor's RAG-based codebase indexing and Claude Code's grep-style retrieval, and draws practical advice on supplying context through instruction files, coding conventions, up-to-date documentation and debug logging. The post closes by arguing that vibe coding by people without programming experience accumulates defects and technical debt, while predicting that AI will erode demand for average programmers and favour small teams and independent developers.
