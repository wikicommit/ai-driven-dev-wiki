## Summary

A Google Codelabs tutorial, the second in a "Building AI Agents with ADK" series, that adds tools to a personal-assistant agent built with Google's Agent Development Kit. It introduces ADK's three tool categories — function tools, built-in tools and third-party tools — and walks through wrapping a Python function as a FunctionTool, wrapping a Google Search specialist agent as an AgentTool so the root agent acts as a router, and integrating LangChain's Wikipedia tool.
