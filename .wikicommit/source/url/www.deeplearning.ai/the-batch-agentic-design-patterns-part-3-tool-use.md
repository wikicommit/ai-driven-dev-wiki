## Summary

A letter in DeepLearning.AI's The Batch (3 April 2024), the third in a series on agentic design patterns, describing Tool Use as a key design pattern of AI agentic workflows in which an LLM is given functions it can request to call. It explains the mechanism with web-search and code-execution examples, notes that systems may give an LLM access to hundreds of tools and select a relevant subset for context, traces early tool-use work to the computer-vision community and GPT-4's function calling, and recommends three papers for further reading.
