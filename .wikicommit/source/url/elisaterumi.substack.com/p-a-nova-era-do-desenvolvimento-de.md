## Summary

A Portuguese-language Substack post (July 2026) arguing that AI has moved the developer's value from writing code to technical judgement, and tracing a path from vibe coding — describing what you want and pasting errors back into the chat, which it finds productive for prototypes but insufficient for production — to agentic engineering, in which developers design the environment of documentation, rules, tools, sandboxes, tests and pipelines that agents work within. It covers the "agent = model + harness" framing, context engineering's balance of static and dynamic context, the conductor and orchestrator modes of working, and the cost trade-off between the two approaches, and states that it was inspired by the ideas in a document on the new SDLC with vibe coding by three authors from Google.
