## Summary

OpenAI's API guide to function calling (also called tool calling), which explains how models request calls to application-defined tools, the five-step tool calling flow, and how to define, handle and return results for function tools. It also covers namespaces, tool search for deferring rarely used tools, best practices for function definitions, tool choice, parallel calls, strict mode, streaming, and custom tools constrained by context-free grammars.
