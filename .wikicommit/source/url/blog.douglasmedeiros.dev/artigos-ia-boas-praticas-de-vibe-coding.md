## Summary
A Portuguese-language essay by a software engineer arguing that AI coding agents have moved the development bottleneck from writing code to validating it, putting the developer back in the position of an "ivory tower" architect who, unlike the old model, still reviews the implementation. It treats vibe coding, taken seriously, as this cycle of specifying, handing execution to the model and validating the result, and sets out the author's practices for doing it well: production basics such as observability, instruction files as a floor rather than a ceiling, paying for the stronger model, planning in Markdown before coding, strict automated guardrails including mutation testing, automated end-to-end tests, review by decision rather than by line, and a human stopping criterion against endless over-engineering.
