Qodo is the company behind [[SoftwareApplication/pr-agent]], the open-source pull-request
review agent it built and subsequently donated to the open-source community. Its own product
is an AI code review platform, offered with a free version for open-source projects and
integrating with GitHub, GitLab, Bitbucket and Azure DevOps.

What is known here comes from PR-Agent's own README, so it describes the company as seen
from that project rather than in the round.

## History

The README records one transition. Qodo Merge — which it labels Qodo 1.0 — was the hosted,
enterprise version of PR-Agent; it has since been rebranded and developed into Qodo, labelled
Qodo 2.0, a full AI code review platform. Alongside that, the open-source PR-Agent project
was handed to the community: it now lives in its own PR-Agent GitHub organization, is described
as fully community-owned, and its documentation moved to docs.pr-agent.ai. The README frames the
release as a community contribution from Qodo and calls the company the origin of modern
AI-powered code collaboration — an epithet from the project's own README, not an outside
assessment.

## Activities & Products

The company's current offering is positioned in the README as distinct from, and more capable
than, the donated open-source project: a feature-rich, context-aware code review experience,
against PR-Agent's description of itself as a community-maintained legacy project. Qodo
is listed as PR-Agent's gold sponsor, under a heading stating that the project's ongoing
development is supported by its sponsors, and offers a free
version of its own product to open-source projects.
