GitHub is the developer platform whose primitives — Git hosting, pull requests and GitHub Actions —
underpin much of the tooling this wiki covers, and the publisher of
[[SoftwareApplication/github-copilot]] and [[SoftwareApplication/github-copilot-coding-agent]]. In
its own account of its history it describes itself as having repeatedly addressed systemic problems
in how software gets built: making Git accessible, making code review systematic through pull
requests, and automating deployment with Actions.

As of its Universe 2025 announcement GitHub reported 180 million developers on the platform and
described itself as growing at its fastest rate ever, with a new developer joining every second and
80% of new developers using Copilot in their first week. These are GitHub's own figures, published
in a product announcement.

## Activities & Products

GitHub's agentic products are built on the platform primitives rather than beside them.
[[SoftwareApplication/github-copilot-coding-agent]] runs on GitHub Actions and delivers its work as
a draft pull request; [[SoftwareApplication/agent-hq]] extends the same flow to coding agents from
other vendors while keeping Git, pull requests, issues and Actions as the working surface. GitHub
describes Actions, introduced in 2018, as the largest CI/CD ecosystem in the world, with more than
25,000 actions in the GitHub Marketplace and more than 40 million jobs executed daily across
GitHub-hosted and self-hosted runners.
