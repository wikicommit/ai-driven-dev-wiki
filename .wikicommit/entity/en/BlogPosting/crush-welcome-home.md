This post by Christian Rocha on the blog of [[Organization/charm]] announces that
[[SoftwareApplication/crush]], a terminal-based AI coding agent, has "come home" to Charm. Its subtitle
sums up the framing: "We made the command line glamorous. Now we're making it intelligent."

The post tells how Crush's original creator, Kujtim Hoxha, built the agent in Go on the core of the Charm
stack, how the Charm team took notice, and how the project now continues with its original creator and
the full support of the Charm team. The rest of the post argues why the moment and the terminal are right
for AI-powered development tools.

## Key Points

- Crush was built on Charm's Bubble Tea, Bubbles, Lip Gloss and Glamour libraries, which the post says
  Charm had been building and refining for the previous five years.
- The post argues that LLMs have crossed from impressive demos to genuinely useful tools that can handle
  complex, multi-file reasoning; as an example, the author says he built a GLSL shader for the website's
  background effect with Crush in a few minutes, a task he says would otherwise have taken hours.
- It holds that powerful AI is only half the equation, and that the right interface for it is the
  terminal: developers already work there, and it is fast, scriptable and integrates with existing
  workflows.
- On this account Crush can directly use the same tools a developer can, such as git, docker, npm, ghc,
  sed and nix.
- The post introduces Ultraviolet, Charm's next-generation terminal UI toolkit, as the company "doubling
  down" on terminal applications.
- It closes on Charm's community — over 150,000 GitHub stars and more than 11,000 GitHub followers — and
  the claim that "glamorous software is a force multiplier".

## Context

The post is a company announcement written by Charm's founder, and its arguments for the terminal as the
home of AI coding tools are the company's own position. It says nothing about how Crush compares with
other coding agents or how it works internally beyond the libraries it is built on.
