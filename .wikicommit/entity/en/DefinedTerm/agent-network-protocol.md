The Agent Network Protocol (ANP) is an agent communication protocol that supports open-network agent discovery and secure collaboration between agents, using W3C decentralized identifiers (DIDs) and JSON-LD graphs.

## Usage

[[ScholarlyArticle/a-survey-of-agent-interoperability-protocols]] treats ANP as one of four emerging protocols for interoperability between LLM-powered agents, alongside [[DefinedTerm/model-context-protocol]], [[DefinedTerm/agent-communication-protocol]] and [[DefinedTerm/agent2agent-protocol]]. It places ANP at the last stage of the phased adoption roadmap it proposes: after MCP for tool access, ACP for messaging and A2A for collaborative task execution, adoption extends to ANP for decentralized agent marketplaces.
