Boris Cherny leads [[SoftwareApplication/claude-code]] at [[Organization/anthropic]]. He is recorded here as the public source for how much of Claude Code is written by Claude Code itself — a figure [[Person/kevin-ryan]] uses in [[Book/spec-driven-development-ai-native-software-engineering]] as evidence that the recursive loop has closed.

## Background

In May 2025 Cherny reported that roughly 80% of Claude Code was written by Claude Code. On 7 March 2026 he posted publicly: "Can confirm Claude Code is 100% written by Claude Code." Ryan reads the progression — eighty to one hundred percent in ten months — as showing that the people who build the models are running their own development this way, which shifts the question from whether the approach is viable to what is stopping everyone else. A separate figure for the intervening period comes from a different party: Ryan reports that by October, Dario Amodei told Marc Benioff the number was above 90%.
