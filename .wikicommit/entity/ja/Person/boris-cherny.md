Boris Cherny は [[Organization/anthropic]] において [[SoftwareApplication/claude-code]] を率いている。本ページに収録しているのは、Claude Code のどれだけが Claude Code 自身によって書かれているかについての公開された出所としてである。この数字は [[Person/kevin-ryan]] が [[Book/spec-driven-development-ai-native-software-engineering]] において、再帰的なループが閉じたことの証拠として用いている。

## 経歴

2025年5月、Cherny は Claude Code のおよそ 80% が Claude Code によって書かれていると報告した。2026年3月7日には公開の場で「Claude Code は 100% Claude Code によって書かれていると断言できる」と投稿した。Ryan はこの推移——10か月で 80 パーセントから 100 パーセントへ——を、モデルを作る当人たちが自分たちの開発をこのやり方で回していることを示すものと読み、問いをこのアプローチが実行可能かどうかから、他の全員を止めているものは何かへと移している。その間の時期についての別の数字は別筋から来ている。Ryan は、10月までに Dario Amodei が Marc Benioff にその数字は 90% を超えていると語ったと報告している。
