Addy Osmani はエンジニアリングおよびエバンジェリズムのリーダーであり、Google に14年以上在籍して Chrome、そして近年は AI——Gemini、コーディングエージェント、エージェンティックエンジニアリング——にわたる開発者体験を率いてきた。直近の肩書きは Google Cloud AI のディレクターである。addyosmani.com でエージェンティックコーディングの実践について公開しており、同じ題材について業界のイベントで講演もしている。

## 経歴

ここで利用できる出典は、年譜というよりも彼の役職と在籍期間を述べている。Google に14年以上、Chrome にわたる開発者体験、そして近年は AI とコーディングエージェントへの注力、直近の役職として Google Cloud AI のディレクターが挙げられている。

## 業績

2026年3月の O'Reilly AI CodeCon で "The Code Agent Orchestra" を発表し、その講演の文章版を [[BlogPosting/the-code-agent-orchestra]] として公開した。そこではマルチエージェントの協調パターン、オーケストレーションのツーリング、エージェント出力に対する品質ゲートが扱われている。彼はまた、AI 支援およびエージェンティックエンジニアリングについての O'Reilly の書籍 *Beyond Vibe Coding* の著者でもある。

彼は [[SoftwareApplication/addyosmani-agent-skills]] を維持している。これは開発ライフサイクル全体にわたるシニアエンジニアリングのワークフローと検証要件をコード化した24個の Agent Skills からなるオープンソースのパックであり、このスナップショット時点で 88.8k のスターを示している。
