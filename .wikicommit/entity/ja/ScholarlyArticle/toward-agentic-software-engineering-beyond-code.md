Monash University の Rashina Hoda によるビジョン論文であり、International Conference on Software Engineering（ICSE）2026 の AGENT ワークショップに採択された。その論旨は、[[DefinedTerm/agentic-software-engineering]] の初期のビジョンがほぼ全面的にコードに関わる活動——コード生成、レビュー、デバッグ、修復、設定——に集中しており、要件工学、設計、運用、そして導入、チームワーク、マネジメント、ワークフローへの統合といった実践的な関心が扱われないまま残されている、というものである。

本論文が掲げる立場は、エージェンティック SE が単なるコーディングの加速装置ではなく次のプロセスレベルのパラダイム転換となるためには、そのスコープが SE のライフサイクル全体にわたる社会技術的な活動、成果物、役割、関心の全域へ広がらなければならない、というものだ。エージェントとマルチエージェントシステムのために刷新された従来のものに加え、人間とエージェントのエコシステムを機能させるために必要な新しいものも含まれる。論文はこれを SE 自身の歴史のレビューに根拠づけ、ウォーターフォールからアジャイルに至るまで、これまでのあらゆる SE のプロセスモデルが「プロセス全体」のアプローチを備えていたことを指摘する。

## 主な貢献

- **エージェンティック SE のための「プロセス全体」のビジョン**。決定版のプロセスモデルではなく暫定的な「最初の一瞥」として明示的に提示されている。人間による統制のもとでさまざまなレベルの AI のエージェンシーを持つ人間とエージェントのアクターによって反復的に取り組まれる5つの高レベルの領域にまたがる。すなわち、エージェンティック SE の倫理的アラインメント（最初に、かつ中心に置かれる）、エージェンティック要件工学、エージェンティック設計、エージェンティック開発、エージェンティック運用である。
- **CRAFT の価値と原則**——5つの価値それぞれに2つの原則を伴う暫定案であり、コミュニティの対話を喚起するために提示されている。価値は Comprehensive（プロセス全体のアプローチ、人間・エージェント・社会技術の各側面）、Responsible（倫理バイデザイン、持続可能性）、Adaptive（産業上の関連性、社会技術的な関連性）、Foundational（コーディングを超えた基礎的な知識と解）、そして Translational（認知と教育、実行可能なガイドライン）である。
- **エージェンティック SE の語彙についての指針**。まだ緒に就いたばかりの分野においてすでに用語のドリフトと不一致が見て取れるという観察に動機づけられている。エージェンティック AI ソフトウェアエンジニア対 AI ソフトウェアエンジニア対エージェンティックソフトウェアエンジニアのような統語的なものもあれば、より深い意味論的・哲学的な問題を反映するものもある。用語を設計するために5つの考慮点——関連性、網羅性、受容、一貫性、哲学的整合——が提案されている。
