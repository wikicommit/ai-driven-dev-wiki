「From Industry Claims to Empirical Reality」は、GitHub のプルリクエストにおける [[DefinedTerm/code-review-agent]] の有効性についての実証研究であり、リオデジャネイロで開催された第23回国際ソフトウェアリポジトリマイニング会議（MSR '26）で発表された。著者たちはケネソー州立大学と Quanta Technology に所属する。同論文は自らを明示的にベンダーの主張に対置している。オープンソースのリポジトリにおいてコードレビューエージェントは人間の関与なしにプルリクエストの 80% を処理できるという業界の立場から始め、実証的な記録がそれを支持するのかを問うのである。

手法は実験的ではなく観察的である。[[Dataset/aidev]] データセットの 19,450 件のプルリクエストのレビューコメントから、少なくとも1件のレビューコメントを持つ 3,109 件のユニークな PR を導出し、各 PR のレビュアー構成を5つのカテゴリ（CRA のみ、人間のみ、および3つの混合の変種）に分類して、マージ、クローズ、停滞の結果を比較する。第二段階では、クローズされた CRA のみの PR 98 件を検討し、2層のキーワード枠組みを用いて各コメントを実行可能な内容についてスコア付けし、PR ごとの信号対雑音比を算出する。

その結論は、コードレビューエージェントは人間のレビュアーを置き換えるのではなく補強すべきであり、有効で実行可能なコードレビューにとって人間の関与は依然として決定的である、というものである。

## 主な貢献

- **マージ率の隔たり。** CRA のみがレビューした PR は 281 件中 127 件がマージされ、マージ率 45.20% であったのに対し、人間のみがレビューした PR は 1,176 件中 804 件（68.37%）であった——23.17 パーセントポイントの差である。放棄も同じ方向に動く。CRA のみは 34.88% がクローズされたのに対し、人間のみでは 21.60% である。レビュアーの種別と結果の独立性についてのカイ二乗検定は、自由度8で χ² = 83.0319、p < 0.001 を与える。
- **混合レビューはその中間に位置する。** 人間が優勢なレビューは 67.99%、CRA が優勢なレビューは 63.25%、均衡した混合は 61.09% でマージされた——エージェントが同席していても人間の関与が結果を改善するという、同論文の証拠である。
- **CRA は決して判断を下さない。** コードレビューエージェントのみがレビューした PR は、もっぱら Commented のレビュー状態にのみ現れる。著者たちは、単独の CRA レビュアーは独立に承認、却下、変更要求を行えないと報告している。
- **自動レビューコメントの大半はほとんど信号を含まない。** クローズされた CRA のみの PR 98 件のうち、59 件（60.2%）が信号 0〜30% の帯に、14 件（14.3%）が 31〜59% に、7 件（7.1%）が 60〜79% に、18 件（18.4%）が 80〜100% に落ちる。
- **量は質ではない。** 信号比 0.80 以上の PR は、比が 1.0 近辺のコメント1〜3件のあたりに集まるのに対し、0.30 未満の PR は比が 0.0 近辺のコメント1〜8件に広がる——重要なのはコメント数ではなく実行可能なフィードバックの割合である、と同論文が述べる根拠である。
- **この弱点はエージェントをまたいでほぼ普遍的である。** クローズされた集合で見つかった13のユニークな CRA のうち、12（92.31%）が平均信号比 60% 未満を示す。
- **推奨される用途は狭い。** 考察では、汎用のレビューではなくセキュリティ脆弱性やスタイル違反といった特定のチェックのために CRA を設定すること、マージ前に人間の承認を強制すること、そして CRA のコメントが開発者の直接の応答ではなく人間のレビューを引き起こすようなワークフローを確立することが論じられている。

## 注記

著者たちは自らの限界を率直に述べている。キーワードに基づく信号の分類は、キーワードを使わない実行可能なフィードバックを取りこぼしたり、無関係にキーワードを含むコメントを誤ってラベル付けしたりしうる。2名の研究者がコメントを独立に分類し、Cohen の κ は 0.75 に達した。彼らはまた、カイ二乗検定がレビュアーの種別と結果の間の統計的に有意な関連を示すとはいえ、相関は因果を含意しないことも注記している——低い信号のレビューが、数え上げられた放棄を*引き起こした*ことを、この研究は示せない。外的妥当性は AI 生成コードを含むオープンソースの GitHub リポジトリに限られており、同論文は、この知見がプロプライエタリなリポジトリ、他のプラットフォーム、あるいは CRA を用いないプロジェクトへ一般化しないかもしれないと述べている。

エージェントごとの数値のいくつかは非常に小さな標本に依拠しており、そのように読まれるべきである。あるエージェントはレビューした PR 1件で平均信号比 100.00% に達している一方、より実質的な件数を持つエージェントのなかで最高の比は 7 件にわたる 52.29% である。
