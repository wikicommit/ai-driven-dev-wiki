本サーベイは、Cleveland State University、Kent State University、Northeastern University の Khoury College と Roux Institute、そして AI 研究センターに所属する Aditi Singh、Abul Ehtesham、Saket Kumar、Tala Talaei Khoei、Athanasios V. Vasilakos によるもので、[[DefinedTerm/agentic-rag]] システムの分析的サーベイである。その議論は、従来の [[DefinedTerm/retrieval-augmented-generation]] に帰される限界から始まる。RAG は静的な訓練データが古かったり不正確だったりする出力を生むという問題に対処したが、「従来の RAG システムは静的なワークフローに制約されており、多段階の推論と複雑なタスク管理に必要な適応性を欠いている」というのである。

本論文の説明によれば、Agentic RAG は「RAG のパイプラインへ自律的な AI エージェントを埋め込むことでこれらの限界を超える」。本論文はこの語を自らのものと主張してはいない。Agentic RAG を生んだ RAG とエージェント的知能の合流は先行研究に帰しており、すでに用語の不統一に悩まされていると述べる分野を記述している。自らのものとして提示しているのは分類体系の方である。これらのエージェントは、本論文が名指す4つのエージェント的設計パターン——リフレクション、プランニング、ツール利用、マルチエージェント協働——を用いて、検索の戦略を動的に管理し、文脈の理解を反復的に洗練させ、順次的なステップから適応的な協働にまで及ぶと本論文が記述する運用構造を通じてワークフローを適応させる。

## 主な貢献

- **パラダイム転換の追跡。** サーベイは、RAG のパラダイムがエージェント的な形態へ至るまでの進化を追跡している。
- **原理に基づく分類体系。** Agentic RAG のアーキテクチャを4つの軸——エージェントの数、制御構造、自律性、知識表現——に沿って分類している。
- **トレードオフの比較分析。** 既存の枠組みにまたがる設計上のトレードオフを比較している。
- **応用。** カスタマーサポートとバーチャルアシスタント、ヘルスケア、法務および契約分析、金融、教育、企業文書処理、グラフで強化されたマルチモーダルなワークフローといった領域における実世界の応用を検討し、システム設計者と実践者に向けた実践的な教訓を抽出している。
- **未解決の研究課題。** 評価、協調、メモリ管理、効率、ガバナンスにおける課題を特定し、今後の研究の方向性を示している。

サーベイはこの資料のための GitHub リポジトリを併せて維持している。

## 注記

本論文が土台とする4つの設計パターン——リフレクション、プランニング、ツール利用、マルチエージェント協働——は、本 wiki の主題領域における実践者の文章がコーディングエージェントについて用いるのと同じ語彙であり、ソフトウェア開発についての論文ではないにもかかわらず、それがここで関連性を持つ理由である。Agentic RAG システムについて主張されている便益は強い言葉で述べられており——「多様な応用にわたる比類のない柔軟性、スケーラビリティ、文脈認識」——、測定された結果ではなくサーベイ自身による特徴づけである。

応用として概観されている領域は本 wiki のスコープの外にある。持ち越されるのは構造的な主張、すなわち次に何を取得するかをエージェントが決める検索パイプラインは、固定された検索ステップを持つものとは異なる振る舞いをする、というものである。同じ問いのコードベースに固有の版——エージェントが作業しながら字句的検索と意味的検索のあいだで選択する——については [[DefinedTerm/semantic-search]] を、エージェントそのものについては [[DefinedTerm/coding-agent]] と [[DefinedTerm/multi-agent-orchestration]] を参照。
