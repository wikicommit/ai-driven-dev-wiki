「Code as Agent Harness」は、2026年5月18日に arXiv へ投稿された大規模なサーベイであり、イリノイ大学アーバナ・シャンペーン校、Meta、スタンフォード大学にまたがるグループによるものである。著者一覧は長く、うち6名がコア貢献者として記されている。自らのキーワードとして agent harness、coding agent、harness engineering、agentic AI を挙げ、付随する論文リストを維持している。

その整理の軸となる主張は、能力ではなく役割の変化についてのものである。「立ち現れつつあるエージェンティックなシステムにおいて、コードはもはや目標となる出力であるだけではない。それはますます、エージェントの推論、行為、環境のモデル化、実行に基づく検証のための運用基層として機能している。」同サーベイはその転換を [[DefinedTerm/agent-harness]] を通じて枠づけ、**エージェントハーネスとしてのコード**を「エージェントのインフラの基礎としてコードを中心に据える統一的な見方」として導入している。

## 主な貢献

同サーベイは、相互に結びついた3つの層を軸に構成されている。

- **ハーネスインターフェース**——コードがエージェントを推論、行為、環境のモデル化へつなぐ場所である。推論のもとでは、プログラムへ委譲された推論、形式検証と記号推論のインターフェース、コードに接地された反復的な推論を扱う。行為のもとでは、接地されたスキル選択、プログラム的な方策生成、コードに基づく生涯学習エージェントを扱う。環境のもとでは、構造化された世界表現、実行トレースによる世界モデル化、コードに接地された評価環境、検証可能な環境の構築を扱う。
- **ハーネス機構**——長期にわたる実行のための計画、メモリ、ツール使用であり、「ハーネスを信頼でき適応的なものにする、フィードバック駆動の制御と最適化とともに」扱われる。計画のタクソノミーは線形分解、構造接地、探索ベース、オーケストレーションベースである。メモリのタクソノミーは、コンテキストのコンパクションと状態のオフロードと並んで、ワーキング、意味的、経験的、長期、マルチエージェントの各メモリを切り分ける。ツール使用のタクソノミーは、関数指向、環境相互作用、検証駆動、ワークフローオーケストレーションである。制御は計画・実行・検証のループとして整理され、ハーネスレベルの制御、契約形成としての計画、権限付きの状態遷移を伴うサンドボックス実行、決定論的なセンサーを通じた検証を扱う。
- **ハーネスのスケーリング**——単一エージェントのシステムからマルチエージェントの設定へ、「共有されたコード成果物がマルチエージェントの協調、レビュー、検証を支える」場へと広げる。この部分は、機能的な役割の専門化と人間に導かれた計画、共有されたプログラム状態に接地された相互作用の様式、ワークフローのトポロジー、実行フィードバックの統合と共有ハーネスの同期を扱い、コード中心の共有ハーネス基層を主張するポジションの節で締めくくられる。

これらの層を通じて、コーディングアシスタント、GUI と OS の自動化、身体性を持つエージェント、科学的発見、パーソナライゼーションとレコメンデーション、DevOps、企業のワークフローにまたがる手法と応用が要約されている。

## 注記

同サーベイはハーネスエンジニアリングにおける6つの未解決課題に名を与えている。最終的なタスク成功を超えた評価、不完全なフィードバックのもとでの検証、リグレッションのないハーネス改善、複数エージェントにまたがる一貫した共有状態、安全性が重要な行為に対する人間の監督、そしてマルチモーダルな環境への拡張である。

そのうち2つは、すでにここに記録されている素材に直接つながる。「リグレッションのないハーネス改善」は [[ScholarlyArticle/dont-blame-the-large-language-model]] が実証的に測定している問題——ハーネスの相次ぐリリースがエージェントの品質を確実には改善せず、ときに劣化させること——であり、「最終的なタスク成功を超えた評価」は、同研究が解決率と並んでトークン消費とツール呼び出しのオーバーヘッドを測ることで埋めているのと同じ隔たりである。同サーベイはまた、深いテレメトリ、進化エージェント、統治されたハーネスの変異を軸に構成された、適応的なハーネス最適化の節も含んでおり、これは [[DefinedTerm/harness-engineering]] が手作業の実践として説明するものの自動化された形である。

これは新たな測定ではなく文献のサーベイである。タクソノミーと枠づけを貢献するものであり、そのなかの主張は著者たちにではなく概観された諸研究に属する。本ページで要約した内容は、その要旨、序論、節構成に由来する。
