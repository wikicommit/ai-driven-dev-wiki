「Vibe engineering」は2025年10月8日付の Simon Willison's Newsletter の一号であり、その巻頭項目は [[DefinedTerm/vibe-engineering]] という語を提案した2025年10月7日の彼の記事を再掲したものである。Willison の出発点は用語の空白である。彼は [[DefinedTerm/vibe-coding]] を「AI でソフトウェアを作る、速くていい加減で無責任なやり方」——完全にプロンプト駆動で、コードがどう動くかにはまったく注意を払わない——として十分に定着した語だと見なす。そうすると反対側の端、すなわち出荷するものに責任を持ち続けながら LLM で自分の仕事を加速させる熟練の専門家たちには、名前が残されていないことになる。

項目の大部分は、LLM が積極的に報いると Willison が論じる、確立されたソフトウェアエンジニアリングの実践の一覧であり、その後に名前そのものの短い擁護が続く。彼の枠づけは終始、この働き方は*難しい*というものであり、エージェントが動くコードを生み出す速さは、人間の参加者に対する要求水準を下げるどころか上げるのだ、というものである。

ニュースレター号の残りは無関係なリンクブログ——OpenAI DevDay の報道、モデルのリリース、Python のリリース——であり、バイブエンジニアリングの議論の一部ではない。

## 要点

- **変化をもたらしたのはコーディングエージェントである。** Willison は、実世界の問題に対する LLM の有用性を劇的に高めたものとして、コーディングエージェントの台頭を挙げている。指定された目標を達成するまでコードを能動的にテストし修正しながら反復するツールとして、Claude Code（2025年2月リリース）、OpenAI の Codex CLI（4月）、Gemini CLI（6月）を名指している。[[DefinedTerm/coding-agent]] を参照。
- **複数のエージェントを同時に走らせる。** 彼は、経験豊富なエンジニアたちがエージェントのコピーを並列に複数走らせていると聞いたと報告し、当初は懐疑的だったと述べ、自分でもそれを始めたと述べている。「驚くほど効果的だ——精神的にはくたびれるが」。
- **LLM が報いる実践。** 自動テスト（テストのないエージェントは、テストしないまま何かが動くと主張しうる）。事前の計画。包括的なドキュメント（これによりモデルはコードを読んでいない API を使えるようになる）。良好なバージョン管理の習慣（LLM は「Git については獰猛なまでに有能」だと記述される）。CI、フォーマッタ、リンタ、プレビューデプロイといった効果的な自動化。コードレビューの文化。「きわめて奇妙な形のマネジメント」。強力な手動 QA。強力な調査能力。プレビュー環境へ出荷できること。何を AI に外注できるかについての勘。そして見積もりの感覚の更新——AI はこれを容易にするどころか難しくすると彼は述べる。
- **置き換えではなく増幅。** Willison のまとめの主張は、AI ツールは既存の専門性を増幅するというものである。エンジニアが持つスキルと経験が多いほど、結果はより速くより良くなる。そして列挙された特徴のほとんどすべては、すでにシニアエンジニアの特徴でもある。
- **意図的に生意気な名前。** 彼はおそらく馬鹿げた名前だろうと認め、AI の概念としての「vibes」はもう擦り切れた感じがすると述べつつ、ここで多少の門番的な振る舞い（ゲートキーピング）をすることこそ、より難しく洗練された働き方を示すために必要なのだと論じる。彼は以前「AI 支援プログラミング（AI-assisted programming）」を定着させようとしてほぼ皆無の成果しか得られなかったと指摘し、「vibes」と「engineering」の自己矛盾は記憶に残るものとして気に入っていると述べている。

## 背景

この記事は、バイブコーディングとはコードへの関与を放棄することを意味するという Willison のそれ以前の主張——[[BlogPosting/not-vibe-coding]] で扱われている立場——の直接の続編である。規律ある対の側に名前を与えることは、その立場が生み出す用語上の圧力を彼なりに解消する方法である。コードをレビューし理解することがバイブコーディングではないのなら、その実践にはやはり名前が必要だからだ。

Willison はこの領域全体が未確定であると明示している——「この領域全体が、いろいろな意味でまだ滑稽なままだ」——そして、この語を確定した定義ではなく提案として提示している。記事には Hacker News と lobste.rs で議論されたことが記されている。
