Google Cloud AI Agent Bake-Off から 5 つのアーキテクチャパターンを引き出した Google for Developers のブログ記事である。このコンペティションシリーズでは、開発者チームが厳しい時間制限のもとで、実際の業界の課題（e コマースの返品、レガシーな銀行システムのモダナイゼーション、市場開拓の自動化）に取り組む自律型エージェントを構築した。著者らはこのシリーズを、実践が単一モデルへのプロンプティングの段階を越えたことの証拠として提示している。彼らの捉え方では、デモから本番アプリケーションへ進むために必要なのは、より良いプロンプトエンジニアリングではなく、マルチエージェントアーキテクチャ、状態管理、決定論的なガードレールである。

5 つのパターンは、発見としてではなく、アーキテクチャの青写真として示されている。スーパーバイザーの下で専門化されたサブエージェントに分解すること、エージェントハーネスは短命であると想定すること、マルチモダリティを本来備わったものとして扱うこと、独自の統合コードではなくオープンなエージェントプロトコルを採用すること、そしてモデルを推論に限定し、実際の処理は決定論的なコードに行わせることである。それぞれがシリーズ中のエピソードで例示され、記事は最後に読者を Google 自身の [[SoftwareApplication/agent-development-kit]] と Agent Starter Pack へと案内して締めくくられる。

## 要点

- 複雑なエージェントを、範囲を厳密に絞ったプロンプトを持つ専門化されたサブエージェントに分解し、トラフィックをルーティングするスーパーバイザーエージェントで調整する。記事はエージェントをマイクロサービスのように扱い、意図の抽出、検索、推論を一度に処理する単一の巨大なプロンプトは、ハルシネーションやレイテンシの急増を招くと主張している。
- 記事の報告によれば、エピソード 3 では、範囲を厳密に絞ったエージェントを並列に実行したチームが処理時間を「1 時間からわずか 10 分に」短縮した。これはシリーズ中に観察された単一の結果を主催者が報告したものであり、測定されたベンチマークではない。
- モジュール化された分解は保守性の論拠としても示されている。モデルを差し替えたりデータベーススキーマを変更したりしても、影響はワークフロー全体ではなく 1 つのサブエージェントにとどまる。
- 一時性を前提に設計する。著者らは、今日書かれた複雑なエージェントハーネスは数か月のうちにモデルの能力によって不要になりうると主張し、自身の e コマースの課題を引き合いに出している。そこでは多段階のバーチャル試着が 3 時間の締め切りのもとで構築された。記事の報告によれば、当時 Nano Banana の最初のバージョンの登場は「わずか数週間後」に迫っており、現在では同じ体験が「単一のプロンプトで実現できる」という。
- マルチモダリティを後付けの機能ではなく中核的な要件として扱う。記事は、テキストだけの推薦では実際の小売の課題に対応できないと主張し、より優れたアーキテクチャは、ユーザーの写真を取り込み、視覚的な文脈を抽出し、画像生成ツールを呼び出して視覚的な結果を組み立てていたと述べている。
- ツールごとに独自の API ラッパーを書くのではなく、オープンなエージェントプロトコルを採用する。記事は現在の状況として MCP、A2A、UCP、AP2、A2UI、AG-UI を挙げ、これを使いこなせるかどうかがプロトタイプと本番システムを分けると主張している。
- LLM は推論と意図の抽出に限定し、その出力を厳格なスキーマ（記事は例として Pydantic を挙げている）に照らして検証し、検証済みの変数を決定論的なコード（Python の関数や SQL クエリ）に渡して実行させる。著者らの報告によれば、レガシーな銀行システムの課題で、金融計算をモデルに直接行わせたチームは検証エラーを引き起こした。

## 背景

この記事は Google の社員が執筆し、Google 自身の開発者ブログに掲載されたものであり、その推奨は Google 自身のフレームワークを指し示している。したがって、プロトコルやツールに関する助言は、独立した比較ではなく、ベンダーによる自社エコシステムの説明である。根拠となっているのは同じ組織が運営したコンペティションシリーズであり、各エピソードは人為的な時間的プレッシャーのもとで作業するチームを直接観察したものとして描かれている。著者ら自身もこれを、統制された研究ではなく「生のままでフィルターのかかっていない」ものとして位置づけている。

記事は 5 つのパターンを、自らの発案としてではなく、シリーズから抽出した青写真として提示しており、いずれかのパターンの起源を主張してはいない。
