Charm（Charmbracelet, Inc.）は、「We make the command line glamorous.（私たちはコマンドラインを魅力的にする）」というタグラインのもと、コマンドライン向けのツールを開発している企業である。同社のサイトは、その成果をライブラリとアプリに分類して紹介しており、同社のブログは、同社が第一級のターミナルアプリケーションの基盤づくりに 5 年を費やしてきたと説明している。創業者は Christian Rocha である。

## 活動と製品

Charm のライブラリには、同社が絶えず開発と改良を重ねてきたツールだとする Bubble Tea、Bubbles、Lip Gloss、Glamour のほか、高度な合成処理と高速なレンダリングを実現するとする次世代のターミナル UI ツールキット Ultraviolet がある。同社のブログでは、投稿をターミナルで読む手段として、同じく Charm のツールである Glow も紹介している。

2025 年、Charm は同社のライブラリを基盤に構築されたターミナルベースの AI コーディングエージェント [[SoftwareApplication/crush]] を社内に迎え入れ、[[BlogPosting/crush-welcome-home]] で「We made the command line glamorous. Now we're making it intelligent.（私たちはコマンドラインを魅力的にした。今度はそれを賢くする）」という一文とともにそれを発表した。同社はターミナルこそが AI を活用した開発にふさわしいインターフェースだと位置づけ、15 万を超える GitHub スターと 11,000 人を超える GitHub フォロワーからなるコミュニティを挙げている。
