Qodo は、同社が開発し、その後オープンソースコミュニティへ寄贈したオープンソースのプルリクエストレビューエージェント [[SoftwareApplication/pr-agent]] の開発元企業である。同社自身の製品は AI コードレビュープラットフォームであり、オープンソースプロジェクト向けには無料版が提供され、GitHub、GitLab、Bitbucket、Azure DevOps と統合できる。

ここでの情報は PR-Agent 自身の README に基づいているため、同社を全体像としてではなく、そのプロジェクトから見た姿として記述している。

## 沿革

README には 1 つの移行が記録されている。README が Qodo 1.0 と位置づける Qodo Merge は、PR-Agent のホスト型エンタープライズ版だった。その後これはリブランドされ、Qodo 2.0 と位置づけられる本格的な AI コードレビュープラットフォームである Qodo へと発展した。これと並行して、オープンソースの PR-Agent プロジェクトはコミュニティに引き渡された。現在は独立した PR-Agent GitHub organization で管理され、完全にコミュニティが所有するプロジェクトと説明されており、ドキュメントも docs.pr-agent.ai に移転した。README はこの公開を Qodo からのコミュニティへの貢献として位置づけ、同社を現代的な AI 駆動のコードコラボレーションの起源と呼んでいる。ただしこれはプロジェクト自身の README による形容であり、外部からの評価ではない。

## 活動と製品

README の中で、同社の現在の製品は、寄贈されたオープンソースプロジェクトとは別物であり、より高機能なものとして位置づけられている。すなわち、機能が豊富でコンテキストを考慮したコードレビュー体験であり、これに対して PR-Agent は自らをコミュニティが保守するレガシープロジェクトと説明している。Qodo は、プロジェクトの継続的な開発がスポンサーによって支えられていることを示す見出しのもとで PR-Agent のゴールドスポンサーとして掲載されており、また自社製品の無料版をオープンソースプロジェクトに提供している。
