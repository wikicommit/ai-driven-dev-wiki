Sonar はコード解析ベンダーであり、本ウィキにとっての関わりは、AI が生成したコードが実際にどう振る舞うかについての調査の公刊者としてのものである。同社は毎日 7,500 億行を超えるコードを解析していると述べ、その規模を、公刊する調査が依拠するコード理解の基盤として提示している。

## 沿革

ここで取り込んだ出典は、Sonar の設立や企業としての沿革を扱っていない。

## 活動と製品

同社は State of Code と呼ぶレポートシリーズを公刊しており、これは自社の知見を開発者や技術リーダーにより広く共有するために始められたものである。同社はこのシリーズについて、これまでコードの信頼性、セキュリティ、保守性、そして主要な LLM に固有のコーディングパーソナリティと呼ぶものを扱ってきたと説明しており、それらをコードそのものとそれを作るモデルに焦点を当てたレポートと特徴づけている。

[[Report/state-of-code-developer-survey-2026]] は、視座を実作業に当たる開発者の側へと移した回である。その掲げられた狙いは、AI がコーディングの機構を変えつつあるなかで現場で何が変わっているのか——効率、フラストレーション、そして立ち現れつつあるワークフロー——を読み取ることにあった。また、他の主要な開発者調査の知見を踏まえたうえで、それらを読んでもなお著者たちに残った問いに答えるよう意図的に設計されていた。期待された生産性向上の代わりに [[DefinedTerm/verification-bottleneck]] が現れているというその中心的な知見は、同社独自のものである。

同レポートの結びの章は、自社製品である SonarQube を AI 生成コードの検証レイヤーとして位置づけ、SonarQube の利用者は非利用者よりも、コード品質、技術的負債、手戻りコスト、欠陥、脆弱性への好影響が強く出ていると報告している——これは Sonar 自身の調査のなかから、自社製品について引き出された比較である。
