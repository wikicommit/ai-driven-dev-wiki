Microsoft は世界中に拠点を持つ大規模なソフトウェア企業であり、そのエンジニアは多くのプロダクト領域にまたがり、多様なコードベースで作業し、幅広い言語でプログラミングしている。Microsoft の従業員が執筆した研究 [[ScholarlyArticle/adoption-and-impact-of-command-line-ai-coding-agents]] によれば、同社は AI ツールを販売してその利用を奨励しており、[[SoftwareApplication/github-copilot-cli]] の開発元である [[Organization/github]] を所有している。

## 活動・製品

2026 年以前の数年間、Microsoft の従業員は CLI 以外の形態で [[SoftwareApplication/github-copilot]] を利用できた。具体的には、VS Code などの IDE におけるコード補完、チャット、エージェントモードである。2026 年上半期には、同社のエンジニアが利用を認められたエージェント型のコマンドラインツールが 2 つあった。1 つは、一般提供に先立ってプロダクトプレビュープログラムを通じて Microsoft が利用できた Copilot CLI、もう 1 つは [[SoftwareApplication/claude-code]] である。後者がエンジニアに届いた経路はより限られており、2025 年後半から、特定の部門や個人が管理されたプログラムを通じてアクセス権を得ていた。そのアクセス対象者のリストは時とともに変わっていった。この研究は、2026 年 1 月 5 日前後を、社内でこれらのツールの利用が広く立ち上がった時点として扱っている。Microsoft はまた、これらのツールに関するデモ、チュートリアル、ハンズオンセッションからなる社内イベント「Agentic Engineering Day」も開催した。

2026 年 4 月 29 日の直後、社内告知により、ほとんどのエンジニアについて Claude Code のライセンスが約 1 か月後に打ち切られることが示され、対象のエンジニアは Copilot CLI へ移行するよう指示された。この展開についてテレメトリに基づいて行われた同社の研究では、Copilot CLI の導入は主に同僚やマネージャーが使っている様子が目に見えることを通じて広がり、いずれかのツールを導入したエンジニアは、合成反実仮想（synthetic counterfactual）による予測よりもおよそ 24% 多くのプルリクエストをマージしていた。

Microsoft は、エンジニアリング職を並行する 2 つのキャリアステージのラダーで編成している。個人貢献者向けの IC と、ピープルマネージャー向けの M である。数字が大きいほど担う範囲と職位が大きいことを表し、IC4 と M4 のように 2 つのラダーで同じ数字のステージは同格として位置づけられている。
