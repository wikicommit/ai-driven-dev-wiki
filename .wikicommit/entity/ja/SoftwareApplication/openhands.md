OpenHands は、かつて OpenDevin として知られていた、人間の開発者と同じしかたで——コードを書き、コマンドラインを使い、ウェブを閲覧することで——世界と関わる AI エージェントを開発するためのオープンソースのプラットフォームである。[[ScholarlyArticle/openhands]] に文書化されており、そこでは新しいエージェントの実装、コード実行のためのサンドボックス環境との安全な相互作用、複数エージェント間の協調、そして評価ベンチマークの組み込みを支えるものとして記述されている。

## 概要

OpenHands におけるエージェントは、環境の状態を知覚して行動を生み出す。状態の中心的な構成要素はイベントストリームである。過去の行動と観測の時系列の記録であり、エージェント自身の行動と、指示やフィードバックといったユーザーとのやり取りの双方を含む。それと並んで、状態は LLM 呼び出しの累積コストと、マルチエージェントの委譲に必要なメタデータを追跡する。

環境へのインターフェースは、大きなツールのカタログではなく、少数の汎用的な行動である。`IPythonRunCellAction` と `CmdRunAction` がサンドボックス内で任意の Python と bash を実行し、`BrowserInteractiveAction` がドメイン固有言語を通じてブラウザを操作する。行動空間がプログラミング言語であるため、従来のツールもその内部で表現可能なままである。ユーザーは Python 関数を書き、同じプリミティブを通じてそれをエージェントへ露出できる。

## 機能

**AgentSkills** は Python パッケージとして提供される拡張可能なツールライブラリであり、その関数はエージェントの IPython 環境へ自動的に読み込まれるため、ツールを寄与することは Python 関数を書くことを意味する。プロジェクトが掲げる採用基準はライブラリを意図的に小さく保つ。スキルが追加されるのは、直接コードを書くことが LLM にとって容易には達成できない場合——挙げられている例は特定の行を置き換えるファイル編集である——か、外部モデルの呼び出しを必要とする場合に限られる。同梱されるスキルには、SWE-Agent と Aider から取り入れたファイル編集のユーティリティ、ファイルの異なる部分を見るための `scroll_up` と `scroll_down`、そしてマルチモーダルな文書を読むための `parse_image` と `parse_pdf` が含まれる。

**エージェントの委譲**は、専用の `AgentDelegateAction` を通じてあるエージェントがサブタスクを別のエージェントへ手渡すことを可能にする。文書化されている例は、汎用の CodeActAgent がウェブ閲覧の作業を特化した BrowsingAgent へ委譲するというものである。

**AgentHub** は、エンドユーザーが選べる、そして異なるタスクのベースラインとして機能する、コミュニティが寄与したエージェントの実装を集めている。既定の汎用エージェントは **CodeActAgent** であり、各ステップで、明確化や確認を求めるために自然言語で会話するか、bash、Python、あるいはブラウザ自身の言語のいずれであれコードを実行してタスクを遂行するかのいずれかを行う。

ユーザーインターフェースは、ファイルを閲覧し、実行された bash コマンドと Python コードを検査し、エージェントのブラウザ操作を観察し、エージェントと直接対話することを可能にする。

## 沿革

プロジェクトは MIT ライセンスのもとで公開されており、その論文では学術界と産業界にまたがるコミュニティのプロジェクトとして、執筆時点で188名を超えるコントリビュータによる 2,100 を超える貢献があると記述されている。報告されているベンチマークの結果は著者ら自身のものである。SWE-Bench Lite では claude-3.5-sonnet を用いた CodeActAgent v1.8 が 26% の解決率に達し、HumanEvalFix の Python の分割ではエージェントが 0-shot の設定で 79.3% のバグを修正した。
