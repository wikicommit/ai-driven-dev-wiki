Mistral Vibe CLI は、Mistral AI が公開し、Apache 2.0 ライセンスでリリースしたコマンドライン型のコーディングアシスタントである。Devstral モデルファミリー向けに作られており、[[BlogPosting/introducing-devstral-2-and-mistral-vibe-cli]] で Devstral 2 とともに発表された。自然言語の指示にもとづいてコードベースを探索し、変更を加え、その結果としての変更を実行するもので、ターミナルでも IDE の中でも動作する。

これはターミナル常駐型の [[DefinedTerm/ai-coding-agent]] ツールのカテゴリに属する。Mistral 自身の位置づけにおいてこれを際立たせているのは、エージェントとそれが前提とするモデルの両方がオープンなライセンスで提供されている点である。エージェントは Apache 2.0、Devstral Small 2 も同じく Apache 2.0、Devstral 2 は修正版 MIT ライセンスで提供されている。Mistral はこの組み合わせを、本来であればホスト型のプロプライエタリなモデルに依存することになる [[DefinedTerm/agentic-coding]] の作業に対する、エンドツーエンドでオープンな代替手段として提示している。

## 機能

CLI は、ファイル操作、コード検索、バージョン管理、コマンド実行のためのツールに支えられた対話型のチャットインターフェースを提供する。Mistral はこれをプロジェクトを考慮したものと説明しており、ユーザーが関連ファイルを指定しなくても、自らファイル構造と Git の状態をスキャンしてコンテキストを組み立てる。セッション内では、`@` による補完でファイルを参照し、`!` でシェルコマンドを実行し、スラッシュコマンドで設定を変更できる。セッションは永続的な履歴と自動補完を備え、インターフェースはカスタマイズ可能なテーマをサポートしている。

Mistral は、CLI が開いているファイルだけでなくコードベース全体にわたって推論すると述べ、これを複数ファイルにわたるオーケストレーションと呼び、アーキテクチャレベルの推論を可能にするものだと説明している。これによって PR のサイクルタイムを半減できるという主張は Mistral 自身によるもので、ローンチの発表の中で裏付けとなる測定なしに述べられている。

CLI はスクリプトからプログラム的に呼び出すことができる。ツールの実行は自動承認にするか承認制のままにするかを設定でき、ツールのパーミッションを制限することもでき、ローカルモデルとプロバイダーは `config.toml` ファイルで設定する。Devstral と組み合わせて使う場合、Mistral は temperature を 0.2 にすることを推奨している。

## 採用状況とエコシステム

Mistral Vibe CLI は Agent Communication Protocol を通じて IDE と連携し、Zed エディタ向けの拡張機能としても配布されているため、別のターミナルではなくそのエディタの中から操作できる。

発表はこの CLI を Devstral のネイティブなハーネスとして位置づけているが、モデルはサードパーティのエージェントツールにも提供されている。Mistral は、開発者がすでに使っているツールで Devstral 2 を利用できるようにするために協力したパートナーとして Kilo Code と Cline の名前を挙げている。したがって、この CLI はこれらのモデルをエージェント的に動かす唯一の手段ではなく、いくつかある手段の 1 つであり、Mistral はプロジェクト自身のリポジトリの README でそのベストプラクティスを公開している。
