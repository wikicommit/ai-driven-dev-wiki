OpenHarness は、HKUDS が MIT ライセンスで公開している [[DefinedTerm/agent-harness]] のオープンソース Python 実装であり、`oh` という単一のコマンドで起動する。README はエージェントハーネスを、LLM を包み込んで機能するエージェントに仕立てるための基盤一式と定義している。モデルが知性を提供し、ハーネスは「手、目、記憶、そして安全の境界」を提供するという整理であり、README は「モデルがエージェントであり、コードがハーネスである（The model is the agent. The code is the harness.）」という一文で締めくくられている。

このプロジェクトは自らを、コミュニティ主導の研究プロジェクトと位置づけている。対象は、本番環境の AI エージェントが内部でどう動いているかを理解したい研究者や開発者、ツール・スキル・エージェント協調パターンを試したい人、独自のプラグインやプロバイダーでハーネスを拡張したい人、そしてその上に特化型エージェントを構築したい人である。同じリポジトリでは、OpenHarness 上に構築されたパーソナルエージェント [[SoftwareApplication/ohmo]] も提供されている。

## 機能

中核にあるのはエージェントループである。ハーネスはモデルの応答をストリーミングし、モデルがツールを要求し続けるかぎり、各ツール呼び出しをパーミッションチェックとライフサイクルフックに通して実行し、その結果を会話に追加して再びループする。モデルが作業を終えた時点で停止する。README の言葉を借りれば、何をするかはモデルが決め、どうやるかはハーネスが担う。このループの周囲に、プロジェクトは次のサブシステムを挙げている。ツール（43 個以上。ファイル操作とシェル、Web 検索とコード検索、ノートブック編集、サブエージェントとチーム、バックグラウンドタスク、MCP、プランモードとワークツリーの切り替え、スケジュール実行やリモート実行にわたる）、`SKILL.md` ディレクトリからオンデマンドで読み込まれるスキル、コマンド・フック・エージェントをまとめたプラグイン、パーミッション、PreToolUse と PostToolUse の [[DefinedTerm/agent-hooks]]、スラッシュコマンド、MCP クライアント、永続メモリ、バックグラウンドタスク、そしてマルチエージェント協調である。コンテキストの扱いとしては、CLAUDE.md ファイルの検出と注入、自動的なコンテキストの [[DefinedTerm/compaction]]、永続メモリファイル MEMORY.md、セッションの再開が含まれる。

パーミッションには 3 つのモードがある。書き込みや実行の前に確認するデフォルトモード、すべてを許可しサンドボックス環境での利用を想定したオートモード、そしてあらゆる書き込みをブロックするプランモードである。これに加えて、設定ファイルでパス単位のルールや拒否するコマンドを指定できる。`oh` ツールは React/Ink 製のターミナルインターフェースで対話的に動かすことも、スクリプト向けにテキスト、JSON、ストリーミング JSON で出力する非対話モードで動かすこともできる。ドライランモードは、モデルを呼び出したり、ツールを実行したり、サブエージェントを起動したり、MCP サーバーに接続したりすることなく、設定、認証、プロンプトの組み立て、スキル、コマンド、ツール、MCP の構成を解決し、ready・warning・blocked のいずれかの判定を、推奨される次のアクションとともに報告する。モデルプロバイダーは名前付きのワークフロープロファイルとして設定され、Anthropic 互換および OpenAI 互換の API、Claude と Codex のサブスクリプション、GitHub Copilot をカバーしており、Ollama の OpenAI 互換エンドポイントで提供されるローカルモデルも受け入れる。

## 採用とエコシステム

OpenHarness は、Anthropic のスキルリポジトリにおける `SKILL.md` のディレクトリ構成（[[DefinedTerm/agent-skills]]）および [[SoftwareApplication/claude-code]] のプラグインとの互換性をうたっており、12 個の公式プラグインでテスト済みだと報告している。また `.claude/skills` や `.agents/skills` ディレクトリからもスキルを検出する。README は OpenHarness を、Claude 形式のツーリング規約を包む軽量なハーネス層と位置づけ、[[SoftwareApplication/openclaw]] 志向のワークフローや ClawTeam 流のマルチエージェント作業に適しているとしている。想定される用途としては、リポジトリのコーディングアシスタント、ヘッドレスなスクリプティングツール、スキルやプラグインのテストベッド、マルチエージェントのプロトタイプ用ハーネス、プロバイダーを比較するためのサンドボックスが挙げられている。最初のオープンソースリリースは 2026 年 4 月 1 日付である。
