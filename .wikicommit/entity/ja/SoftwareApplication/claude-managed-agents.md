Claude Managed Agents は、顧客に代わって長期にわたるエージェントを実行するための、Claude Platform における
[[Organization/anthropic]] のホスト型サービスである。その設計についての Anthropic 自身の説明である
[[BlogPosting/scaling-managed-agents-decoupling-the-brain-from-the-hands]] は、これを「特定の実装よりも長く
存続することを意図した、少数のインターフェース」を中心に構築されたものと説明している。その理由として、
エージェントハーネスは Claude が自力ではできないことについての前提を組み込んでおり、そうした前提はモデルが
向上するにつれて古くなる、という考え方が挙げられている。Addy Osmani による長時間稼働エージェントの概説は、
これを 4 月初めにローンチされた Anthropic のホスト型ランタイムと説明している。

この設計は、本 wiki が [[DefinedTerm/brain-hands-session-split]] と呼ぶものに従っている。Anthropic はエージェントを、
セッション（起きたことすべての追記専用ログ）、ハーネス（Claude を呼び出し、そのツール呼び出しを振り分けるループ）、
サンドボックス（Claude がコードを実行しファイルを編集できる実行環境）に仮想化し、それぞれの背後にある実装を
他に影響を与えずに差し替えられるようにしている。Anthropic はその結果を [[DefinedTerm/meta-harness]] と呼んでいる。
Claude が必要とする特定のハーネスについては特定の立場をとらず、[[SoftwareApplication/claude-code]] のような
汎用ハーネスにもタスク特化型のハーネスにも対応できるものである。

## 機能

ハーネスはサンドボックスの内部には置かれない。ハーネスは他のツールを呼び出すのと同じように
`execute(name, input) → string` というインターフェースを通じてコンテナを呼び出し、コンテナの障害は Claude には
ツール呼び出しのエラーとして現れる。その後、標準のレシピから新しいコンテナをプロビジョニングできる。ハーネス
自体はステートレスである。セッションログがハーネスの外にあるため、障害を起こしたハーネスは `wake(sessionId)` で
再起動し、`getSession(id)` でイベントログを取得して、最後のイベントから再開できる。Anthropic はセッションを、
Claude のコンテキストウィンドウの外に存在するコンテキストオブジェクトと説明している。`getEvents()` によって
ハーネスはイベントストリームの位置指定のスライスを選択でき、それらのイベントが Claude に届く前のあらゆる変換、
すなわちコンテキストエンジニアリングやプロンプトキャッシュの最適化はハーネスに委ねられている。

コンテナはセッションが必要とするときにのみプロビジョニングされるため、オーケストレーション層がセッションログから
保留中のイベントを取り出すとすぐに推論を開始できる。Anthropic は、これによって最初のトークンまでの時間が p50 で
およそ 60%、p95 で 90% 以上短縮されたと報告している。セキュリティのため、トークンは Claude が生成したコードが
実行されるサンドボックスの外に置かれる。Git のアクセストークンはサンドボックスの初期化時にリポジトリのクローンに
使われ、ローカルのリモートに組み込まれるため、エージェントがトークンを扱うことなく push と pull が機能する。
カスタムツールは MCP を通じてサポートされ、OAuth トークンはボールトに保持され、呼び出しは認証情報を取得する
プロキシを経由して行われる。同じ切り離しによって、ハーネスはネットワークピアリングなしに顧客自身の VPC 内の
リソースに接続でき、1 つの頭脳が多数の実行環境に到達できる。Anthropic は、頭脳同士が手を受け渡すことさえできると
書いている。

## 導入とエコシステム

Osmani は、ホスト型の長時間稼働エージェント製品を構築するチームにとっての 3 つの現実的な選択肢の 1 つとして
これを挙げている。他の 2 つは Google の Agent Platform と、Claude Agent SDK、Codex SDK、または Google の ADK の上に
ランタイムをセルフホストすることである。彼が示すトレードオフは、マネージド型とセルフホスト型の間によくあるもので
ある。Claude Managed Agents は Brain/Hands/Session 分割、オブザーバビリティ、アイデンティティ、監査証跡を
最初から提供する一方、セルフホストはそれと引き換えに制御と、役割ごとに異なるモデルを割り当てる能力を得る。
