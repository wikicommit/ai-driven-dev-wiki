Claude Artifacts は [[Person/simon-willison]] によって、[[DefinedTerm/vibe-coding]] のために広く利用可能となった最初期のプラットフォームの一つとして、またサンドボックス化によってこの実践を完全な初心者にとって安全にしうることの例として記述されている。その際立った性質はコード生成ではなくサンドボックスの方にある。生成されたコードは閉じた `<iframe>` の内側で実行され、承認されたライブラリしか読み込めず、他のサイトへネットワークリクエストを送ることができない。

このアプローチを「すばらしい」と呼ぶ Willison は、この設計を意図的な取引として枠づけている。サンドボックスは、誰かが自分のプロジェクトでしくじって害をもたらすことを非常に難しくする——事故が他所へ伝播しえないことこそ、彼がこれを好む理由である。同時にそれは、それらのプロジェクトにできることも大きく制限する。Artifacts のプロジェクトは外部 API のデータに到達できないし、作者自身のプロンプトを LLM に対して実行することすらできない。

## 概要

このプラットフォームは、Willison が提示するバイブコーディングのツールのスペクトルにおいて、初心者にとって安全な側の端に位置する。彼はこれを [[SoftwareApplication/cursor]] と対比する。Cursor は当初プロのデベロッパーに向けられたものであり、安全のための柵ははるかに少ないと彼は記述する。そして両者のあいだの隔たりを、人々が自分専用のツールを生産的にかつ安全に作れるようにするツール分野に、革新の余地があることの証拠として扱っている。

## 機能

出典が記述している機能はサンドボックスである。承認されたライブラリの集合に制限された `<iframe>` であり、他のサイトへの外向きのネットワークリクエストはブロックされる。ここで利用できる出典には、このプラットフォームの他の能力は記述されていない。
