Jules は Google Labs による非同期コーディングエージェントである。その枠づけはコード補完と並ぶものとしてではなく、それに対置するものとして設定されている。Google はこれを「副操縦士でもなく、コード補完の相棒でもなく、あなたのコードを読み、あなたの意図を理解し、仕事に取りかかる自律的なエージェント」と記述する。既存のリポジトリと直接統合し、コードベースを安全な Google Cloud の仮想マシンへクローンし、開発者が別のことをしているあいだにバックグラウンドで作業し、完了時にはその計画、推論、そして加えた変更の差分を提示する。

Google が挙げるタスクは、テストの作成、新機能の構築、音声による変更履歴の提供、バグの修正、依存関係のバージョン更新である。パブリックベータの時点では Gemini 2.5 Pro 上で動作しており、Google はこれによって最も先進的なコーディングの推論能力の一端が利用できると述べている。導入時には「Gemini 2.0 を使う」実験的なエージェントとして記述され、Python と JavaScript のコーディング作業に限られていた。

## 概要

Google が強調する設計上の選択は、作業がどこで行われるか、そしてそのどれだけを開発者が目にするかに関わるものである。Jules はデフォルトでプライベートであるとされ、プライベートなコードで訓練を行わず、データは実行環境の内側に隔離される。Google は「サンドボックスを必要としない」と主張し、既存プロジェクトの完全な文脈を取り込んで変更について推論すること、そしてタスクをクラウド VM の内側で実行することで複数のリクエストの同時実行が可能になることを述べている。制御については、変更を加える前に計画と推論を示し、開発者がその計画を実行の前・最中・後に修正できるようにする。導入時の記事は、包括的な多段階の計画を作り、複数のファイルを変更し、修正を GitHub へ戻すためのプルリクエストを準備するものとして記述していた。

GitHub との統合が接点として提示されている。Jules は「あなたがすでに働いている場所、すなわち GitHub のワークフローの内側で直接働く」のであり、Google の記述によればコンテキストの切り替えも追加のセットアップも要らない。音声の変更履歴はより珍しい機能である。直近のコミットの音声要約であり、プロジェクトの履歴を開発者が聴けるものへ変える。

これらは自社製品についての Google 自身の主張であり、公開とベータの告知においてなされたものである。ここでの出典にはそれらの独立した評価は含まれておらず、導入時の記事自身が「Jules は誤りを犯すことがある」という留保を付していた。

## 機能

- 安全な Google Cloud の VM へのクローンを伴うリポジトリ統合。
- 非同期のバックグラウンド実行と、VM 内での同時タスクの並列実行。
- 変更の前に提示される可視の計画と推論、そして完了時の差分。
- ユーザーによる操縦可能性。計画は実行の前・最中・後に修正できる。
- プルリクエストの準備を含む GitHub ワークフローとの統合。
- 直近のコミットの音声変更履歴。
- デフォルトでプライベート。プライベートなコードでの訓練はなく、データは実行環境に隔離される。

## 沿革

Jules は2024年12月に Google Labs において、[[Organization/google]] の「The next chapter of the Gemini era for developers」の記事のなかで、信頼されたテスターの限られたグループに提供される実験的な AI 駆動のコードエージェントとして導入され、他の関心ある開発者へのより広い提供が2025年初頭に約束された。同記事はこれをこの分野についてのより広い主張のなかに位置づけ——「AI によるコード支援が単純なコード検索から開発者のワークフローに組み込まれた AI 駆動のアシスタントへ急速に進化するなかで、Gemini 2.0 を使う最新の進展を共有したい」——、あわせてコード実行ツールを備えた Gemini 2.0 Flash による [[Dataset/swe-bench]] Verified での 51.8% という研究結果を報告している。

2025年5月20日、Jules は [[BlogPosting/build-with-jules]] においてパブリックベータへ入り、待機リストなしで誰でも、Gemini モデルが利用可能な世界中の地域で使えるようになった。そこでの Google の枠づけは、「エージェント的な開発はプロトタイプから製品へ移りつつあり、急速にソフトウェアの作られ方の中心になりつつある」というものだった。ベータ期間中のアクセスは利用上限付きで無償であり、Google はプラットフォームの成熟に伴いベータ後に価格を導入する見込みだと述べていた。
