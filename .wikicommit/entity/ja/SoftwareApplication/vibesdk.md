Cloudflare VibeSDK は、Cloudflare が MIT ライセンスのもとで公開しているオープンソースのプラットフォームで、AI コーディングエージェントと協働してフルスタックアプリケーションを構築・デプロイするためのものである。ユーザーは作りたいものを説明し、エージェントからの確認の質問に答え、エージェントが計画を立て、ファイルを編集し、プレビューをデプロイし、エラーを調べ、ユーザーを交えながら反復していく様子を見守る。リポジトリはこれを、Cloudflare スタックのみで構築された、「独自のバイブコーディングプラットフォームの構築を支援する」オープンソースの [[DefinedTerm/vibe-coding]] プラットフォームと説明している。Cloudflare は build.cloudflare.dev で公開インスタンスを運用しており、プロジェクトは独自のインスタンスをデプロイする方法を文書化している。

## 機能

生成は段階的ではなくエージェント型である。README は、生成フェーズの固定された順序ではなく、モデルとツールのループを通じて反復的に構築すると説明している。エージェントは、要求が十分に特定されていない場合に構造化された質問をすることができ（[[DefinedTerm/human-in-the-loop]] による確認）、自身の出力、ツールの動作、ファイルの変更、デプロイの状況をインターフェースにストリーミングし、生成されたファイルを統合コードエディタに表示する。エージェントは明示的なツール ― ワークスペースの読み取りと編集、復元ポイントの作成、プレビューのデプロイ、ブラウザログの調査、質問 ― を通じて作業し、bash へのアクセスは無効化されている。

README は、エージェントのワークフローを 7 つのステップとして示している。要求を理解する（重要な詳細が欠けている場合は質問する）、ファイルを作成・編集して構築する、一貫性のある復元ポイントを保存する、現在のブランチをコミットしてバンドルしプレビューとしてデプロイする、ライブプレビューとそのブラウザコンソールの出力を調べて検証する、ビルドエラーや実行時エラーを修復してデプロイと検証のループを繰り返す、そして全体を通じて進捗をインターフェースにストリーミングする、というものである。生成された各アプリケーションには、ユーザーが調べたりリセットしたりできる、SQLite を基盤とした独自の分離されたストレージが与えられる。ロールバックは履歴を書き換えるのではなく、選択したコミットを新しいコミットとして復元する。完成したプロジェクトはエクスポートして、VibeSDK の外で開発を続けることができる。

これらはすべて Cloudflare のサービス上で動作する。Cloudflare Think 上に構築され Durable Object に支えられたエージェントがモデルとツールのループを実行し、別の Durable Object が各プロジェクトの分離されたワークスペースとファイルを提供し、Cloudflare Artifacts が git の履歴と復元ポイントを保持する。生成されたコードはバンドルされて Dynamic Worker のプレビューとして読み込まれるため、常時稼働する開発サーバーは必要ない。生成された各アプリのデータは Durable Object Facet に置かれ、モデルプロバイダーへのリクエストは AI Gateway を経由してルーティングされ、これにより一元的なオブザーバビリティとキャッシュが加わる。README は、これによって得られる分離を挙げている。各アプリはそれぞれ独自のエージェント、ワークスペース、Artifacts リポジトリ、ストレージを持ち、プレビュー URL には署名付きでブランチ単位にスコープされたアクセスが用いられる。

## 導入とエコシステム

独自のインスタンスを運用するには、関連する Workers の機能が使える Cloudflare アカウント、Cloudflare の API トークン、そしてプロバイダーのキーを AI Gateway に保存しない限り、サポートされている少なくとも 1 つのモデルプロバイダーの認証情報が必要である。本番環境のプレビューにはさらに Workers for Platforms へのアクセスを含む Workers Paid プランが必要であり、本番デプロイにはワイルドカード DNS を設定したカスタムドメインが必要である。ローカル開発には Node.js と Bun を使用し、Cloudflare のリソース、AI Gateway、モデルプロバイダー、認証、データベースのマイグレーションを設定するセットアップスクリプトが用意されている。
