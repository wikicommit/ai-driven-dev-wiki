MetaGPT は、MIT ライセンスのオープンソースのマルチエージェントフレームワークであり、異なる LLM に異なるロールを与え、それらを「複雑なタスクのための協働的な実体」として協力させるという発想に基づいている。README はこの実体をソフトウェア会社になぞらえている。MetaGPT は 1 行の要求を入力として受け取り、ユーザーストーリー、競合分析、要件、データ構造、API、ドキュメントを生成するものであり、その内部のロールとしてプロダクトマネージャー、アーキテクト、プロジェクトマネージャー、エンジニアが置かれている。プロジェクトはその哲学を `Code = SOP(Team)` ── 標準作業手順を具体化し、LLM で構成されたチームに適用すること ── と要約しており、このソフトウェア会社の構想図は段階的に実装されているところだと説明している。MetaGPT は [[DefinedTerm/llm-based-multi-agent-system]] の一例であり、そのリポジトリは現在 GitHub 上の `FoundationAgents` オーガニゼーションの下で公開されている。

## 機能

MetaGPT は `pip install metagpt` でインストールする Python パッケージであり、実行時には Node.js と pnpm も必要とする。モデルへのアクセスは `~/.metagpt/` 以下の YAML ファイルで設定し、そこで API の種類（OpenAI、Azure、Ollama、Groq など）、モデル、エンドポイント、キーを指定する。コマンドラインから操作することができ（`metagpt "Create a 2048 game"` でローカルのワークスペースにリポジトリが生成される）、生成されたプロジェクトのリポジトリを返すライブラリとして使うこともできる。ソフトウェア会社のパイプラインに加えて、プロジェクトはデータ分析などのタスクのためにコードを書いて実行する **Data Interpreter** エージェントも提供している。また、そのドキュメントでは単一のエージェントやマルチエージェントシステムの構築方法を順を追って解説しており、ユースケースとしてエージェント同士のディベート、リサーチャー、レシートアシスタントなどが含まれている。

## 採用とエコシステム

同じチームは、ホスト型の自然言語プログラミング製品である MGX（MetaGPT X）を運営している。README はこれが 2025 年 2 月 19 日にローンチされたと告知し、「世界初の AI エージェント開発チーム」と説明している。README はまた、チームによるその他の研究論文を紹介しており、MetaGPT を出版物で利用する人に対して、MetaGPT について記述したチームの論文を引用するよう求めている。
