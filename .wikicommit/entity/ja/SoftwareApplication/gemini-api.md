Gemini API は、[[Organization/google]] の Gemini モデルへのホスト型インターフェースである。ツールに関するそのドキュメントは、ツールを、モデルがクエリに答えるために使える特定の機能（Google 検索やコード実行など）と説明し、Gemini モデルが現実世界で行動し、リアルタイムの情報にアクセスし、複雑な計算タスクを実行できるようにするものとして位置付けている。ツールは、標準的なリクエスト・レスポンス型のやり取りでも、API の Live API を通じたリアルタイムのストリーミングセッションでも使用できる。

API は 2 種類のツールを提供する。完全マネージドの組み込みツール群と、開発者が関数呼び出しを使って定義するカスタムツールである。多段階でゴール指向のシステムについては、ドキュメントはツールそのものではなく、別のエージェントの概要ページを案内している。

## 機能

組み込みツールは、それぞれの想定用途とともに次のように挙げられている。

- **Google Search** — Web 上の最新の出来事や事実に基づいて応答をグラウンディングする。ハルシネーションを減らすことが目的として述べられている。
- **Google Maps** — 場所を探し、道順を示し、地域の文脈を提供する、位置情報を活用したアシスタントを構築する。
- **Code Execution** — モデルに Python コードを書かせて実行させ、数学の問題を解いたりデータを正確に処理したりする。
- **URL Context** — 特定の Web ページやドキュメントの内容を読んで分析するようモデルに指示する。
- **コンピュータ操作（Computer Use）**（プレビュー） — Gemini が画面を見て、Web ブラウザのインターフェースを操作するアクションを生成できるようにする。アクションはクライアント側で実行される（[[DefinedTerm/computer-use]] を参照）。
- **File Search** — 開発者自身のドキュメントをインデックス化・検索し、検索拡張生成を可能にする。

ツール呼び出しがどのように実行されるかは、それがどちらの種類かによって決まる。これは [[DefinedTerm/client-and-server-tools]] で説明されている区分である。コンピュータ操作以外の組み込みツールでは、処理全体が 1 回の API 呼び出しの中で完結する。Gemini はツールが必要だと判断し、それを Google のサーバー上で実行し（ドキュメントの例では、株価を検索してから Python を実行してその平方根を求める）、結果に基づく最終回答を返す。カスタムツールとコンピュータ操作では、実行はアプリケーション側が担う。Gemini は特定の関数を呼び出す構造化 JSON を返すことがあり、そこには常に一意の `id` が含まれる。アプリケーションはその関数を実行し、同じ `id` を付けて結果を送り返す。Gemini はそれを使って最終応答または次のツール呼び出しを生成する。bash とカスタムツールを組み合わせて構築する開発者向けには、別のプレビュー版エンドポイント `gemini-3.1-pro-preview-customtools` が提供されている。

プレビュー機能として、Gemini 3 シリーズのモデルは 1 回のターンで組み込みツールとカスタムツールを組み合わせることができ、ドキュメントはこれをツールコンテキストの循環（tool context circulation）と呼んでいる。開発者は宣言したツールと併せて組み合わせ用のフラグを有効にする。Gemini は組み込みツールを実行し、クライアント側の関数呼び出しを生成した時点でアプリケーションに制御を渡す。その際、ツール呼び出しの確認、組み込みツールの結果、カスタム呼び出しの JSON、そしてコンテキストを保持する暗号化された思考シグネチャを返す。アプリケーションはその応答のすべてのパートを自身の関数の結果とともに返し、Gemini は統合されたコンテキストから最終回答を生成する。

ドキュメントは、関数呼び出しと構造化出力を目的によって区別している。関数呼び出しは、モデルが開発者自身のツールやデータシステムに接続して中間ステップを実行する必要がある場合のためのものであり、構造化出力は、たとえばカスタムインターフェースを描画するために、モデルの最終応答が特定のスキーマに厳密に従わなければならない場合のためのものである。Gemini 3 シリーズのモデルでは、プレビュー機能として構造化出力を組み込みツールと組み合わせることができ、外部データや計算に基づく応答であっても厳密なスキーマに従わせることができる。

## 導入とエコシステム

ツールのドキュメントは、各組み込みツールのガイド、関数呼び出しのガイド、ツールの組み合わせのガイドへのリンクを示しており、一部のツールには API の料金ページに記載された独自の費用がかかることを注記している。
