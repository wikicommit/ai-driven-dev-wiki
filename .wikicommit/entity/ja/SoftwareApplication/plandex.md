Plandex は、ターミナルで動作するオープンソースの [[DefinedTerm/ai-coding-agent]] である。プロジェクトはこれを、多数のステップにまたがり数十のファイルに手を入れる大規模なコーディングタスクを計画・実行できる開発ツールと説明し、大規模プロジェクトと実世界のタスクのために設計されていると述べている。README は、プロジェクトが一定の規模を超えたり変更が複雑になりすぎたりすると苦戦するとするツールと対比して、Plandex を位置づけている。

依存関係のない 1 行の CLI インストールと、ローカルの Docker で動かすことも利用者自身のマシンでホストすることもできるサーバーとを組み合わせて配布されている。CLI は `plandex` として呼び出し、短縮形として `pdx` も使える。リポジトリは MIT ライセンスで公開されている。Windows は WSL 経由でのみサポートされており、プロジェクトは Plandex が Windows のコマンドプロンプトや PowerShell では正しく動作しないと明言している。

## 機能

プロジェクトが最初に挙げる機能はコンテキストの扱いである。デフォルトのモデルパックでは実効コンテキストウィンドウが 200 万トークン（1 ファイルあたりおよそ 10 万トークン）であるとし、Plandex は各ステップに必要なものだけを読み込むと述べている。2,000 万トークン以上のディレクトリは tree-sitter のプロジェクトマップを使ってインデックス化される。プロジェクトはこれを構文検証にも用いており、30 以上の言語をカバーするとしている。OpenAI、Anthropic、Google のモデルではコンテキストキャッシュが使われ、プロジェクトによればこれによりコストとレイテンシが削減される。

変更はプロジェクトに直接書き込まれるのではなく、いったんステージングされる。README はこれを累積差分レビューサンドボックスと呼んでいる。AI が生成した変更は、適用できる状態になるまでプロジェクトのファイルとは分けて保持され、コマンドの実行も制御されているため、実行をロールバックしてデバッグできる。プロジェクトはこれを、エージェントがコードベースを散らかしたままにするのを防ぐ仕組みとして提示している。

自律性は固定ではなく設定可能である。プロジェクトは、Plandex が完全な自律動作、すなわち関連ファイルの読み込み、変更の計画と実装、コマンドの実行、自動デバッグをこなせる一方で、必要に応じてきめ細かな制御と段階的なレビュープロセスも提供すると述べている。自動デバッグの対象は、ビルド、リンター、テスト、デプロイ、スクリプトといったターミナルコマンドであり、Chrome がインストールされている場合はブラウザアプリケーションも含まれる。

実装と並んで、プロジェクトを把握したチャットモードがある。プロジェクトはこれを、実装に移る前にアイデアを具体化したり、コードベースについて質問したりするための手段と説明している。複数のプロバイダーのモデルを組み合わせることができ、能力・コスト・速度のトレードオフが異なる厳選されたモデルパックが提供されている。その中にはオープンソースのパックやプロバイダー固有のパックも含まれる。プロジェクトはファイル編集について、正確さを優先し、必要に応じて構文とロジックの両方を検証し、問題が生じた場合には複数のフォールバック層を備えていると説明している。

プランへの更新はすべて独自のバージョン管理下に置かれ、複数の道筋を探ったり異なるモデルを比較したりするためのブランチも使える。これと並んで、コミットメッセージの生成と任意の自動コミットを備えた git 統合がある。開発者向けのインターフェースは、コマンドやファイル読み込みのためのあいまい一致による自動補完を備えた REPL と、スクリプトからの利用やデータのコンテキストへのパイプ入力のための CLI である。

## 採用とエコシステム

Plandex は、利用者が用意したモデルプロバイダーに対して実行される。プロジェクトは選択肢の 1 つとして OpenRouter.ai のキーを文書化しており、代替手段として他のモデルプロバイダーのアカウントや API キーを挙げている。また、Anthropic モデルの呼び出しには Claude Pro または Max のサブスクリプションを接続でき、初回実行時に接続を促すプロンプトが表示されると述べている。

README が挙げる 2 つのホスティング方式のうち、マネージド型のほうは終了しつつある。README によれば、Plandex Cloud は 10/3/2025 をもって段階的に終了しており、新規ユーザーの受け付けも停止している。残る選択肢は、セルフホストおよびローカルモード（ローカルの Docker、または利用者自身のインフラ上のサーバー）である。

プロジェクトは GitHub 上でオープンに開発されており、フィードバックや質問の場として Discord サーバー、GitHub Discussions、イシュートラッカーが挙げられている。ドキュメントは別途 docs.plandex.ai でホストされている。
