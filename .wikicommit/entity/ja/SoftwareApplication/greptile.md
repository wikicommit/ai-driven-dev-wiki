Greptile は、プルリクエストで使われる AI コードレビューサービスである。[[BlogPosting/redesigning-code-review-for-the-ai-era]] では、あるチームが GitHub Copilot および [[SoftwareApplication/claude-code-action]] と並行して運用した 3 つの AI レビュアーの 1 つとして説明されており、同記事の著者が個人的な好みとして名前を挙げているのがこれである。

同記事がこのサービスについて記録しているのは、指摘を投稿するだけにとどまらない一連の機能である。コメントに返信し、プルリクエスト上で相談することができ、設計の意図について議論でき、そして受け取ったレビューコメントやリアクションから学習して、そこからカスタマイズルールを生成する。

## 機能

- プルリクエストをレビューしてコメントを投稿する。同記事はそのレビューの質を高く評価し、重要な点に集中していると特徴づけている。
- プルリクエスト上での会話をサポートする。コメントに返信したり相談したりすることができ、同記事はこれを人間のレビュアーと仕事をすることになぞらえている。また、設計思想について議論することもできる。
- 蓄積されたコメントやリアクションから学習し、そこからカスタマイズルールを自動生成する —— これは、人間のレビュアーのように返信し相談できる点と並んで、同記事の著者が Greptile を 3 つの中で個人的に最も気に入っているものとして挙げる理由の 1 つである。
- セットアップは簡単と評価されている。レビューの速度は、最速の Copilot と遅い Claude Code Action に対して中程度と評価され、ドメインの理解は良好と説明されている。

## 採用とエコシステム

同記事のチームは、これを並行して運用する 3 つの AI レビュアーの 1 つとして使っている。これは分野がまだ定まっていない間の意図的な体制であり、表明されている狙いは、当面は複数のモデルに異なる角度から見てもらうことで、同記事によれば、チームは後にどのサービスを使い続けるかを評価して選ぶかもしれない。その比較の中で、チームのメンバーが最も高く評価しているとされるのは Greptile と Claude Code Action の 2 つであり、Copilot は最速で品質は中程度と評価されている。

同記事はまた、自らの利用から得た 2 つの注意点を記録している。Greptile のルールはすべてのリポジトリにまたがって適用されること、そして特定の 1 つのリポジトリ向けに設定するのが難しいことである。
