Hello-Agents は、AI エージェントの構築に関するオープンソースのチュートリアルで、Datawhale コミュニティが
《从零开始构建智能体》というタイトルで中国語で公開しており、英語では *Hello-Agents:
Building an AI Agent from Scratch* として引用される。プロジェクトのリポジトリ、オンライン閲覧サイト、
ダウンロード可能な PDF リリースを通じて無料で配布されており、ライセンスは CC BY-NC-SA 4.0 である。

序文が掲げる前提は、2024 年が基盤モデル競争の年だったとすれば、2025 年は「エージェントの年」の幕開けであり、
技術の焦点がより大きな基盤モデルの学習から、より高性能なエージェントアプリケーションの構築へと移った一方で、
体系的で実践重視のチュートリアルは依然として極めて乏しい、というものである。本プロジェクトは、
その空白を埋めるものとして自らを位置づけている。

対象範囲は、序文が 2 種類のエージェント構築の間に引く区別によって絞り込まれている。
一方はソフトウェアエンジニアリング型で、Dify、Coze、n8n がその例とされ、LLM がデータ処理のバックエンドとして
機能する、プロセス駆動のソフトウェア開発だと特徴づけられている。もう一方は AI ネイティブ型で、
真にモデルによって駆動されるものである。本チュートリアルは後者を扱うと明言しており、その目標を、
読者をフレームワークの表層から中核となる原理、アーキテクチャ、古典的なパラダイムへと導き、
最終的に独自のマルチエージェントアプリケーションを構築させることだと説明している。

## 内容

本書は 5 部 16 章からなり、リポジトリ上ではすべての章が完成済みとされている。
第 1 部はエージェントと言語モデルの基礎を扱う。エージェントとは何か、その種類とパラダイム、
記号的 AI から LLM 駆動のエージェントに至る歴史、そして Transformer、プロンプティング、主要な LLM と
その限界についての章が含まれる。第 2 部は実践の中核で、ReAct、Plan-and-Solve、Reflection を
手作業で実装し、次にローコードプラットフォーム（Coze、Dify、n8n）、続いて主要なフレームワーク
（AutoGen、AgentScope、LangGraph）を扱い、最後にエージェントフレームワークをゼロから構築する。
第 3 部はメモリと検索、[[DefinedTerm/context-engineering]]（コンテキストエンジニアリング）、
[[DefinedTerm/model-context-protocol]]、A2A、ANP を含むエージェント間通信プロトコル、
SFT から GRPO までの Agentic RL、そしてエージェントの性能評価へと話を広げる。第 4 部は 3 つの統合プロジェクトで、
旅行アシスタント、自動化されたディープリサーチエージェント、そして社会的ダイナミクスをモデル化した
エージェントによる「サイバータウン」のシミュレーションからなる。第 5 部は総仕上げで、
読者が自分自身の完全なマルチエージェントアプリケーションを構築する。

本文とは別に、リポジトリにはコミュニティが寄稿した *Extra-Chapter* シリーズも収められている。
エージェント関連職の面接質問集、コンテキストエンジニアリングの補足、Dify の解説、
[[DefinedTerm/agent-skills]] と MCP の比較、GUI エージェントと Web エージェントの入門、
良い Skill の書き方の指針、エージェントアプリケーション開発における実践上の落とし穴集、
そしてエージェントの自己進化に関する章である。

後半の部は、プロジェクトが HelloAgents と呼ぶ自作のフレームワークを通じて進められる。これは OpenAI の
ネイティブ API の上にゼロから構築されたもので、その後 v1.0.0 に更新されたと説明されている。第 3 部では、
サードパーティのフレームワークではなく、第 2 部で作ったこのフレームワークを使うと明記されている。

## 登場人物と出版

本書は Datawhale コミュニティのプロジェクトであり、リポジトリでは完全にオープンソースかつ無料と説明されている。
GitHub、中国国内の読者向けに別ミラーを備えたオンライン閲覧サイト、そして PDF リリースを通じて配布されている。
プロジェクトによれば、PDF には Datawhale の透かしが入っており、これは無料の教材を転売業者が再パッケージして
販売するのを防ぐために付けられたものだという。

リポジトリが示す引用情報では、年を 2025 年とし、「all Hello-Agents contributors」（すべての Hello-Agents
貢献者）の前に 7 名の貢献者を挙げている。リポジトリ自身の謝辞は、それらの名前の背後にある役割を説明している。
全文を担当したプロジェクトリーダー、それぞれ 1 章と演習問題を寄稿した 2 名の共同発起人、
複数の章の寄稿者、そして学術アドバイザーであり、さらに Extra-Chapter の資料について別の名前付きの
貢献者たちにも謝意を示している。リポジトリの今後の計画一覧には、エージェントをゼロから学習させることを
扱う続編が、動画講座や HelloAgents フレームワークのさらなる開発と並んで挙げられている。
