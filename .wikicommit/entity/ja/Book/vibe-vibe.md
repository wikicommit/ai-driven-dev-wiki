Vibe Vibe は [[DefinedTerm/vibe-coding]] に関するオープンソースのチュートリアルであり、中国語で
《Vibe Vibe —— 人人都能学会的 AI 编程（Vibe Coding）指南》（「誰でも学べる AI プログラミングガイド」）という
タイトルで書かれ、Datawhale コミュニティの GitHub 上の `datawhalechina` オーガニゼーションから公開されている。
vibevibe.cn でオンライン閲覧でき、ライセンスは CC BY-NC-SA 4.0 である。想定読者として掲げられているのは
プログラミング経験のない学習者 — 学生、起業家、社会人、さらに新しい働き方を学びたい従来型のプログラマー — であり、
「アイデアがある」段階から「プロダクトを作り上げた」段階まで彼らを導き、誰もがビルダーになれるようにすることを
目的として掲げている。

このチュートリアルは、Andrej Karpathy によるバイブコーディングの概念を枠組みとしており、それを「Coder から
Commander へ」の移行と言い表している。つまり、プログラミングはコードを書くことから、自然言語で AI に指示を出す
対話的な創作へと変わる、というものである。本書は自らを中国初の体系的なオープンソースのバイブコーディング・
チュートリアルと位置付けており、その動機として、バイブコーディングが世界的なトレンドとなった今、中国語の学習
教材が断片的な状態にあることを挙げている。

## 内容

チュートリアルは 4 つの部で構成されており、それぞれ異なる読者を対象としている。

- **基礎篇**（基础篇）は、すべての人に向けた入門である。5 つの章は、今がプログラミングを始める最良の時である理由
  — バイブコーディングと「スペックコーディング」を解説する章や、Cursor、Windsurf、Bolt.new、Replit などの
  ツールの比較を含む — から始まり、プロダクトマネージャーのように考えること（最小限の実用的な製品、つまり MVP、
  そしてユーザーは誰か、ペインポイントは何かという問い）、AI と対話する技術（「Context is King」という見出しの
  もとでのプロンプトの基本、ユーザージャーニーマップ、最初の PRD の作成、機能の P0・P1・P2 への優先順位付け）、
  個人用ツールを 3 ラウンドで作るハンズオン、そして最後に、壊れたコードからの復旧、Web への公開、セキュリティ
  意識、バイブコーディングにできることとできないことの限界へと進む。
- **進階篇**（进阶篇）は、よくある落とし穴を避けながら完全なプロダクトを「ゼロからローンチまで」届けるための、
  16 章からなるガイドである。PRD とドキュメント駆動開発、環境変数とセキュリティ、データベース、テスト、Git、
  サーバーレスデプロイと CI/CD、ドメイン、サーバー運用、SEO とアナリティクス、ユーザーフィードバックに基づく反復
  などを扱う。Next.js、React、TypeScript、Tailwind CSS、shadcn/ui、Drizzle ORM、PostgreSQL の技術スタックを
  軸に構成されている。
- **実践篇**（实践篇）は、読者層ごと — 人文系・ビジネス系の学生、理工系の学生、社会人 — に分類したプロジェクト
  集と、デプロイ、データベースと認証、RAG と MCP を用いた AI エージェント開発、フルスタックプロジェクト、
  ワークフローツールを扱う上級編を収めている。
- **優良記事篇**（优质文章篇）は、継続的な学習のために、企業のエンジニアリングブログ、ポッドキャスト、調査
  レポート、ニュースレター、開発者コミュニティをまとめている。

README は、経歴に応じて異なる出発点を勧めている。まったくの初心者は第 1 章から、ChatGPT を使ったことはあるが
プロジェクトを作ったことのない読者はプロダクトマネージャーのように考える章から、プログラミング経験のある読者は
基礎篇にざっと目を通してから進階篇へ進む、というものである。

## 公開形態

ホスティングされたサイトのほかに、リポジトリには Dockerfile と Docker Compose の設定が同梱されており、
チュートリアルのサイトをローカルネットワークやイントラネット上にプライベートにデプロイできる。プロジェクトは
また、Node.js、Python、Docker の環境と 50 以上のプリインストール済み AI スキルを備えたクラウド IDE を中心とする
オンライン版を予告しており、学習者が何もインストールせずに始められるようにするとしている。
