ReAct は、Yao らが [[ScholarlyArticle/react-synergizing-reasoning-and-acting]] で提案したプロンプティング手法であり、エージェントの行動空間を、通常のタスク固有の行動に加えて自由形式の思考からなる「言語空間」で拡張するものである。思考はそれ自体では外部環境に作用せず、観測のフィードバックも生まない。その代わりに、現在のコンテキストから有用な情報を組み立て（目標の分解、進捗の追跡、例外の記録など）、後続の推論や行動を支えるようにコンテキストを更新する。この手法は、凍結された大規模言語モデルに少数のインコンテキスト例を与えてプロンプトすることで適用される。各例は人間が書いた、思考・行動・環境からの観測の軌跡であり、モデルの追加学習は一切必要としない。

## 用法

この手法は、インコンテキスト例をタスクごとに 1 セットずつ手で書くことで適用される。著者らは自分たちの例を、GPT-3 のプロンプティングコードの MIT ライセンスのリポジトリとして公開しており、タスクごとに 1 つのノートブックがあり、小さな Wikipedia 環境が検索（search）と参照（lookup）の行動を提供している。そのリポジトリは、収録している 4 つ以外のタスクに ReAct を適用したい読者を、自身のプロンプトではなく [[SoftwareApplication/langchain]] のゼロショット ReAct エージェントへと案内している。

この手法がモデルをまたいでどこまで通用するかについて、2 つの文書の読み方は異なる。論文の付録は 2 つのタスクで PaLM-540B と GPT-3（`text-davinci-002`）を比較し、どちらでも GPT-3 が上回ったとして、これを ReAct プロンプティングが異なる大規模言語モデルにわたって有効であることの証拠と読んでいる。リポジトリの表は 4 つのタスクを扱い、GPT-3 は 2 つで上回り残りの 2 つで下回っており、リポジトリはこれを、2 つのモデルが得意とするタスクが異なると要約している。

## 適用される場面

提案論文は、行動空間と推論の必要性が異なるタスクに ReAct を適用している。知識集約型のタスク（マルチホップ質問応答、事実検証）では思考と行動のステップを密に交互させ、単純な Wikipedia の検索・参照インターフェースとやり取りして裏付けとなる情報を取得する。対話的な意思決定タスク（テキストベースの家庭内シミュレーションとオンラインショッピング環境）では、思考をよりまばらに、軌跡の中で最も役立つ地点に現れるようにし、いつ思考しいつ行動するかは言語モデル自身が決める。論文は、ReAct が行動のみのベースラインを一貫して上回ったと報告している。推論のみの Chain-of-Thought に対しては、事実検証では上回ったがマルチホップ質問応答ではわずかに下回り、この 2 つのタスクでの論文の最良の結果は、ReAct 単独ではなく ReAct と自己整合性（self-consistency）推論を組み合わせたものから得られた。また、先行する「Inner Monologue」手法をモデルにした、密で外部からトリガーされる思考を用いるアブレーションは、家庭内シミュレーションのタスクにおいて、ReAct のよりまばらで柔軟な思考パターンを下回ったことも報告している。論文自身が述べる限界は、行動空間の大きなタスクではうまく学習するためにより多くのデモンストレーションが必要になり、それがインコンテキストのプロンプティングの入力長の上限を超えうることである。

論文の中のさらに 2 つの結果は、プロンプティングの設定を超えてこの手法がどう使われるかに関わっており、著者らは自身の Google Research のブログ記事でその両方をあらためて述べている。1 つ目は、いま挙げた限界に対するファインチューニングという答えである。ReAct でプロンプトされた PaLM-540B モデルが生成した成功した軌跡を使って、より小さな PaLM-8B と PaLM-62B のモデルをファインチューニングする。これにより推論トレースを大規模に手作業でアノテーションすることが避けられ、ファインチューニングの下では ReAct が最も性能の高い手法だと報告されている。2 つ目は、人間が軌跡に介入できることである。エージェントの思考のうち 2 つを編集する（ハルシネーションを起こしている思考を 1 つ削除し、ヒントを 1 つ加える）だけで、その後の振る舞いが変わり、それまで失敗していた家庭内シミュレーションのタスクを完了させるのに十分だった。著者らはこれを、編集すべき思考がわずかで済むという事実によって実用的になった、人間と機械の協働の一形態として示している。
