構造化ノートテイキング（Structured note-taking）は、エージェント的メモリ（agentic memory）とも呼ばれ、エージェントが定期的にノートを書き、それをコンテキストウィンドウの外のメモリに永続化し、後の時点でコンテキストウィンドウに引き戻す手法である。Anthropic はこれを、最小限のオーバーヘッドで永続的なメモリを提供するものとして提示している。このパターンにより、エージェントは複雑なタスク全体にわたって進捗を追跡し、数十回に及ぶツール呼び出しの中で失われてしまうはずの重要なコンテキストや依存関係を保持できる。

## 用法
Anthropic はこのパターンの 2 つの形を挙げている。[[SoftwareApplication/claude-code]] が to-do リストを作成することと、カスタムエージェントが NOTES.md ファイルを維持することである。また、コーディング以外の領域でのこの手法のデモンストレーションとして Claude がポケモンをプレイする例を挙げている。そこではエージェントが数千のゲームステップにわたって正確な集計を維持する — 例えば、ある場所でトレーニングに何ステップを費やし、それによって目標に向けてレベルがいくつ上がったかを追跡する。Anthropic の報告によれば、メモリの構造についてのプロンプトが一切なくても、エージェントは探索した地域のマップを作り、どの主要な達成項目を解放したかを覚え、さまざまな相手にどの攻撃が最も効くかについての戦略的なノートを維持するようになる。コンテキストのリセット後には自分のノートを読み、数時間に及ぶトレーニングの流れやダンジョン探索を続ける。Anthropic はこれを、すべての情報をコンテキストウィンドウだけに保持していたのでは不可能な長期的戦略を可能にするものだと説明している。

Anthropic はまた、Claude Developer Platform 上でメモリツールをパブリックベータとして公開している。これはファイルベースのシステムを通じて、コンテキストウィンドウの外で情報を保存・参照するものである。Anthropic は、これによりエージェントが時間をかけて知識ベースを構築し、セッションをまたいでプロジェクトの状態を維持し、すべてをコンテキストに保持することなく過去の作業を参照できるようになると述べている。

## 適用される場面
- 明確なマイルストーンをもつ長期的な作業に適用される。Anthropic は、ノートテイキングは反復的な開発で優れているとしており、広範なやり取りを必要とするタスクに推奨する [[DefinedTerm/compaction]] と対比している。
- コンテキストウィンドウの外にある永続化の場所と、ノートを読み戻す仕組み — エージェントが書いて読み直すファイル、またはプラットフォームのメモリツール — を前提とする。
- Anthropic 自身の実践として確立されており、Claude Code の to-do リスト、Claude がポケモンをプレイするデモンストレーション、パブリックベータのメモリツールがその裏づけとなっている。ポケモンの事例は Anthropic が報告するデモンストレーションであり、統制された測定ではない。
