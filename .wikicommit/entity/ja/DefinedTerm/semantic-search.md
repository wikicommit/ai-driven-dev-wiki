[[Organization/anysphere]] が説明するコーディングエージェントの文脈におけるセマンティック検索とは、「grep のようなツールが提供する正規表現ベースの検索に加えて、『認証はどこで扱っているか？』といった自然言語のクエリに合致するコード断片を取得する」検索ツールである。これは字句検索の代替としてではなく、[[SoftwareApplication/cursor]] のエージェントがプロンプトを受け取ったときにコードベースの理解を組み立てるために使うツールの一つとして提供されている。[[BlogPosting/improving-agent-with-semantic-search]] における Cursor の結論は、同社のエージェントは「セマンティック検索と同様に grep も多用しており、この2つの組み合わせが最良の結果をもたらす」というものである。

## 用法

このツールを支持する Cursor の論拠は実証的なものであり、その数値は同社自身のものである。同社は独自の埋め込みモデルを学習させ、高速な検索のためのインデックス作成パイプラインを構築したと報告し、セマンティック検索がとりわけ大規模なコードベースにおいてエージェントの性能を著しく改善すると主張する。質問への回答の正確性が平均 12.5% 向上（モデルにより 6.5%〜23.5% の幅）、コード変更がコードベースに残される割合の上昇、ユーザーが正しい解に到達するまでの反復回数の減少、そしてフロンティアのコーディングモデルすべてを含むテストしたあらゆるモデルでの正確性の改善である。

これらの数値は2種類の測定から得られており、効果量は異なって報告されている。[[Dataset/cursor-context-bench]] に対するオフライン評価は、Cursor で最もよく使われているモデル全体にわたって、セマンティック検索を含むツールセットと含まないツールセットを比較したもので、Cursor はすべての構成においてセマンティック検索が結果を有意に改善したと述べている。オンライン A/B テストは、両グループが同じモデルを使い、片方のエージェントだけがセマンティック検索を利用できるというもので、より小さな数値をもたらした。コードの残存率は全体で 0.3%、1,000 ファイル以上のコードベースでは 2.6% の上昇、そしてセマンティック検索が使えない場合に不満を示すユーザーの追加リクエストが 2.2% 増加した。Cursor はこの差を、A/B テストがエージェントへの全クエリを対象にしており、すべてのリクエストが検索を要するわけではないためだと説明している。

Cursor が説明する学習の手法こそ、そのモデルを汎用的なコード類似度から区別するものである。エージェントのセッションを学習データとして用いる。タスクに取り組むエージェントは正しいコードにたどり着くまでに複数回の検索を行いファイルを開くため、それらのトレースを分析すれば、会話のより早い段階で何を取得すべきだったかが事後的に見えてくる。Cursor はトレースを LLM に与え、各ステップでどの内容が最も役に立ったはずかをランク付けさせ、その後、埋め込みモデルの類似度スコアをそのランキングに整合させるよう学習させる——これを、エージェントが実際にコーディングのタスクをどう進めるかから学ぶフィードバックループだと説明している。

Cursor はこの必要性を恒久的なものではなく現時点のものとして枠づけている。セマンティック検索は「特に大規模なコードベースにおいて、最良の結果を得るために現時点では必要である」とし、モデルの改善に伴い、エージェントハーネスに与えるすべてのツールを引き続きテストし評価していくと述べている。

### コード検索の外にある同じ組み合わせ

Cursor の「grep ＋セマンティック検索」という結論には、一般的な検索の実践において直接の対応物がある。[[DefinedTerm/retrieval-augmented-generation]] に関する Wikipedia の記述は、**ハイブリッド検索** を、Cursor の数値が示唆するまさにその弱点を緩和する一つの方法として説明している。ベクトルデータベースの検索——これをセマンティック検索の技法と同一視している——は「ユーザーの質問に答えるのに必要な重要な事実を取り逃しうる」ため、一つのアプローチは従来の全文検索も走らせ、その結果を取得されたベクトルに紐づくテキストチャンクと統合し、統合されたテキストを生成のためにモデルに与えることであり、その順序づけにはスコアリングや再ランキングを用いる、というものである。同じ記述はチャンキングについても、コードファイルは関数やクラス全体としてチャンク化しベクトル化するのが最良だと注記している。
