エージェント型プルリクエスト（Agentic-PR）とは、AI コーディングエージェントがリポジトリに提出するプルリクエストのことであり、これによってエージェントは現実のソフトウェア開発に直接参加する。[[ScholarlyArticle/why-are-agentic-pull-requests-merged-or-rejected]] は、この用語をオープンソースリポジトリへのエージェント作成の PR を指すものとして用いており、そうした PR が数千のリポジトリにまたがっていることを [[Dataset/aidev]] データセットの証拠から示している。また、*クローズされた* Agentic-PR を、マージかリジェクトかの明示的な決定を受けたものとして扱っている。

## 用法

この用語は、マイニングソフトウェアリポジトリ研究において、エージェントが作成した変更が人間のレビュアーと出会った後にどうなるかを調べるための分析単位として用いられる。同研究の説明では、Agentic-PR はマージ率や承認頻度といった結果ベースの指標で評価されることが多く、同研究の中心的な主張は、そうした結果だけではエージェントの能力を正しく表さないというものである。リジェクトはエージェントの失敗ではなく、ワークフロー上の制約や記録されていないレビュアーの判断を反映している場合があり、マージもレビュアーのフィードバックや人間が加えたコミットに依存している場合がある。手作業で精査したサンプルでは、リジェクトされた Agentic-PR のうち明確なエージェントの失敗が見られたのは 35.7% にとどまり、マージされたもののうち 15.4% には明示的なレビュアーの関与があった。

このため同研究は、ボットだけがレビューした Agentic-PR と人間のコメントがあるものとを区別し、前者を人間の判断の文脈が得られないケースとして除外している。そして、最終的な PR の状態だけでなく、レビュアーのコメント、CI の結果、コミット履歴、ワークフロー上のアクションを読み取る、インタラクションを考慮した評価を提唱している。
