エージェント型プルリクエスト（Agentic-PR）とは、AI コーディングエージェントによってリポジトリに提出されたプルリクエストで
あり、これによってエージェントは現実のソフトウェア開発に直接参加することになる。
[[ScholarlyArticle/why-are-agentic-pull-requests-merged-or-rejected]]
は、オープンソースリポジトリに対してエージェントが作成した PR を指してこの用語を用いており、そうした PR が数千の
リポジトリにまたがっているという [[Dataset/aidev]] データセットの証拠に依拠している。また同研究は、明示的なマージまたは
却下の判断を受けたものを *クローズされた* Agentic-PR として扱う。

## 用法

この用語は、マイニングソフトウェアリポジトリ研究において、エージェントが作成した変更が人間のレビュアーと出会った後に
どうなるかを調べるための分析単位として用いられる。同研究の説明では、Agentic-PR はマージ率や承認頻度といった結果ベースの
指標で評価されることが多く、同研究の中心的な主張は、そうした結果だけではエージェントの能力を誤って表してしまうという
ものである。却下はエージェントの失敗ではなく、ワークフロー上の制約や文書化されていないレビュアーの判断を反映している
かもしれず、マージはレビュアーのフィードバックや人間が適用したコミットに依存しているかもしれない。手作業で精査した
サンプルでは、却下された Agentic-PR のうち明確なエージェントの失敗を示していたのは 35.7% にすぎず、マージされたものの
15.4% にはレビュアーの明示的な関与があった。

このため同研究は、ボットによってのみレビューされた Agentic-PR を人間のコメントがあるものから区別し、前者を人間の判断の
文脈が得られないケースとして除外している。そのうえで、最終的な PR の状態だけでなく、レビュアーのコメント、CI の結果、
コミット履歴、ワークフロー上のアクションを読み解く、インタラクションを考慮した評価を提唱している。
