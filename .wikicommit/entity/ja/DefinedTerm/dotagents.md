dotagents は、Brandon Greenwell に帰される提案で、プロジェクトのエージェント向けコンテキストを**ルーター**と**ライブラリ**に分割するものである。ルートの [[DefinedTerm/agents-md]] ファイルはルーターになる。軽量で、常に読み込まれ、より深いコンテキストそのものを含むのではなく、条件に応じて*どこを見ればよいか*をエージェントに伝える責務を負う。隠しディレクトリ `.agents/` が重い素材を保持し、トピックごとではなく内容の種類ごとに整理される。

その仕組みは [[DefinedTerm/progressive-disclosure]] である。エージェントはまず一画面分のルーティングルールを読み込み、その後、現在のタスクに合致するファイルだけを引き込む。ここでの説明は、これをデバッグ専用の診断エンドポイントを本番ビルドから外しておくことや、すべてを返す一つのエンドポイントではなく関心事ごとに一つのエンドポイントを設けて API を設計することになぞらえる——「必要なものを、必要なときに読み込む。それより前ではなく」。

## 用法

**7種類の内容**がそれぞれ独自のサブディレクトリを持つ。恒常的な振る舞いの制約のための `rules/`、スキーマや API の型といった静的な参照素材のための `context/`、変化しうる永続的な決定のための `memory/`、QA やアーキテクトといった専門的な役割のための `personas/`、再利用可能な複数ステップの手順のための `skills/`、現在のタスクの要件のための `specs/`、そしてセッションの記録のための `logs/` である。

**2つの区別が最も重い意味を担う**、と [[BlogPosting/dotagents-standard-agent-skill]] は述べる。*ルール*は常に従う恒常的な指示であり、*メモリ*は経緯を説明する、変わりうる事実ないし決定である——両者を混同することこそ、この規約が防ぐために存在する元々の問題として説明されており、読み手が「こうしなければならない」と「かつてこう決めた」を区別できなくなってしまう。これとは別に、`context/` は多数のタスクにまたがって永続的かつ読み取り専用であるのに対し、`specs/` は今まさに作られているものであり、タスクが出荷された瞬間に用済みとなる。

**ルーティングルールは、条件付きでなければ何の働きもしない。** 指針とされているのは、各ルールがトリガーを名指し、アクションの動詞——`READ`、`CHECK`、`CONSULT`、`ADOPT`、`RUN` ——を伴うことである。そうすることで、エージェントはポインタをどう扱えばよいか、そして決定的に重要なことに*いつ*扱えばよいかを知る。すべてを読めと言う無条件のルーターは、一階層深いところにモノリスを作り直しているだけだ。

**`memory/` は読み書き可能である。** タスクの途中で永続的な決定を下したり、長く残る選好を学んだりしたエージェントは、それを書き戻すよう指示される——決定を記録するファイルに ADR を追記する、ユーザー向けファイルに選好を書き留める——ことで、次のセッションがそれを導き直すのではなく引き継げるようにする。ルーターがまだ指し示していないコンテキストを必要とするタスクは、ルーターのバグとして扱われる。ともかくそのファイルを読み、タスクを終わらせ、そのうえで欠けていたルールを追加するのである。

**より広い `.agents` プロトコルは、これとは別のスーパーセットである。** 同じディレクトリの考え方を保ちつつ、プロジェクト層とマージされるグローバル層、機械可読な設定ファイル、独自のフロントマタースキーマを持つ構造化されたサブエージェント・タスク・メモリ、そしてバンドルを共有する公開ハブを加える。その記事の示す指針は、手で書いたプロジェクトのコンテキストにはコアの dotagents を使い、グローバル層や MCP との配線が必要になったときにプロトコルの拡張に手を伸ばすこと——そして、ディレクトリ名が共通しているために混同しやすいので、どちらを指しているのかを明示すること、である。

## 関連用語

dotagents は、[[DefinedTerm/agents-md]] が記録しているサイズの問題に対する一つの具体的な答えであり、その分類は `memory/` の軸で [[DefinedTerm/agentic-memory]] と、`skills/` の軸で [[DefinedTerm/agent-skills]] と重なる。これを適用するツールが [[SoftwareApplication/dotagents-standard-skill]] である。
