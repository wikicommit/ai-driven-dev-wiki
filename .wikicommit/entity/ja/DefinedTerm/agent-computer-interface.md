エージェント・コンピュータ・インターフェース——略して ACI——は、モデルが自らのツールを知覚し操作する面である。アクションがどう指定されるか、パラメータが何と呼ばれるか、形式がどう形づくられるか、そしてドキュメントに何が書かれているか。[[TechArticle/building-effective-agents]] はこれを類比によって導入する。「ヒューマン・コンピュータ・インターフェース（HCI）にどれだけの努力が注がれているかを考え、良い*エージェント*・コンピュータ・インターフェース（ACI）を作ることにも同じだけの努力を投じる計画を立てよ」。丁寧な ACI の設計は、その記事がエージェント構築について結びで挙げる3つの原則の一つである。

## 用法

**形式の選択は見た目の問題ではない。** その記事の例は、ファイル編集が差分としても全面的な書き直しとしても指定でき、構造化された出力がマークダウンでも JSON でも返せる、というものだ——ソフトウェアエンジニアなら可逆な変換と呼ぶような違いである。だが、モデルにとって書くのがはるかに難しい形式がある。差分は、新しいコードが書かれる*前に*チャンクのヘッダでその塊の行数がいくつ変わるのかを知っている必要があり、JSON の中のコードは改行と引用符のエスケープを要する。

そこから形式を選ぶ3つの規則が導かれる。モデルが自ら袋小路に書き進んでしまう前に考えるだけのトークンを与えること。形式を、モデルがインターネット上のテキストの中で自然に目にしてきたものに近く保つこと。そして、何千行もの正確な行数を管理し続けるとか、コードを文字列エスケープするといった、形式上のオーバーヘッドがないようにすること。

インターフェースそのものについては**4つの実践**が挙げられている。*モデルの立場に立ってみること*——そのツールの説明とパラメータをもとに、それを使うのに自分でも慎重な思考を要するのなら、モデルにとってもそうである。良いツール定義には、使用例、エッジケース、入力形式の要件、そして他のツールとの明確な境界がしばしば含まれる。*パラメータの名前と説明を、ジュニア開発者向けの優れた docstring のように書くこと*——これは似たツールが多数関わるときに最も重要になる。*モデルが実際にそのツールをどう使うかをテストすること*——多数の入力例を走らせてどんな誤りを犯すかを見て、反復する。そして*ツールをポカヨケすること*——誤りが起きにくくなるよう引数を変える。

**報告されている見返り**は、[[Dataset/swe-bench]] 向けのエージェントを構築する際、チームがプロンプト全体よりもツールの最適化に多くの時間を費やした、というものだ。挙げられている具体例はこうである。エージェントがルートディレクトリの外へ移動した後、相対パスを使うツールでモデルが誤りを犯した。そのツールを常に絶対パスを要求するよう変更したところ、モデルはその方法を完璧に使いこなすようになった。

### 本番環境における失敗面としてのツール

[[TechArticle/how-we-built-our-multi-agent-research-system]] は同じ言葉でこの原則を言い直し——「エージェントとツールのインターフェースは、ヒューマン・コンピュータ・インターフェースと同じくらい重要である」——スケールしたときに何が起きるかを付け加える。誤ったツールを選ぶことは、単に非効率というより致命的であることが多い。「Slack にしか存在しないコンテキストをウェブで検索しているエージェントは、初めから絶望的である」。[[DefinedTerm/model-context-protocol]] のサーバーはこの問題を複合させる。エージェントは、説明の質が大きくばらつく未知のツールに出くわすことになり、悪い説明は「エージェントを完全に誤った道へ送り込みかねない」からだ。その答えとして採られたのは、プロンプトに明示的な選択のヒューリスティックを置くこと——まず利用可能なツールをすべて調べる、ツールの用途をユーザーの意図に合わせる、広く外部を探索するときはウェブ検索を使う、汎用のものより専用のツールを優先する——に加え、各ツールが明確に区別された目的と明快な説明を持つことを要件とすることであった。

同じ記事は、その改善そのものを自動化したことも報告している。**ツールテストエージェント**に欠陥のある MCP ツールが与えられ、それを使おうと試み、ぶつかった失敗を避けるようにツールの説明を書き換えた。そのツールを何十回もテストすることで重要なニュアンスとバグが浮かび上がった。報告されている結果は、新しい説明を使った後続のエージェントのタスク完了時間が 40% 減少したことである。犯していた誤りのほとんどを回避できたからだ。
