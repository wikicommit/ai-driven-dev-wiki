「Agentic coding and persistent returns to expertise」は、[[Organization/anthropic]] が2026年6月16日に公開した経済調査レポートである。2025年10月から2026年4月にかけての約23万5千人による約40万件の対話的な [[SoftwareApplication/claude-code]] セッションの、プライバシーを保護した分析に基づいており、CLI、Claude.ai、デスクトップアプリを通じた利用を対象として、非対話的な利用は明示的に除外している。エージェントの自律性の測定と、Anthropic 社内で Claude Code が仕事をどう変えているかについての、同社の先行する2本のレポートを踏まえたものである。

同レポートの枠づけとなる問いは、形式的なコーディング経験を持たない人々が複雑な技術的作業を通じてエージェントを首尾よく導けるのか、そしてそれが知識労働一般について何を含意するのか、というものである。その答えは、2つの主張を同時に保持したものである。エージェンティックコーディングは、動くソフトウェアを生み出すうえでコーディングの*経歴*の重要性を下げつつあるが、ドメインの*専門性*——解こうとしている問題の掌握——は、セッションが成功するかを決めるものであり続ける、というものである。同レポート自身による要約はこうである。「コーディングエージェントはドメインの専門性を代替してはいない——働き手がエージェントに持ち込む理解が深いほど、エージェントはより質の高い仕事をなしうる。」

同レポートのあらゆる指標は、観測された現実の成果からではなく、セッションのトランスクリプトを読む分類器によって導かれている。これは著者たちが直接述べ、末尾で立ち返る限界である。

## 主な知見

- **安定した分業。** 意思決定を帰属させる分類器が、各セッションの意思決定を計画（何をするか、どのアプローチをとるか、何をもって完了とするか）と実行（どのファイルを変更するか、何を書くか、どのコマンドを実行するか）に分け、それぞれを人間か Claude に帰属させる。平均して人間は計画上の意思決定の約70%、実行上の意思決定の約20% を行っている。同レポートによるその簡潔な言明は「人間が何を作るかを決め、エージェントがどう作るかを決める」というものである。
- **専門性は1つの指示あたりの仕事量を増やす。** 各トランスクリプトから分類器が、*そのタスクにおける*ユーザーの見かけの専門性を、初心者から専門家までの5段階で評定する。用いる信号は3つ——指示がどれだけ精密に枠づけられているか、ユーザーが Claude に何を検証させるか、そしてユーザーが Claude を訂正するのかその逆なのかである。同レポートは、これが職位ではなくタスク固有のものであることを強調する。「初めて Rust の質問をするシニアエンジニアは Rust については初心者である」一方、Python を使ったことがなくとも、スクリプトがどの照合ルールを強制せねばならないかを正確に指定する会計士は、そのタスクにおける専門家である。典型的な初心者のセッションでは、各プロンプトが約5回の Claude のアクションと約600語の出力を引き起こす。専門家のセッションでは約12回のアクションが引き起こされ、約3,200語を伴う。この傾向はあらゆる種類の作業とあらゆるタスク価値帯の内部で成り立ち、作業モード、タスク価値、月、職種、モデルファミリーを統制した回帰でも、専門性1段階あたりアクション +9%、出力 +13% として残る。
- **専門性は成功を予測し、その効果の大半は尺度の下端にある。** 初心者と評定されたセッションが*検証済みの成功*に達するのは15%、少なくとも部分的な成功に達するのは77% である。中級以上と評定されたセッションでは検証済みの成功が28〜33%、部分的な成功が91〜92% となる。困難に直面したセッションのなかでは、検証済みの成功は初心者評定の4% から専門家評定の15% へ上がる。最も明瞭な行動上の違いは、諦めることである。困難に直面したセッションのうち、初心者評定のものは19% が*放棄*——コードが1行も書かれないまま失敗と判定される——で終わるのに対し、それ以外はいずれも5〜7% である。
- **職種は専門性ほどには効かない。** ソフトウェア関連の職種の人々は、全体としてセッションの約30% で検証済みの成功に達するのに対し、他の職業では約26% である。コードを生み出すセッションに限れば34% と29%、少なくとも部分的な成功は89% と88% である。上位10の職種グループはいずれも、コードを生み出すセッションにおいてソフトウェアエンジニアから7パーセントポイント以内に収まっており、その差は7か月を通じて、両グループの成功率がともに上昇するなかでも、広がりも縮まりもしていない。管理職の職種は検証済みの成功で最も高く、ソフトウェアエンジニアリングをわずかに上回る。著者たちはこれが転用可能なマネジメント技能を反映しているのかもしれないと示唆しつつ、測定上の人工物である可能性にも注意を促している。検証は部分的にはトランスクリプト中の明示的な確認に依拠しており、管理職は求めたものが得られたときにそう言う傾向が強いかもしれないからである。
- **作業はデバッグから離れていった。** セッションは9つの作業モード——構築、修正、テスト、オーケストレーション、運用、理解、計画、分析、コミュニケーション——に分類される。観測期間を通じて、壊れたコードの修正に費やされたセッションの割合は33% から19% へ下がり、ソフトウェアの運用は14% から21% へ増え、文章作成とデータ分析は約10% から20% へおよそ倍増した。全期間では、約56% のセッションが文章作成（25%）、修正（26%）、あるいはテストとオーケストレーション（5%）であり、運用が17%、計画ないし探索が14%、分析ないし散文が13% であった。
- **タスクの価値は上がった。** 各セッションの経済的価値を、その作業がフリーランスのマーケットプレイスでいくらになるかによって見積もり、実際の募集案件の公開データセットに対して較正したところ、平均的なセッションの推定価値は10月から4月にかけて27% 上昇した——構築で約43%、運用で34%、修正で32% である。同レポートは、これらの価格推定は粗いものであり、ドル金額として読まれるためではなく、時間を通じてタスクを比較するためのものだと述べている。
- **セッションの形。** 典型的なセッションは約4ターンで進む。各ユーザープロンプトは平均して約10回、ときには100回を超える Claude のアクションの連鎖を引き起こし、Claude は1ターンあたり平均2,400語の出力を書く。確認と確認の間に Claude がどれだけ行うかは、誰が決めているかに連動する。ユーザーが実行上の意思決定の80% 超を行うとき Claude は1ターンあたり約8回のアクションを取り、Claude が計画上の意思決定の80% 超を行うときには約16回になる。

## 根拠と留保

証拠の基盤は、Anthropic 自身の製品についての自社のテレメトリとトランスクリプトを、自社の分類器で分析したものである。同レポートはこの点と、行った検証・行わなかった検証について透明である。セッションの作業モードの分類は自動記録されたテレメトリと突き合わされ、コードの作成ないし修正とラベル付けされたセッションの90% 超で実際にコードの変更が見られた。専門性と成功の分類器は、コーディングエージェントのセッションの公開データセットである SWE-chat に対して例示されている。それでもなお著者たちは、分類器は「大規模に検証することが依然として難しい」こと、そして Claude Code のセッションは、人手によるラベルが正解として機能するには長く複雑すぎるかもしれないことを述べている。

成功そのものも、2層からなるトランスクリプト由来の構成概念である。*判定された成功*は、その人が意図したことをなしたかを分類器が判断することから得られる。*検証済みの成功*はこれに加えて、少なくとも1つの硬い検証可能な信号——作業に対応する git のコミットやプルリクエスト、通過するテストスイート、あるいはユーザーによる明示的な肯定——を要求する。明確な目標がないと判定されたセッション、標本の約7.7% は、成果の分析から除外されている。専門性の比較は作業モード、タスク価値帯、月、タスクの主題、大きな職種グループを固定したうえで行われており、著者たちはこれを、専門家は単に違うタスクを選んでいるだけではないかという懸念への、完全ではなく部分的な答えとして提示している。

述べられている限界は、現実の成果が観測されていない——あるセッションから出たコードが実際に使われたのか破棄されたのかは測定されていない——ことと、活動のかなりの割合を占めると説明される非対話的な利用が完全に除外されていることであり、それを測定する枠組みが今後の作業の優先事項として挙げられている。著者たちはまた、今後注視するつもりの2つの信号も挙げている。専門性へのリターンが下がり始めること——これはモデルが、いまはユーザーが持ち込んでいる判断を供給し始めていることを示唆するだろう。そして、ソフトウェア以外の職種のユーザーによる成功したコーディングセッションの継続的な増加——これはソフトウェアの生産があらゆる分野の通常業務の一部になりつつあることを示唆するだろう。
