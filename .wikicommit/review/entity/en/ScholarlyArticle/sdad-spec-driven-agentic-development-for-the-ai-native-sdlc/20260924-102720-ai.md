Key Points bullet 3 says the report reframes 'Waterfall's requirements freeze and Big Design Up Front ("BDUF 2.0")' as technical optimisations for the agentic execution phase. The source (Sec. 6.3) uses the words 'as a technical optimisation' only for the requirements freeze. It frames BDUF 2.0 more broadly, as clarity acting as an execution constraint (Sec. 6.2). The page's wording puts the two into one phrase, which slightly overstates what the source says about BDUF 2.0.
Key Points bullet 5 says the four-step workflow is depicted 'as an SDAD-V model'. In the source, the SDAD-V model (Sec. 7.3, Fig. 5) is a separate figure with its own stages: Stakeholder Intent, Spec Architect, Formal Specification, Spec Fidelity Gate, Agentic Implementation and Agentic Verification. The source does not explicitly call it a depiction of the Sec. 8.3 workflow. The overlap is close, so this is not a defect, but a reader could take the two as the same thing.
