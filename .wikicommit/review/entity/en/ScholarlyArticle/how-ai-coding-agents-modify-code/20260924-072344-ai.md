Body paragraph 3 says semantic alignment was measured 'with cosine similarity between CodeBERT and GraphCodeBERT embeddings of the description and the cleaned diff'. This can be misread as comparing a CodeBERT embedding with a GraphCodeBERT embedding. The source (lines 85-88) computes description and diff embeddings with each model separately and measures cosine similarity within each model. Wording such as 'cosine similarity between description and diff embeddings, computed separately with CodeBERT and with GraphCodeBERT' would be clearer.
The intro links 'GitHub Copilot' to [[SoftwareApplication/github-copilot]], and the page says the tool can autonomously submit pull requests. That one-hop page describes plain Copilot as reactive and points agentic, PR-anchored behaviour to [[SoftwareApplication/github-copilot-coding-agent]]. The page attributes the claim to the authors, who cite 'GitHub Copilot [13]', so this is not a contradiction. Still, the PR-submitting 'Copilot' agent type from AIDev may be better linked to the coding-agent page.
