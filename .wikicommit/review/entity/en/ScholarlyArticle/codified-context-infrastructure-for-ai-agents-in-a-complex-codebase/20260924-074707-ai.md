The page says the knowledge base is '34 subsystem specification documents totalling about 16,250 lines'. The source says '34 Markdown files (~16,250 lines including the ~1,600-line retrieval service)', so the 16,250 figure also counts the retrieval server's code, not only the specification documents. A reader could take the whole figure as specification text.
The page's Key Points says 'six practitioner guidelines, among them ... that agent confusion is a diagnostic signal that a specification is missing or stale'. Figure 4's six labelled guidelines (G1–G6) do not include agent confusion; the sixth is G6, 'Stale specs mislead efforts'. The agent-confusion advice appears only in the prose of Section 5.1 ('monitor agent confusion as a diagnostic signal'). So the page puts a prose guideline among the numbered six, which is easy to misread as one of G1–G6.
