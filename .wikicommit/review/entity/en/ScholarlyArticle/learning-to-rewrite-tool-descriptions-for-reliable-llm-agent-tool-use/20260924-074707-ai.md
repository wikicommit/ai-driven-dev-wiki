Key Points bullet 3 says the scaling experiments 'expose the agent to 150 or more candidate tools' and that the 29.23% and 60.89% figures are averages. The source (Section 4.3, source lines 431-433) says these are averages over '0–150 additional tools'. A reader could take the page to mean the gains were measured at 150+ tools only, rather than averaged over the whole sweep from 0 to 150 added tools.
Key Points bullet 1 gives the pattern-coverage figures for 'the analysed tools'. That wording is safe. Note that the source contradicts itself on the sample: the introduction (line 78) says the coverage holds 'on 4,585 unseen tools', but Appendix C.2 (lines 1442-1444) says the analysis used only tools from the Media and Finance categories of A_ts. A later edit that gives a tool count should use the appendix's scope.
