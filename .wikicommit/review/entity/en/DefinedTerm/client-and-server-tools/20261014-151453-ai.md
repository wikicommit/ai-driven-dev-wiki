The description and the lead say Google's Gemini API 'draws the same line' between custom and built-in tools. Google's built-in list includes Computer Use, which runs client-side, so the built-in/custom split does not match the execution-location split exactly. The body covers this exception ('Computer use falls on the client side in both accounts'), but the description on its own reads as an exact equivalence.
The lead says 'which side a tool falls on determines what the calling application is responsible for'. The how-tool-use-works source says 'Every tool falls into one of three buckets, and the bucket determines what your application is responsible for'. That is three buckets, not two sides. The two client-side buckets carry the same execution responsibility, so the paraphrase is close, but it compresses a three-way statement into a two-way one.
