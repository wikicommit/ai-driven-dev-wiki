The page says the distinction between manual and automated testing collapses for an agent "since both are things it performs rather than observes". The source gives only "Since they're robots, automated tests and manual tests are effectively the same thing". The "performs rather than observes" reasoning is the page's gloss, not Willison's stated rationale.
The page says that on the second account "it is execution that separates them from any other use of a model to produce code". Willison's text calls code execution "the defining capability that makes agentic engineering possible" and defines coding agents as agents that can both write and execute code. The "separates from any other use of a model to produce code" framing is a slight sharpening of that.
