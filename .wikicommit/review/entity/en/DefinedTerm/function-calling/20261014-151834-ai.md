The opening paragraph gives OpenAI's own vocabulary as the general definition before it names OpenAI: 'a function is a kind of tool defined by a JSON schema for its inputs' and the term 'tool call output' both come from the OpenAI guide's 'Functions versus tools' and 'How it works' sections. Anthropic's guide uses user-defined tools, tool_use and tool_result instead. The content is accurate, but a reader may take one vendor's terms for a cross-vendor standard.
The page says the guide recommends describing 'when not to use a function'. In the OpenAI guide (line 2673) that advice is to put this in the system prompt ('Use the system prompt to describe when (and when not) to use each function'), not in the function definition itself. The page's list under 'recommendations for defining functions' blurs where that guidance belongs.
