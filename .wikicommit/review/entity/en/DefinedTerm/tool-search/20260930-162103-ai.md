'When It Applies' gives Anthropic's threshold as 'more than ten tools are available'. The source says '10+ tools available' and lists '<10 tools' as less beneficial, so exactly ten tools falls on the recommended side. 'ten or more' would match the source more exactly.
'Less beneficial for ... tools used in every session' shortens the source's 'All tools used frequently in every session'. Dropping 'all' makes the condition look broader than Anthropic states it.
The Claude Code paragraph says 'MCP tools are always deferred' and also says 'tools marked to always load stay loaded'. Both follow the post, but in the post's isDeferredTool code the alwaysLoad check runs before the isMcp check. An MCP tool marked alwaysLoad would therefore not be deferred, so read together the two statements can look contradictory.
