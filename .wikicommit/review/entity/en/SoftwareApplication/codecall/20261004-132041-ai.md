The lead paragraph says that in Codecall several tool operations, 'including independent ones run in parallel', happen in one execution. The README lists 'No Parallel Execution' as a problem with traditional agents (lines 219-221), but it never says outright that Codecall runs calls in parallel. Its own example scripts call the tools one after another inside for-loops (lines 258-276, 680-685). Parallelism is therefore implied by the README's framing of the problem, not stated as a Codecall feature. A reader could take it as a documented capability.
