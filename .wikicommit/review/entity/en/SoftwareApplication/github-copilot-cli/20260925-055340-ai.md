The custom-agents post contradicts itself on the profile filename. Its prose says the file 'ends with `.agent.md`' (e.g. `accessibility.agent.md`), but all four of its worked examples are headed `.github/agents/security-audit.md`, `iac-compliance.md`, `release-docs.md` and `incident-response.md`, with no `.agent` infix. The page follows the prose, which is defensible, but a reader who copies the examples will see a mismatch.
The Capabilities section says Copilot CLI 'exposes' `/plan` and `/autopilot`. The applied-science post never states outright that these are Copilot CLI commands. It lists Copilot CLI as the author's coding agent, tells readers to 'Plan a new feature with Copilot using `/plan`' and to 'Let Copilot implement the feature on `/autopilot`', and later runs `/plan` inside a `copilot` CLI session. So linking `/plan` to the CLI is well supported, but linking `/autopilot` to it is an inference from context.
