The claim that the SDK authenticates against the Gemini Developer API rests only on a passing mention in 0.1.13 (setup_vscode_debugging.sh configures 'Gemini Developer API defaults', source line 2811) rather than an explicit feature entry; supported but thinly.
'Much of the release history consists of moving settings into such objects — models, retries, budgets, command execution and context compaction' is the page's own synthesis; each item is supported (models → AgentConfig/LocalAgentConfig 0.1.4; retries in LocalAgentConfig 0.1.9; BudgetConfig 0.1.11; RunCommandConfig 0.1.13; CompactionConfig 0.1.17), but the changelog does not itself frame this as a trend, and it does not state BudgetConfig's host object.
Subagents given 'their own instructions and tool allowlists (0.1.8)' — 0.1.5 already added SubagentConfig with 'declarative instructions and tools' (source line 2985); both version attributions match the changelog's wording, but a reader could take 0.1.8 as the first introduction of per-subagent instructions.
Vertex AI Express mode (API key) is announced in both 0.1.11 (line 2843) and 0.1.16 (line 2737); the page correctly avoids attributing a version.
