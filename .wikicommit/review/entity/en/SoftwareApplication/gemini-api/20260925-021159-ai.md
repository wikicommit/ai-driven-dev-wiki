Line 61-62: 'Gemini 3 series models can combine built-in and custom tools in a single turn, which the documentation calls tool context circulation' attaches the name to the combining feature itself. The source says the model *uses* tool context circulation to coordinate execution across environments. The name belongs to the coordination mechanism, not to the ability to combine tools. Easy to misread.
Lines 50-51 link the built-in/custom execution split to [[DefinedTerm/client-and-server-tools]], but that page defines the term as a distinction in Anthropic's Claude API. The two pages do not contradict each other. A reader may still take the link to mean the term is vendor-neutral, or that Gemini's documentation uses it. The Gemini source only talks about 'built-in (managed by Google)' and 'custom (managed by you)'.
The Computer Use bullet says it interacts with 'web browser interfaces', which matches this source's table. The linked [[DefinedTerm/computer-use]] page, drawing on a different Gemini doc, describes Gemini's computer_use tool as also targeting mobile and desktop environments. This is a narrower scope rather than a contradiction, because the source here does say browser UIs, so I did not raise it as an issue.
